voice_profiles 新增列 (向前兼容, 旧库自动 ALTER ADD):
| 列 | 类型 | 默认 | 用途 |
|----|------|------|------|
| reference_audio | TEXT | NULL | 参考音频路径 (克隆用) |
| style | TEXT(JSON) | '{}' | 声音风格覆盖 (对齐 VoiceStyle) |

## 5. 状态机

```
creating ──┬──→ ready ──┬──→ disabled ──┬──→ ready
           │            │               │
           ↓            ↓               ↓
        disabled     deleted         deleted
           │            │
           ↓            ↓
        deleted      (终态)
```

转移表 (`_TRANSITIONS`):
- creating → {ready, disabled, deleted}
- ready → {disabled, deleted, creating}
- disabled → {ready, deleted, creating}
- deleted → {} (终态, 仅硬删可移除)
- active → {ready, disabled, deleted} (V1.4 前向兼容)

非法转移抛 `VoiceProfileError`。

## 6. ID 生成策略

- 显式 `voice_id`: 调用方提供, 校验唯一, 冲突抛异常
- 自动生成: `{slug(name)}_{uuid4.hex[:8]}`, 冲突重试 8 次, 极端退化为 `voice_{uuid4.hex[:12]}`
- slug: ASCII 名称小写+非字母数字转`_`; 非 ASCII (如中文) → `voice`
- 示例: `元亨默认` → `voice_e0eea30d`; 显式可传 `yuanheng_default`
