## YHLZ核心理念

## 项目定位（重排：数字生命第一）

- 第一主体：**数字生命**（YHLZ 的元亨是生命形态：陪伴、理解、记忆、成长、共同演化）。
- 第二主体：智能助手——是数字生命发挥的一个功能面，不是项目本体。
- 一切功能开发服务于"数字生命"定位；助手类能力作为功能面持续增强。
- YHLZ 内核 = 认知（反思/成长/治理）、记忆（长期/人格/经验）、人格引擎、具身系统——**必须保留**，不因功能迭代删除、降级或改称"花瓶层"。

## 吸收的核心理念（记忆架构思想）

- 记忆可遗忘，模式永存：具体事件可归档，但性格、思维、价值观沉淀为人格。
- 理解这个人 > 记住一切：记忆服务于理解与陪伴，而非堆砌记录。
- 数据永不静默删除：记忆只做标记、冷存、归档、版本化。
- 人在人格与记忆上拥有人工裁决权（用户确认后才生效）。
