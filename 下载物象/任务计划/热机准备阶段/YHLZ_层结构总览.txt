三、层间调用铁律（架构冻结）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Interface → Service → Manager → Storage / Adapter

| 层 | 角色 | 约束 |
|----|------|------|
| Service (service.py)      | 唯一 API 入口 (170+ companion_* API) | 跨子系统协作只能经 Service 层 |
| MainCompanionAgent        | 引擎聚合/路由/委派               | 不直接暴露外部 |
| 各引擎 (21 子包)          | 单一能力域                       | 不跨子包调用存储 |
| Storage/Adapter           | 存储与外部能力                   | Adapter 不调 Service |
| 独立子系统 (agent/vision/ | 互相不依赖                       | 协作仅经 Tool System 或 Service API |
|   personality/voice_identity) |                            |                |
