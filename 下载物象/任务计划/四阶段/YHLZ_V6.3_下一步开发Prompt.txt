## 2. 本阶段开发判断（为什么做这个，不做那个）

### 为什么做"真实感知引擎 + 感知-行动集成"

V6.2 建立了**完整的安全感知管道**（权限/验证/候选），但 OCR/检测还是 Mock。
同时感知结果**没有出口**——记忆候选没有反思批准流程，感知没有接入 Agent Pipeline。

V6.3 双主线：
1. **真实感知引擎**：Tesseract OCR + 模板匹配检测（Mock 同接口，无环境 skipIf）
2. **感知-行动闭环**：感知 → 反思 → 记忆批准 → 行动参考（经 Permission）

### 为什么不做（V6.3 明确不包含）

- 不做具身化（虚拟形象/动作）→ V7.x
- 不做 VLM 深度视觉理解（纯规则 + 传统引擎）
- 不做自主行动（行动仍经 Permission + 用户确认）
- 不做黑盒训练

## 3. 本版本目标

**V6.3 Embodied Perception & Action Integration**

1. **真实感知引擎** `perception/adapters/`
   - `ocr_tesseract.py`：Tesseract OCR 适配器（无环境 → is_available=False，skipIf）
   - `detection_template.py`：OpenCV 模板匹配检测（skipIf 无 OpenCV）
   - Mock/真实同接口（行为一致，仅引擎不同）
2. **感知-反思-记忆批准流程** `companion/perception/memory_gate.py`
   - 记忆候选 → Reflection 评估 → 批准 → 写入经历（多模态隔离保持）
3. **感知接入 Agent Pipeline**
   - perception_agent 增强：接收感知帧作为管道输入（V5.2 pipeline 扩展）
4. **配置**：`perception_ocr_engine` / `perception_detect_engine` /
   `perception_tesseract_path` / `perception_memory_gate_enabled`

## 4. 架构设计要求

### 分层铁律（保持）

```
Interface → Service → Manager → Storage / Adapter
```

### 真实感知适配器

```
backend/embodied/companion/perception/adapters/
├── ocr_tesseract.py       # Tesseract OCR (pytesseract, skipIf 无)
└── detection_template.py  # OpenCV 模板匹配 (skipIf 无 cv2)
```

- 与 Mock 同一 `PerceptionAdapter` 接口
- `is_available()` 严格检查（无引擎 → False → 测试 skipIf）
- 注册表默认 Mock，配置切换真实（`perception_ocr_engine=ocr_tesseract`）

### 记忆批准流程

```
backend/embodied/companion/perception/
└── memory_gate.py
```

- 候选 → 反思评估（ReflectionEngine.reflect）→ 置信度判断 → 批准/拒绝
- 批准 → ExperienceManager.store_from_event（source="vision_perception"）
- 拒绝 → 审计记录（不写入）
- 多模态隔离：批准前不触碰人格/行动

### Agent Pipeline 扩展

- perception_agent 增加感知帧读取（经 Service API）
- 管道：perception → experience → planning（V5.2 已有框架，扩展输入源）

## 6. 开发要求

### 必须

- Mock 与真实同一接口，行为一致
- 无引擎环境 → is_available=False → skipIf 测试（不失败）
- 记忆批准必须经 Reflection（多模态隔离保持）
- 拒绝必须有审计（禁止静默）
- 权限默认拒绝（V6.2 保持）
- 配置驱动（`perception_*`），禁止魔法数字
- 中文 docstring / 类型注解 / RLock / 完整日志 / 测试 CRLF
- 版本断言批量更新用 Python 脚本

### 禁止

- 禁止破坏 V6.2 及以前 API
- 禁止感知结果直接修改人格/行动（必须经批准）
- 禁止跨层调用 / 静默吞异常 / 黑盒 / 临时方案
- 禁止感知层直接调用 LLM
