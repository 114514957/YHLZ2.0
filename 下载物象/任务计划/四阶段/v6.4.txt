# 5. 核心原则


# 原则一

## 感知不是经验


任何感知：

不能直接进入长期记忆。


必须经过：



Perception

↓

Verification

↓

Reflection Evaluation

↓

Memory Gate

↓

Experience



---

# 原则二

## Reflection不是决策者


Reflection Evaluator：

只能提供：

- 分析
- 评分
- 风险提示
- 价值判断建议


不能：

直接写入Memory。


规则：



Reflection Layer

    ↓

Advisor

Memory Gate

    ↓

Authority



---

# 原则三

## 经验必须具有来源


所有Experience必须可追溯：



来源

↓

输入

↓

验证

↓

反思

↓

批准

↓

存储



---

# 原则四

## 多模态统一经验对象


禁止：


Vision Memory

Audio Memory

Text Memory



独立发展。


统一：



Multimodal Experience Object

# 8. Reflection Evaluator


## 目标


实现：

感知后的深度评估。


---

输入：



Perception Candidate



---

输出：


```json
{
"reflection_score":0.0,

"pattern":"",

"contradiction":"",

"value_hint":"",

"reason":""
}
9. Reflection规则

必须检查：

可信度

来源是否可靠。

一致性

是否与已有知识冲突。

长期价值

是否值得保存。

身份影响

是否影响长期成长。

风险

是否包含危险信息。

10. Counterfactual Check

新增：

反事实验证。

目标：

降低幻觉进入Memory。

接口：

counterfactual_check()

检查：

如果该感知不存在：

结论是否仍成立？

示例：

OCR：

支付成功

验证失败：

不得形成经验。

11. Memory Gate增强

V6.3已有：

五维评分。

V6.4增加：

Reflection Score。

最终评分：

Source Trust

+

Repetition

+

Long Term Value

+

Identity Impact

+

Risk

+

Reflection Score

=

Final Score

规则：

>= threshold

approved


< threshold

rejected

}

要求：
