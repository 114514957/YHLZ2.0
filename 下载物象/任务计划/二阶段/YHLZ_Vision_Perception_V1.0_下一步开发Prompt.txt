================================================ 二、本阶段开发判断
================================================

当前系统已经具备：

输入： Voice + Vision (基础帧输入)
思考： Agent Core
基础记忆： Memory Interface

当前 Vision Foundation 已能稳定产出 VisionFrame, 但 YHLZ 还"看不懂"画面内容。

Foundation 阶段严守"只输入不理解"的边界, 已完成。

下一步判断：

进入 Vision Perception Layer (视觉感知层)。

本阶段只建设：

在 Foundation 之上, 加入"基础视觉理解"能力。

不进入：

-   完整 VLM (视觉大模型) 集成
-   多模态推理 (Vision + Language 联合推理)
-   视觉记忆 (Vision Memory)
-   自动操作电脑

原因：

理解层未抽象稳定前, 直接接入大模型会造成架构耦合, 后续替换模型时返工成本高。

================================================ 三、本版本目标
================================================

版本：

YHLZ Vision Perception V1.0

只解决：

在稳定视觉输入层之上, 建立可替换、可测试、可观测的基础视觉感知能力。

包含：

1.  Perception 模块基础架构 (在 vision/ 之下扩展 perception/)

2.  统一感知数据结构 (PerceptionResult / PerceptionTarget / TextRegion / DetectionBox)

3.  OCR 文字理解能力 (基于 PaddleOCR 或 RapidOCR, 二选一, 默认 RapidOCR 轻量)

4.  基础目标检测能力 (基于 YOLO, 默认 YOLOv8n 轻量模型, 可换 YOLOv5n)

5.  感知适配器接口 (PerceptionAdapter 抽象 + OCRAdapter + DetectionAdapter)

6.  感知服务编排 (PerceptionService: 接收 VisionFrame → 调度多 Adapter → 汇总 PerceptionResult)

7.  与 Agent Core Tool System 对接 (注册 read_screen_text / detect_objects 工具)

8.  权限扩展 (在 VisionPermission 之上增加 perception_enabled / ocr_enabled / detection_enabled)

9.  日志扩展 (复用 VisionLogger, 增加 perception 事件类型)

10. 测试框架 (Mock 模型 + 真实模型双通)

================================================ 四、本版本不包含
================================================

禁止本版本开发：

-   VLM 视觉大模型 (Qwen-VL / LLaVA / GPT-4V 等) 集成
-   图像语义分割 (Semantic Segmentation)
-   人脸识别 / 表情识别
-   姿态估计 (Pose Estimation)
-   视频时序理解 (Action Recognition)
-   Vision Memory (视觉记忆持久化)
-   自动操作电脑 (鼠标键盘控制)
-   多模态推理 (Vision-Language 联合 prompt)

原因：

感知层接口未稳定前, 接入高阶能力会导致架构返工。
本版本只让 YHLZ 能"读出字"和"框出物体", 不让其"理解画面语义"。

================================================ 六、开发任务
================================================

------------------------------------------------------------------------
任务 P0：

Perception Schema

要求：

定义统一感知数据结构。

定义：

PerceptionResult

字段：

-   id
-   frame_id (关联 VisionFrame.id)
-   source (screen / camera / mock)
-   timestamp
-   ocr_results: List[TextRegion]
-   detection_results: List[DetectionBox]
-   latency_ms
-   status (ok / error / permission_denied / no_model)
-   error
-   metadata

定义：

TextRegion

字段：

-   text
-   confidence
-   bbox (x, y, w, h)
-   language (zh / en / ja / mixed)

定义：

DetectionBox

字段：

-   label
-   confidence
-   bbox (x, y, w, h)
-   class_id

------------------------------------------------------------------------
任务 P0：

Perception Interface

要求：

建立统一感知适配器接口。

支持：

-   OCR Adapter
-   Detection Adapter
-   Future Perception Adapter (如条码识别 / 二维码)

定义：

PerceptionAdapter (抽象基类)

方法：

-   name (类属性)
-   type (类属性: "ocr" / "detection" / "barcode" 等)
-   is_available() -> bool
-   perceive(frame: VisionFrame) -> PerceptionResult (或对应子结果)
-   list_models() -> List[Dict] (可选, 列出可用模型)
-   load_model(model_name: str) -> bool (可选)

------------------------------------------------------------------------
任务 P0：

OCR Adapter

目标：

实现图像中文字识别。

技术选型：

默认 RapidOCR (轻量, CPU 友好, ONNX 推理)。
保留 PaddleOCR 切换接口 (通过 register_adapter("paddleocr", ...))。

功能：

1.  文字检测 (定位文字区域)
2.  文字识别 (输出文本内容)
3.  置信度输出
4.  语言检测 (中/英/日/混合)
5.  模型不可用时返回 NO_MODEL 错误结果 (不抛异常)
6.  Mock 模式 (返回合成 TextRegion)

输出：

List[TextRegion]

------------------------------------------------------------------------
任务 P0：

Detection Adapter

目标：

实现图像中目标检测。

技术选型：

默认 YOLOv8n (ultralytics, ONNX 或 PyTorch 后端)。
保留 YOLOv5n 切换接口。

功能：

1.  目标检测 (输出 bbox + label + confidence)
2.  支持 COCO 80 类 (默认)
3.  置信度阈值可配置 (默认 0.5)
4.  NMS 阈值可配置 (默认 0.45)
5.  模型不可用时返回 NO_MODEL 错误结果 (不抛异常)
6.  Mock 模式 (返回合成 DetectionBox)

输出：

List[DetectionBox]

------------------------------------------------------------------------
任务 P1：

Perception Manager

职责：

管理多 PerceptionAdapter 生命周期。

支持：

-   register_adapter(type, adapter)
-   unregister_adapter(type)
-   list_adapters() -> Dict[type, Adapter]
-   perceive(frame, types: List[str]) -> PerceptionResult (并行调度多 Adapter)
-   单例: get_manager / reset_manager

约束：

-   并行调度 (OCR + Detection 可同时跑)
-   单 Adapter 异常不影响其他 Adapter
-   全部异常在 Manager 层隔离, 不外抛

------------------------------------------------------------------------
任务 P1：

Perception Service

职责：

统一对外 API, 组合 VisionService + PerceptionManager + PermissionChecker + VisionLogger。

流程：

1.  (可选) 调用 VisionService.capture() 获取帧 (或接收外部传入帧)
2.  权限校验 (perception_enabled / ocr_enabled / detection_enabled)
3.  调用 PerceptionManager.perceive(frame, types)
4.  日志记录 (复用 VisionLogger, event="perceive_start/success/fail")
5.  返回 PerceptionResult

API：

-   perceive(frame=None, types=None) -> PerceptionResult
-   perceive_screen(types=None) -> PerceptionResult (快捷: 自动截图)
-   perceive_camera(types=None) -> PerceptionResult (快捷: 自动拍照)
-   ocr(frame=None) -> List[TextRegion] (快捷: 仅 OCR)
-   detect(frame=None) -> List[DetectionBox] (快捷: 仅检测)

单例： get_service / reset_service

------------------------------------------------------------------------
任务 P1：

Agent Core 工具注册

目标：

让 Agent Brain 能调用视觉感知能力。

注册工具 (backend/agent/tools/vision_tools.py)：

1.  read_screen_text

    描述： 读取当前屏幕上的文字
    参数： region (可选, 指定区域)
    返回： 文字列表 + 置信度

2.  detect_objects

    描述： 检测当前画面中的物体
    参数： source (screen/camera, 默认 screen)
    返回： 物体列表 + 置信度 + bbox

3.  read_camera_text

    描述： 读取摄像头画面中的文字
    参数： 无
    返回： 文字列表 + 置信度

约束：

-   工具调用必须经权限校验 (PermissionChecker)
-   工具失败返回结构化错误, 不抛异常
-   工具描述使用中文 (Agent Brain 系统提示为中文)

------------------------------------------------------------------------
任务 P1：

配置管理

配置项 (添加到 backend/config.py)：

-   perception_enabled (默认 false)
-   perception_ocr_enabled (默认 false)
-   perception_ocr_engine (默认 "rapidocr", 可选 "paddleocr")
-   perception_ocr_lang (默认 "zh")
-   perception_detection_enabled (默认 false)
-   perception_detection_engine (默认 "yolov8n", 可选 "yolov5n")
-   perception_detection_conf_threshold (默认 0.5)
-   perception_detection_nms_threshold (默认 0.45)
-   perception_max_image_size (默认 1920, 超过则缩放)
-   perception_test_mode (默认 false, 由 YHLZ_PERCEPTION_TEST_MODE 控制)

禁止硬编码。全部从环境变量加载。

------------------------------------------------------------------------
任务 P1：

权限扩展

在 VisionPermission 中新增字段：

-   perception_enabled: bool = False
-   ocr_enabled: bool = False
-   detection_enabled: bool = False

校验逻辑 (PermissionChecker 扩展)：

-   perception_enabled=False 时, 拒绝所有 perceive 请求
-   ocr_enabled=False 时, 拒绝 ocr 类型请求
-   detection_enabled=False 时, 拒绝 detection 类型请求

约束：

-   不破坏 Foundation V1.0 既有 PermissionChecker 行为
-   新增字段有默认值, 旧配置文件兼容

------------------------------------------------------------------------
任务 P1：

日志扩展

复用 VisionLogger, 新增事件类型：

-   perceive_start
-   perceive_success
-   perceive_fail

字段扩展：

-   perception_types (List[str]): 本次调用的 Adapter 类型
-   ocr_count: int
-   detection_count: int

约束：

-   不修改 Foundation V1.0 既有 VisionLogger 接口
-   通过 metadata 字段携带感知特定信息
