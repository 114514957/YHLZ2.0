# 1. AI伙伴项目定位

## 产品定位

YHLZ AI伙伴不是普通 Agent。

不是：

- 单次任务执行器
- 聊天机器人
- 工具调用集合

而是：

 一个具有长期身份连续性、关系能力、经验积累、安全成长能力和逐步创造能力的智能伙伴系统。

# 8. Reflection Engine

## 功能目标

从 Experience 中提取：

- 长期模式
- 行为规律
- 失败原因
- 改进方向


---

## 输入

Experience Records


---

## 输出

Reflection Report


格式：

```json
{
  observation,
  evidence[],
  pattern,
  risk,
  suggestion,
  confidence0.0
}
```

---

# 9. Pattern Discovery 模块


## 目标

发现跨经历规律。


例如：

输入：

多次交互记录。


发现：

```
用户连续多次要求工程化输出

↓

形成偏好模式

↓

未来默认提供结构化方案
```


---

## 限制

禁止：

单次事件形成长期规则。


必须考虑：

- 样本数量
- 时间跨度
- 重复程度
- 反例


---

# 13. Confidence Engine


所有 Experience 必须拥有：

```
confidence
```

---

评估因素：

- 信息来源可靠度
- 重复出现次数
- 结果一致性
- 是否存在反例
- 时间稳定性


---

# 14. Evidence Manager


负责：

保存经验依据。


每条重要经验必须关联：

- 来源事件
- 时间
- 结果
- 证据


---

# 15. Contradiction Detector


目标：

发现经验冲突。


例如：

经验A：

```
用户喜欢简短回答
```


经验B：

```
用户喜欢详细工程方案
```


不能简单覆盖。


应该生成：

```
Context-dependent Experience

场景相关经验
```

---

# 16. Reality Check


所有成长建议必须回答：


```
1. 来源是什么？

2. 证据是什么？

3. 是否重复？

4. 有没有反例？

5. 是否值得影响未来行为？
```
