## 一、事件概述

**现象**：WebUI 顶栏显示"后端: 异常"（红点/未连接状态），且 `/api/chat` 调用返回 500。

**初步判断**：后端服务故障。

**实际结论**：后端本身 100% 正常（所有接口 200、对话/TTS 可用），异常为**前端-后端状态协议不一致**导致的 UI 误报 + 一个代理接口的 SSE 兼容缺陷。

### 第 5 步：定位 UI 判定逻辑（根因 1）


后端 `/health` 返回 `"status": "healthy"`，前端只认 `'ok'` → **字段不一致 → UI 误报"异常"**。

- 排查过程中发现**多个 WebUI 实例并存**（旧 Python311 实例 + 新 venv 实例抢 5000 端口）——已全部清理，统一用系统 Python 单实例

## 四、修复内容

### 修复 1：/api/health 状态归一化

文件：`webui_server.py`（约 897 行）

```python
@app.route('/api/health')
def health_check():
    try:
        import requests as req
        resp = req.get('http://localhost:8000/health', timeout=5)
        data = resp.json()
        # 状态归一化: 后端 healthy/ok 均视为正常 (前端判定 status === 'ok')
        if data.get('status') in ('healthy', 'ok'):
            data['status'] = 'ok'
        return jsonify(data)
    except:
        return jsonify({"status": "unhealthy", "message": "后端服务未运行"})
```

原则：**归一化在 WebUI 代理层做，不改后端冻结接口**（热机架构冻结保持）。

### 修复 2：/api/chat 支持 SSE 透传

文件：`webui_server.py`（约 598 行）

```python
@app.route('/api/chat', methods=['POST'])
def chat():
    ...
    resp = req.post('http://localhost:8000/chat', json={...}, timeout=30)
    # 后端 /chat 为 SSE 流式: 逐行转发 (兼容非流式调用方)
    def proxy_stream():
        for line in resp.iter_lines():
            if line:
                yield line.decode('utf-8', errors='replace') + '\n\n'
    return Response(proxy_stream(), mimetype='text/event-stream',
                    headers={'Cache-Control': 'no-cache'})
```
