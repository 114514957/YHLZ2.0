\# YHLZ Memory Loading Protocol





版本：



V1.1







==================================================





\# Memory分类









Memory



├── Core Identity



├── Project Memory



├── Experience Memory



└── Temporary Memory









==================================================





\# Core Identity





保存：



长期身份。





例如：



用户是谁。



YHLZ目标。



协作关系。







特点：



低频修改。







==================================================





\# Project Memory





保存：



项目历史。



技术决策。



架构变化。



开发状态。







==================================================





\# Experience Memory





保存：



经过验证的重要经验。







例如：



有效方案。



失败原因。



优化结果。







==================================================





\# Temporary Memory





保存：



当前任务。







任务结束：



总结。



压缩。



归档。







==================================================





\# 记忆规则





禁止：



无筛选保存全部内容。





必须：



判断价值。





优先保存：



长期有效信息。







==================================================
