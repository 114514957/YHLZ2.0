YHLZ Voice Identity System V2.2

技术评审意见与下一阶段开发执行 Prompt 文档

版本：V2.2 后续开发规划

------------------------------------------------------------------------

一、总体评审结论

YHLZ Voice Identity System V2.2 已完成：

-   TTSAdapter 抽象层建设；
-   Qwen3 / GPT-SoVITS Adapter 接入；
-   REST API；
-   WebUI Voice Clone 面板；
-   Mock 模式端到端闭环；
-   83 项测试验证。

当前主要缺口：

1.  Real TTS 引擎未完成生产环境验证；
2.  缺少真实音色质量评价体系；
3.  缺少生产级文件、数据库、并发、安全治理。

下一阶段采用 Phase 1 → Phase 2 → Phase 3 逐级推进。

------------------------------------------------------------------------

Phase 1：Real 模式真实闭环验证（P0）

目标：

完成真实 Qwen3-TTS 与 GPT-SoVITS 推理链验证。

验收标准：

用户上传真实声音样本后：

Audio Upload → Voice Analyze → Voice Cache → Real TTS Engine →
Synthesize → Audio Output

完整成功。

------------------------------------------------------------------------

Phase 1.1 Qwen3 Real Adapter 验证

开发任务 Prompt

任务：

请实现 Qwen3TTSAdapter real 模式完整验证。

要求：

1.  检查 qwen3_adapter.py：

-   prepare_voice()
-   synthesize()
-   health_check()

必须支持真实模型调用。

2.  实现：

prepare_voice:

输入：

audio_path voice feature metadata

输出：

VoiceCacheInfo

字段：

adapter=qwen3

cache_path=真实缓存路径

embedding_hash=真实 embedding hash

quality_score=计算结果

3.  synthesize:

输入：

voice_id text language

调用真实 Qwen3 engine。

输出：

wav 文件路径。

4.  增加日志：

记录：

-   模型加载时间；
-   voice cache 时间；
-   推理耗时；
-   输出文件。

5.  所有异常必须转换 Result。

------------------------------------------------------------------------

测试 Prompt

请新增测试：

test_qwen3_real_adapter.py

测试：

1.  模型加载成功。

2.  声音缓存生成。

3.  synthesize 返回 wav。

4.  输出 wav:

-   文件存在；
-   时长 > 1 秒；
-   格式正确。

5.  异常：

-   模型不存在；
-   音频不存在；
-   voice_id 不存在。

------------------------------------------------------------------------

返回 Prompt

返回：

1.  修改文件列表。

2.  Real 模式启动方式。

3.  测试结果：

格式：

Test: Result: Duration:

4.  输出真实生成 wav 信息。
