YHLZ Voice Identity System V2.2 开发实现 Prompt

目标

基于 V2.1 已完成的 Voice Clone Pipeline，实现真实端到端声音克隆能力。

当前 V2.1 已完成: - VoiceClonePipeline - audio_validator -
voice_analyzer - Result[T] - Service.clone_voice() - Registry/Cache
接入 - 单元测试与回归测试

V2.2 目标: 1. 接入真实 TTS Adapter 2. 暴露 REST API 3. 增加 WebUI
克隆管理界面 4. 完成真实音频 → VoiceProfile → 可调用 TTS 的闭环

------------------------------------------------------------------------

一、TTS Adapter 接入

新增模块

backend/voice_identity/adapter/

新增:

tts_adapter.py

职责:

-   定义统一 TTS 接口
-   屏蔽 Qwen3 / GPT-SoVITS 差异
-   不允许 Pipeline 直接调用具体引擎

接口:

class TTSAdapter:

    def prepare_voice(
        self,
        audio_path: str,
        feature: VoiceFeature,
        metadata: dict | None = None
    ) -> Result[VoiceCacheInfo]


    def synthesize(
        self,
        voice_id: str,
        text: str,
        language: str = "zh"
    ) -> Result[str]

------------------------------------------------------------------------

二、Qwen3 / GPT-SoVITS Adapter

新增:

adapter/qwen3_adapter.py

adapter/gpt_sovits_adapter.py

要求:

-   实现 TTSAdapter
-   支持 mock 模式
-   支持真实模型路径配置
-   不修改 Pipeline

配置:

voice_clone_config.json

三、Pipeline 升级

修改:

clone_pipeline.py

新增:

clone_voice(…, auto_prepare=True)

流程:

audio | validate_audio | analyze_voice | manager.create_voice |
tts_adapter.prepare_voice | registry.register | cache.verify | return
CloneResult

新增字段:

CloneResult:

-   adapter
-   cache_path
-   embedding_hash
-   quality_score

------------------------------------------------------------------------

四、REST API

文件:

backend/main.py

新增:

POST /voice/clone

参数:

multipart/form-data

audio: wav/mp3

name: voice name

engine: qwen3/gpt_sovits

voice_id: optional

返回:

成功: { “voice_id”:““,”status”:“ready”, “warnings”:[] }

失败: { “error”:““,”stage”:“validate/analyze/cache” }
