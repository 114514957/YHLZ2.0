## 3. 缓存内容 (三类)

| 缓存类型 | 存储位置 | Qwen3 | GPT-SoVITS |
|---------|---------|-------|-----------|
| embedding 缓存 | `voice_cache/<vid>/embedding.pt` | speaker x-vector | N/A |
| engine cache | 内存 (_voice_caches) | in-memory entry | N/A |
| prompt cache | `voice_cache/<vid>/prompt.pt` | 完整 prompt 对象 | N/A |
| 权重路径 | voice_models.model_path/cache_path | model_path=ref_audio | sovits/gpt 路径 |

永久缓存根目录: `backend/data/voice_cache/`

## 4. VoiceCacheManager API

| 方法 | 阶段 | Qwen3 行为 | GPT-SoVITS 行为 |
|------|------|-----------|----------------|
| prepare(vid, ref) | PROCESSING | load_voice 提取 → save 磁盘 → 登记 | 登记 weight 路径 |
| save(vid) | — | save_voice_cache_to_disk | N/A |
| load(vid) | ACTIVE | load_voice_cache_from_disk + loaded=1 | change_weights + loaded=1 |
| unload(vid) | DISABLE | clear_voice (内存) + loaded=0 | loaded=0 |
| remove(vid) | DELETE | clear + rmtree + 删记录 | 删记录 |
| exists(vid) | — | metadata.json 存在? | voice_models 有记录? |

## 5. M0 兼容性

### Qwen3 多 voice cache (M0.1 + M0.6)
CacheManager 经 Qwen3TTSAdapter 调用 M0 已有能力:
- `adapter.load_voice(vid, ref, x_vector_only_mode=True)` — 提取说话人特征 (M0.1)
- `adapter.save_voice_cache_to_disk(vid, dir)` — 持久化 embedding.pt + prompt.pt + metadata.json (M0.6)
- `adapter.load_voice_cache_from_disk(vid, dir)` — 恢复 (含轻量 _RestoredPrompt 重建, M0.6)
- `adapter.clear_voice(vid)` — 清内存 (M0.1)

磁盘结构与 M0.6 完全一致: `<voice_id>/metadata.json + embedding.pt + prompt.pt`

### GPT-SoVITS 缓存 (M0.2)
- 权重路径登记于 voice_models (model_path=sovits, cache_path=gpt)
- load 调用 `adapter.change_weights(sovits, gpt)` 热切换 (M0.2 GPTSovitsAdapter.change_weights)
- 不破坏 GPT-SoVITS "权重决定声音" 语义

## 6. 解耦设计: duck-typed 适配器

cache_manager.py **不 import backend.tts** (AST 校验通过), 通过构造函数注入适配器实例:
```python
VoiceCacheManager(qwen3_adapter=..., gpt_sovits_adapter=..., db=...)
```
仅依赖适配器方法签名 (鸭子类型), 保持 voice_identity 与 tts 物理解耦。
voice_identity 核心层 (profile/registry/manager) 经 CacheManager 间接访问引擎, 永不直接调用 GPT-SoVITS/Qwen3。

imports: `__future__ / hashlib / logging / shutil / pathlib / typing / voice_identity.database / voice_identity.models`

## 7. 生命周期对齐 (与 V1.4 Manager)

| Manager 操作 | CacheManager 调用 | 缓存效果 |
|-------------|-------------------|---------|
| create (PROCESSING) | prepare | 提取+持久化 |
| activate (ACTIVE) | load | 内存加载 |
| disable (DISABLED) | unload | 清内存, 留磁盘 ✅ |
| delete 软删 | (无) | 保留缓存 ✅ |
| delete 硬删 | remove | 全清 ✅ |

符合 V1.5 约定: **删除清缓存, 禁用保留缓存**。

## 8. 测试结果

- ✅ Qwen3 prepare: 提取+磁盘文件 (metadata.json/embedding.pt) + voice_models 记录 + hash
- ✅ load: 磁盘→内存恢复 + loaded=True
- ✅ unload: 清内存 + 磁盘保留 + loaded=False
- ✅ save: 内存→磁盘
- ✅ remove: 磁盘+内存+记录全清
- ✅ GPT-SoVITS: 权重登记 + change_weights 调用
- ✅ Manager 集成: disable 保留缓存, 硬删清缓存, 软删保留缓存
- ✅ AST: cache_manager 无 tts import

## 10. 遗留 / 生产集成注意

- 生产环境需注入真实 `Qwen3TTSAdapter` (M0.2) 与 `GPTSovitsAdapter` (M0.2) 实例

- GPT-SoVITS load 需要 Gradio 服务在线 (change_weights 经 HTTP)
- 这些引擎就绪性由 Service 层 (V1.6) / 启动流程保障, 不在 V1.5 范围
