## 4. select_voice 单激活策略

```
当前选中 A (active)  ──select(B)──►  A: active→ready (deactivate, 保留可发现)
                                       B: →ready (register) →active (activate)
                                       schema_meta.selected_voice = B
```

- 不存在/已删除 → VoiceIdentityServiceError
- 非 ready/active → 先 register (→ready) 再 activate
- 旧选中 active → deactivate (active→ready) + cache.unload, 保留可发现
- 选中状态持久化到 `schema_meta` 表 (key='selected_voice'), 重启可恢复
- 删除选中声音 → 自动清除选中状态

## 5. 工厂方法 create_default()

生产装配一键完成:
```python
svc = VoiceIdentityService.create_default(
    qwen3_adapter=qwen3_adapter,   # Qwen3TTSAdapter (M0.2)
    gpt_sovits_adapter=gpt_adapter, # GPTSovitsAdapter (M0.2, 可选)
)
```
装配链: db → store → registry → cache(adapters) → manager → service
适配器缺省 None 时 CacheManager 静默跳过缓存操作, Service 仍可运行 (待引擎就绪后注入)。
