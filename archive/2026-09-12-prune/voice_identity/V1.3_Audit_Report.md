## 3. VoiceRegistry API

| 方法 | 签名 | 行为 |
|------|------|------|
| register_voice | (voice_id) → VoiceProfile | 注册: creating/disabled→ready; ready/active 幂等; deleted/missing 抛错 |

| list_system_voices | () → List | 系统声音便捷方法 |
| is_registered | (voice_id) → bool | 是否可发现 |

## 4. 设计决策: 无独立索引存储

**方案**: 以 `profile.status` 作为"可发现"信号, DB 即索引。
- 可发现状态 `DISCOVERABLE_STATUS = ("ready", "active")`
- register = 转移到 ready; unregister = 转移到 disabled
- get/list 查询时过滤 status

**理由**:
1. 避免维护额外索引表与 profile 状态不一致
2. DB 单一真相源, 重启后状态保留 (status 持久化)
3. 复用 V1.2 状态机校验, 不绕过业务规则
4. "声音索引" = DB 索引 (idx_voice_models_voice_id 等), 无需重复造索引

## 5. 与约束对齐

| 约束 | 实现 |
|------|------|
| 不直接调用 TTS | registry.py 仅 import logging/typing/voice_identity; AST 校验通过 |

| 支持用户/系统/角色声音 | type=character/user/system + 三个便捷查询方法 |
