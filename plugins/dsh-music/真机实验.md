# dsh-music 真机实验清单

> 目的：证明插件在**真的 DSH** 里被加载、四个工具能被模型调用、CLI 能落到底。
> 我一直跑不了这一步——沙箱账号对 `~/.dsh` 只有 RX 权限（见文末），装和启动都写不进去。

---

## 0. 先确认一件事（10 秒）

```cmd
icacls "%USERPROFILE%\.dsh" | findstr CodexSandbox
```

如果看到 `CodexSandboxUsers:(OI)(CI)(RX)`——那就和我看到的一样：**沙箱只能读**。安装必须由你在自己的终端里跑。

---

## 1. 安装（选一条）

**A. 双击（推荐）**

```
YH\plugins\dsh-music\一键安装.cmd
```

**B. 命令行**

```powershell
cd C:\Users\ACE_WAN——PROJECT\YHLZ\YH
node plugins\dsh-music\install.mjs
```

**C. 装进 headless profile**（想用命令行做实验时用这条）

```powershell
node plugins\dsh-music\install.mjs --profile headless
```

装完**重启 DSH 或按 F5**（客户端模块图是页面加载时的快照）。

---

## 2. 静态验证（不用开 DSH）

```powershell
node plugins\dsh-music\verify.mjs
```

期望输出：

```
OK    dependency row
OK    bundle row
OK    node_modules junction
OK    cli answers — 1 song(s) in the sample

WIRING OK — now boot DSH (GUI: press F5) and ask: 列一下歌库
```

任何一行 `MISS` 都说明没装好，把整段输出发我。

---

## 3. 四个实验（GUI 路线）

装好后在对话里依次说，记录**工具卡返回**（截图或复制文字）：

| # | 你说 | 期望 |
|---|---|---|
| A | 列一下歌库 | 调用 `music_list`；返回 59 首，第一行是《战友文工团_-_学习雷锋好榜样（元亨翻唱·清亮嗓·SeedVC）》 |
| B | 看看《洛天依-一花依世界》的详情 | 调用 `music_info`；给出 `...\YH\音频素材\翻唱产出\...wav` 的**绝对路径**，且不出现"索引里是旧路径" |
| C | 放一下第 3 首 | 调用 `music_play`；返回"正在播放…"或"交给系统默认播放器"，扬声器出声 |
| D | 把第 3 首发我 QQ | 调用 `music_send`；返回"已发送：《…》"，QQ 收到文件。NapCat 不在线时应返回失败原因（不是静默） |

**判定**：

- A/B 通过 = 插件被加载 + CLI 通了；
- C 通过 = 本机播放链路通；
- D 通过 = NapCat 链路通（和元亨自己的 `song_send` 同一条路径）；
- 任何一步"模型没调工具、直接回答"也算失败——贴回来我看是不是工具描述不够明确。

---

## 4. 命令行路线（不用 GUI）

```powershell
dsh headless "列一下歌库，用 music_list 工具"
```

它会启动一个 headless 会话、跑一轮、打印结果。把输出整段贴回来即可。
（`dsh headless` 需要 `headless` profile 里也有这个插件，见 §1-C。）

---

## 5. 失败时给我什么

1. `node plugins/dsh-music/verify.mjs` 的完整输出；
2. `%USERPROFILE%\.dsh\profiles\desktop\package.json` 里 `dsh-music` 那两行（`dependencies` 和 `bundles`）；
3. DSH 的设置 → 插件管理里有没有 `dsh-music` 这一行（截图更好）；
4. 如果是工具调用失败：工具卡上的错误文字。

## 附：为什么我这边装不了

```
icacls "%USERPROFILE%\.dsh"
  ACE_WAN\CodexSandboxUsers:(OI)(CI)(RX)      ← 我的进程在这个组里，只读
  NT AUTHORITY\SYSTEM:(I)(OI)(CI)(F)
  BUILTIN\Administrators:(I)(OI)(CI)(F)
  ACE_WAN\ACE_WAN——PROJECT:(I)(OI)(CI)(F)
```

而且不只是我的脚本——DSH 自己的 CLI 也一样：

```
> dsh headless --dump-config
Error: EPERM, Permission denied: ...\.dsh\profiles\headless\.dsh-module-fallback
```

**连 DSH 启动自己都要写这个目录**，所以"真机实验"这一步只能在你这边跑。
