## 1. 逐方向：参照 · 可借鉴点 · 可行性

### 1.1 QQ 接入层（OneBot）
- **NapCatQQ** — https://github.com/NapNeko/NapCatQQ （10.8k★；NTQQ 协议端；OneBot 11；YHLZ 已用）。
- **Lagrange.Core** — https://github.com/LagrangeDev/Lagrange.Core （另一协议端，参考）。
- **AstrBot** — https://github.com/AstrBotDevs/AstrBot （全平台 Agent 聊天机器人平台；官方适配 NapCat；**事件总线 + 消息事件流水线 + 插件化**）。
- 可借鉴：AstrBot 的**事件总线/流水线**分层，用于整理 QQ 入站→身份→会话→工具的接线。
- 判定：✅ 可行；YHLZ 保留 `qq_bot` 单桥，借架构思想而非换框架。

### 1.2 可靠投递 / outbox / 幂等
- **模式**：Transactional Outbox、幂等键、at-least-once + 去重、租约（lease/epoch）防旧 worker 提交。
- **可参照库**：huey（SQLite/Redis 任务队列，https://github.com/coleifer/huey ）、dramatiq、rq（Redis）。
- 与 YHLZ 映射：`qq_delivery` 状态机（queued/sending/confirmed/rejected/retryable/**unknown**/expired）+ `before/after_send` + `qq_outbox.peek/ack` 已具雏形。
- **缺口=跨进程/跨重启**（JSONL 仅进程内锁、unknown 未持久）。建议：outbox 落 **SQLite 单事务 + 租约**，复用 `turn_evidence` 的 `effect_id`。
- 判定：✅ 可行；不引入 huey 作为运行时（避免多依赖），**照抄语义**。

### 1.3 长期记忆（L1/L2/L3 + 复盘队列）
- **mem0** — https://github.com/mem0ai/mem0 （66.6k★, Apache-2.0）。2026-04 新算法：**单次 ADD-only 提取**（一次 LLM 调用、不 UPDATE/DELETE、记忆累积不覆盖）、**实体链接**、**多信号检索**（semantic + BM25 + entity 融合打分）、**时间推理**（当前/过去/计划的时间实例排序）。基准：LoCoMo **92.5**、LongMemEval **94.4**、BEAM(1M) 64.1。（托管平台含私有优化，开源自评"方向一致、数值未必相同"。）
- **Letta（原 MemGPT）** — https://github.com/letta-ai/letta （25k★）。有状态 agent + 自管理记忆（core/archival 分层、**记忆即工具**）。
- 与 YHLZ 映射：mem0 的 **ADD-only 累积**与 YHLZ「记忆永不静默删除，只冷存/归档/版本化」**同源**；**多信号融合**对应 YHLZ kw+vector 双路；**时间推理** 正是 R4 所缺（`valid_from/valid_to/supersedes`）。Letta 的**分层+记忆即工具**对应 L1/L2/L3 + 记忆工具。
- 判定：✅ 范式可行，**照抄范式不引运行时**（二者默认依赖云 LLM/服务）。

### 1.4 本地模型 / 工具调用
- **Gemma** — https://deepmind.google/models/gemma/ ；HF `google/gemma-*`（YHLZ 用 gemma-4-E4B + QAT）。
- **llama.cpp** function calling / `--jinja`（YHLZ 用 b10991）。
- 可借鉴：工具调用稳定性取决于**模板与上下文结构**（YHLZ 0569：两条 system → 工具调用失效；0564：schema 注入压人格）。
- 判定：✅ 已在用；约束=训练/推理模板逐字一致 + 单 system + 工具面按需提供。

### 1.5 知识抽取
- **qq-chat-exporter (QCE)** — https://github.com/shuakami/qq-chat-exporter （YHLZ 已用）。
- 可借鉴：RAG 式 chunk/entity/metadata + 游标断点（YHLZ `qq_extract_topic` 已有游标）。
- 判定：✅ 自建即可。
