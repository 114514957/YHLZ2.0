## 2. L1 瞬时（批 1 采纳）

- 保留最近 3-5 轮完整对话（语音回合=一次 ASR final→LLM→TTS 完整往返）；更早内容按"结构化摘要压缩"（Summary Compression），摘要保留：核心实体、结论（Conclusions）、待办项（Action Items）。
- 禁止 Naive Truncation（丢失关键信息）。
- 双闸门：轮数 5 上限 + token 预算（初值 2048，满载时先摘要后退龄）。
- 前缀缓存友好：系统模板+画像固定头（"先进始于计算，元亨开拓未来"+约束行），历史后置。

## 3. 记忆条目 schema（L2/L3c 草案）

```
id          : mem_<uuid8>          tier : L2|L3            type : fact|preference|event|decision
content_hash: sha256[:16]          正文不落盘（只存哈希+摘要）；原文只存对话上下文
summary     : 分层摘要（见 §3.1；不得为低重要性留空长文）
importance  : 1-10（云提取为候选初值；本地裁决者复核/覆盖，本地为准）
keywords    : [词]（中文 jieba 或以 FTS5 分词）
entities    : [人名/地点]
created_at / last_accessed / access_count
decay/weight: 状态字段（active|降权|cold|archive 由状态机维护，数值仅记录）
evidence_ref: 台账记录号 / turn_id / generation（来源互链）
version/status: 版本号 + OBSOLETE 链接（旧条目标失效区间；召回只取 current；支持回溯）
```

### 3.1 分层摘要（按重要性分级）

| importance | 摘要策略 |
|---|---|
| ≥8（高） | 详细摘要 ≤200 字：实体/论点/结论/待办/时间轴完整保留 |
| 4-7（中） | 短摘要 ≤80 字：要点概括 |
| ≤3（低） | 仅标签+哈希（可附一句话） |

## 5. 人格画像（批 1 结构定稿）

- golden=`memory/user_identity.md`+`collaboration_rules.md`+`yhlz_project_context.md`（只读）。
- 五维（仅作展示/蒸馏视图）：①性格量化（OCEAN 各 1-5，draft 显示）②沟通风格（一句话，如"简洁直白，先结论后展开"）③决策偏好（一句话）④核心价值观（2-3 锚点）⑤回复行为指令（一短段）。

## 6. 混合 LLM 的隐私闸（矛盾 5 消解，v4 定稿版——0138 修订）

**LLM 责任划分（本地粗筛优先、云端精细裁决；互不越权）**：
- **本地段（筛选/候选生成）**：候选提取、初筛（哪条值得留）、早期压缩——**本地轨优先**（Ollama），本地失败才云端兜底。
- **云端段（裁决/治理）**：按重要性标签的**裁决**（保留/降权/cold/archive 定级、最终 importance）——云端优先（DeepSeek API），云端失败才本地兜底。
- 任何一端失败：候选保留初值/活跃态，**绝不删除**；两端都不可用时候选队列冻结（恢复后补裁决）——宁可多留，不留丢。
- 一键全本地模式开关预留（关闭云段）——默认关闭。原 v3（云候选/本地裁决）由 0138 用户修订取代。

## 7. 参考吸收清单（NEKO/文档/其他）

- NEKO：分层渲染预算、outbox 幂等、facts 证据+重要性、向量可选降级、日志只留元数据（NDJSON 计数/哈希）。
- 文档：五层召回仅"工具型"启用；RRF k=60；时序加权 0.5^(days/half_life)；版本回溯。

## 8. 讨论确认结论（0118-0119）

1. ✅ L1 瞬时双闸（5 轮 + 2048 token，满载先摘要压缩后退龄）——采纳。
2. ✅ 提取/积累策略：记忆提取可走云端照常积累；**录入时打重要性标签；去留裁决必须由本地模型按重要性标签执行**（云=候选初值，本地=裁决者）。
