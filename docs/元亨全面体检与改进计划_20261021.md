## 8. 根因（按影响排序）

1. **监督权被当成可杀资源**：`gpu_window` 直接 kill watchdog，`close_window` 又把它挂到调用方；daemon 重启 → watchdog 死；唱歌失败 → 空栈。
2. **多套启动/重启路径**：boot bat、workbench bat、全家桶、test bat、`YHLZ_daemon_once` 任务、`yhlz_daemon_restart.bat`；没有单一 supervisor。
3. **可选依赖不降级**：Ollama 永远 500，launcher 仍每轮等/记；启动和日志被拖。
4. **没有上下文预算**：709 次 8k 溢出；回退压缩只覆盖 fallback，不覆盖所有 8081 调用方。
5. **没有干净基线/临时隔离**：1869 untracked、1703 根 tmp、四 venv、依赖冲突；任何重构都没有回滚点。
6. **单体边界**：38 路由的 console_server 把 UI/API/音频/控制混在一起；改动回归成本高。
7. **GPU 没有统一调度**：Gemma/TTS/Seed-VC 各自抢 8 GB，靠杀进程解决。

## 9. 改进计划

### P0 止血（1-2 天，先做）

> 外围学习新增一条 **P0.5 推理微结构**（在 P0 之后、P1 之前，1-2 天）：前缀稳定+KV 预热、30ms 文本平滑、延迟闸门、打断轮次完整性、本地回环代理免疫。详见 [外围学习技术评估_20261021.md](./研究/外围学习技术评估_20261021.md)。P0 未完成前不做 P0.5，避免重启污染测量。

| # | 动作 | 验收 |
|---|---|---|
| P0-1 | 单一 supervisor：watchdog 由 boot/launcher **独立**启动；`gpu_window` 不再 kill/spawn 它，只向 supervisor 请求“暂停/恢复 LLM” | daemon 重启后 watchdog 仍在；唱歌失败后 8081 自动恢复 |
| P0-2 | 清掉遗留重启路径：`YHLZ_daemon_once` 保持 Disabled/删除；`yhlz_daemon_restart.bat` 删除或改成调用统一 supervisor；boot/workbench/全家桶只保留一条实现 | 无第二个 8321 启动者；任务列表无 YHLZ 自启项 |
| P0-3 | Ollama 移出关键路径：launcher/health 将其标 optional，不等待、不每轮刷 false | 启动日志不再出现 1,261 次 ollama false |
| P0-4 | 统一 8081 token 预算：所有调用方（memory/reflection/persona/TTS/工具）走同一估算/截断；超 7000 拒绝或压缩 | 24h 内 `exceeds context size` = 0 |
| P0-5 | GPU 协调器：唱歌/Seed-VC 申请独占窗口；窗口内暂停 LLM；结束/异常都通过独立 supervisor 恢复；不允许直接杀 watchdog | 连续 3 次唱歌后 8081/8321 仍健康 |
| P0-6 | 日志：每个服务独立文件 + 轮转（大小/天数）；daemon 当前启动后无业务日志要修 | 每个服务有当日日志、可追踪一次重启 |
| P0-7 | 仓库止血：`.gitignore` 加 `/tmp*/`、测试临时、一次性日志；删除 1,703 个根 tmp；创建一次干净基线 commit/tag | `git status` 无核心未跟踪文件；可回滚 |
| P0-8 | 秘密收口：`YHLZqwen-apiKey-.csv`/`.env` 移到受保护目录（ACL 仅当前用户）或删除未用文件；确认不被备份/日志采集 | 仓库根无明文 key；引用处改用环境变量/凭据文件 |
| P0-9 | 测试隔离：`TEMP/TMP` 指向 `cache/tmp`；所有 `mkdtemp` 加 cleanup；禁止测试改线上 `qq_management` | 全量测试不再产生根 tmp、不再改线上配置 |
