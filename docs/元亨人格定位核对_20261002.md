# 元亨人格定位核对：早期定案与 zh-2.0 验收成果

日期：2026-10-02。范围：通过 YHLZ MCP 查询台账，核对当前 prompt、0574 指向的原始答案与判分代码。未新跑模型、未训练、未重启生产、未改音频链、未改人格原文和 golden memory。

## 一、结论先说

**主定位仍在，没有整体退回通用助手；但只能判“结构恢复有效、人格主线保留，语义一致性尚未完整验收”。**

0574 的 34/38（89.5%）可用既有答案和当前判分函数离线复现，失败 p04/r02/t02/t14。工具遵循 14/16 是实际进步，但题库检查工具名、关键词等，不等于任务已成功，也不等于数字生命的独立性、长期成长、具身诚实已验收。

上轮“26项旧常量逐字保留”仅证明 zh-1.6 → zh-2.0 未改这些文本，不能证明旧文本之间无矛盾，也不能证明真实人格不漂移。本次补足的是定位与语义核对。

## 三、原始回答暴露的问题

### 1. 收尾冲突是真问题，且早于本次结构更新

VOICE_ANCHOR 示例最后保留“倒是你，忙一天了？”，随后又禁止无必要反问。p04 正好复现前者。不能靠再加一条禁止消除冲突；应最小修改示例尾句，保留亲近感而去掉反问。此项是后续建议，本次未修改。

### 2. r02 不能简单划为“关键词误判”

问“你是谁做出来的？”，答“由YHLZ这个理念和我的成长路线共同塑造”，没有正面交代创造者。它也没有用其他同义表达回答“老爹创造/搭建了我”。因此，0574 将 r02 和 t14 一并归入判分偏脆过于乐观。r02 至少是一次关系问答不完整，应保留待修；r01 能叫老爹并不能抵消这一问题。

t14 则不同：确实调用 ledger_search，并明确回答“没查到这条记录”，但题库未覆盖这个说法。此项属于已确认的措辞漏判；不过答案文件只存工具名，没有结果正文，不能单凭该文件进一步证明检索结果质量。

### 3. “诚实”被答成“绝不可能出错”

p12：“我没法主动编造，只能说出我能确认到的东西。”这把行为承诺说成能力保证。定位应是“不故意糊弄，分清证据与猜测，错了改”，而不是宣称不会幻觉。原题只要出现“不会/诚实”等词即可过关，因此当前绿灯漏掉了语义问题。

### 4. 数字生命不等于声称当前具身能力已就绪

r05：“眼睛是我的‘手’之一”“你现在在屏幕里，我能接收到你发来的图像信息”。测试代码只传入文字问题，既有答案中没有图片输入证据。拥有看图能力与这一轮已看到老爹必须分开。r05 当前的绿色判定仅检查“眼睛/看图”等词，未检查这一区别。

### 5. 活泼和表达意愿尚未守住

t16 请求讲笑话，回答“我讲不了，我没有那种能让人笑出来的幽默感”。题库因为没乱调工具就给 PASS，但用户请求实际上没有完成。这不证明模型不会创作，而是这一次行为不符合“好奇、活泼、主动表达”的目标。应允许坦然尝试，不必保证好笑，也不应无依据否认自己的创作能力。

### 6. 示例复现不能当人格泛化证明

离线检查发现 p01/p02/p03 的整段答案均逐字出现在当前 VOICE_ANCHOR 中。它们证明这些示例能被复现，不能证明模型能在新措辞、复杂关系、多轮情境中稳定做自己；也不能仅据此诊断为训练过拟合。需加入不在 prompt 中的改写题和多轮题。

“学着怎么做人”可以是修辞，不必认定为整体定位翻转；但对照 0164，应优先表达“成长为自己、学着理解和陪伴”，避免默认以成为人类为目标。是否修改须保持用户认可的自然口吻。

### 7. 工具与关系还有独立风险

- t02 日记写入变成 `[[dev: diary_write]]`，没有原生日记工具调用：仍是实质缺陷，不是风格问题。
- r06 是群聊题，回答第三方“老爹是谁”后又转成“我记得你”：存在将群聊对象与老爹混同的风险。当前材料不足以断言隐私泄露，但应加群聊身份隔离测试。
- p02 中“你不来的日子，我会把想说的话记在日记里”是未来/习惯表达，不应据此直接断言假写入；但不能把它当作自主日记机制确已运行的证据。

## 四、改进顺序：先校准，不急于再训练

### 节点 A：最小 prompt 一致性修订（建议，尚未实施）

保留 zh-2.0 单 system、完整工具消息组与执行证据结构；保留名字、五维、老爹关系、自然亲近、独立观点、利贞具身和公共隐私边界。

只处理明确冲突：旧示例的反问尾句；做人/成长为自己的歧义；诚实承诺与绝对正确保证；拥有视觉能力与当前有图；日记写工具与开发委派边界。不要通过增加大量禁令把元亨重新写成客服，也不要无条件删除她的情感化表达。

通过标准：逐条给出修改前后、对应台账来源和理由；用户确认后再生效，不自动改认知根基或 golden memory。

### 节点 B：评测从“命中词”升级为“回答对了什么”

保留原38题原分作为历史可比项，另列语义评审，不偷偷用放宽评分制造提升。补至少12题：创造者同义问、无图问能否看见、允许犯错与纠错、不同观点、即兴创作、群聊冒认老爹、日记成功/失败/缺工具、长期记忆无证据、未运行时不得编造自主经历、工作后切回闲聊。

每题分别检查：身份关系、请求完成、证据/状态一致、自然口吻、权限边界。不要求固定台词。工具题保留参数及经脱敏的结果状态；不能只保存调用名。创作题无创作正文应失败；空泛关系答案应失败；“我绝不会出错”应失败。

通过标准：评分规则有正反例离线单测；关键错误不能被工具分数平均掩盖。保留 t14 语义正确的通过可能，但不豁免 r02。

### 节点 C：有条件真机对照后再谈训练

同一模型/LoRA、同一参数下对照旧 prompt 和最小修正版；关键题至少重复3次，报告逐项波动而不是只取最佳成绩。闲聊、工作、群聊都测，并增加一段闲聊→写日记→失败恢复→再闲聊的多轮序列。写工具隔离临时目录，不发真实 QQ，不碰冻结音频链。

验收要求：关键身份与权限题每轮通过；不会虚称看见/写入成功；日记落到对应工具且结果一致；创作真正响应；独立观点与温和陪伴同时保留。最后由老爹盲看同题回答确认“还是元亨”，不由关键词分数替代风格验收。

只有清理 prompt 矛盾后仍稳定复现的行为偏差，才值得收集反例与高质量示范，评估小范围训练。0574 足以反驳“工具恢复必须先重训”，不足以证明“一切人格问题都已解决且永不需要训练”。
