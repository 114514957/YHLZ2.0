# QQ 知识汇编 2026-09-14

## tech

- 针对人格五维（OCEAN）的调优建议，建议增强开放求新、轻微增强生动有度，同时略微降低神经质倾向，以提升适应性和探索性。
- 核心目标：用10k上下文窗口实现1M以上有效上下文长度
- SNN脉冲发放与STDP训练开销低，接近人脑神经元工作方式，属类脑计算
- 确定性编码器（记忆模块）查询召回率初期可达100%
- STDP难以实现延迟价值学习，实践中常无法收敛
- 随机初始化模型输出近似噪声，资格迹会强化多激活边而非有效边，相当于放大噪声；反向传播无此问题，但需层数少，表达能力受限
- 声纹区分实现难度大且可能增加延迟

## method

- 方案：联合训练LLM记忆模块与SNN，部署时冻结LLM，SNN继续用STDP更新权重
- 推理时异步用STDP在线更新SNN权重，LLM记忆模块提供输入模式与目标索引
- 确定性编码器效果不佳，改用trick解决梯度问题后换MLP更顺畅
- SNN若可微可直接让MLP顺SNN走梯度训练
- 学习节奏：1天速通snnTorch，2天出原型，3天规模化训练
