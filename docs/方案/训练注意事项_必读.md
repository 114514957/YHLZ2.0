# 训练注意事项（必读 · 台账 1211 同文）

> **每次训练前先看这一页。** 台账里的正式记录是 **1211**（`ledger_get 1211`）。
> 训练前还应跑一次自动校验：
>
> ```bash
> python tools/train_preflight.py --config <你的配置> --n-train <条数>
> ```
> 违反任何一条硬规则它都会**拒绝放行**。

## A. 数据（错一条全白跑）

| # | 注意 | 后果/依据 |
|---|---|---|
| 1 | **右侧截断**，保留开头 | 左侧截断会把 assistant 切光 → 标签全 `-100` |
| 2 | **全 `-100` 的样本丢弃** | 单批全坏 → loss = 0/0 = **NaN** |

### A2. **权重配比**（2026-11-14 v13 事故后新增，闸门会拦）

| # | 注意 | 依据 |
|---|---|---|
| 5a | **工具/格式类权重 ≥ 12%** | v13 只有 6.9% → 工具题 16 道挂 13 道，全用话糊过去 |
| 5b | **口述/口味类权重 ≤ 18%** | v13 给到 26.1%，挤掉格式类 |
| 5c | **单来源 ≤ 30%** | 防某一类再次垄断 |
| 5d | **只看条数会骗人**：v13 工具条数 900→836（-7%）看着正常，权重却从 8.9% 掉到 6.9% | 配方前跑 `measure_tool_weight_share.py` |
| 5e | **调权重用纯乘法** `w × k`；写 `max(w,1.0) × k` 会把低权重行全抬平（实测把工具类冲到 36%） |  |

## C. 实验设计（决定能不能归因）

| # | 注意 | 依据 |
|---|---|---|
| 13 | **一次只改一个变量** | v11 同改数据量与 lr → 无法归因 |
| 14 | **loss 不是优化目标** | 降幅与分数相关 **-0.15** |
| 15 | 不拿外部"loss 13–15"对比 | 我们 5.3 → 1.6，口径不同 |
| 16 | **先冒烟**：60 条×6ep、lr 1e-4，三条判据全过 | 我们长期跳过这一步 |

冒烟三判据：① loss 末值 ≤ 起点 60% ② 这 60 条能**逐字背出** ③ 与基座推理**明显不同**。
