# 技能申请：每周QQ知识拉取与提炼

触发场景：需要定期（如每周）将QQ群聊中的新知识点自动拉取并提炼到知识库时。

步骤：
1. 检查QQ知识拉取链路状态 (qq.status) → 确认导出链是否在线，并检查白名单群组和候选消息数量。
2. 拉取指定群组的消息 (qq.export) → 执行 `qq.export({'group_id': '...' })`，将最新群消息导入候选区。
3. 知识提炼与处理 (qq.process) → 执行 `qq.process({'max_items': '...' })`，对候选消息进行抽取、清洗和入库处理。
4. 结果反馈 → 报告执行状态、处理条数、知识库当前数量，并询问下一步操作（如生成汇编或主题总结）。
