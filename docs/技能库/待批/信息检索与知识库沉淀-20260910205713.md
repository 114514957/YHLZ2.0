# 技能申请：信息检索与知识库沉淀

触发场景：当用户要求先通过外部搜索（如 web_search）获取特定信息，然后将搜索结果结构化地存入知识库（如 kb_add）时。

步骤：
1. 识别用户意图：确定需要搜索的关键词/主题。
2. 执行搜索：调用 `web_search` 工具，传入关键词和必要的参数（如 limit）。
3. 接收搜索结果：获取搜索返回的摘要或详细信息。
4. 结构化存储：调用 `kb_add` 工具，将搜索结果整理成知识点，并指定知识库的类别（category）。
5. 确认与反馈：向用户报告搜索和存储的完成状态，并提供关键信息（如知识库编号）。
