# 《记忆改造技术资料》解读与 YHLZ 对照（2026-09-11）

> 来源：`下载物象/记忆改造技术资料.txt`（2026 主流 Agent 记忆结构综述）。本文档只做**了解/对照记录**，不改动 YHLZ 记忆实现。

## 一、素材要点（客观转述）

1. **四层冷热架构**（工业共识）：L0 上下文 / L1 工作记忆 / L2 会话记忆 / L3 长期记忆；默认只载 L0+L1，按需召回 L2/L3，Token 省 80~90%。
2. **三大机制**：①写入=智能抽取原子事实（非原文）②检索=混合（向量+BM25+元数据+时间衰减）③管理=Write-Manage-Read 闭环（后台去重/合并/摘要/遗忘，如 AutoDream）。
3. **L3 双层**：**画像层（Profile，精确读，错一次是事故）** vs **情景层（Episodic，向量检索）**。
4. **代表实现**：Mem0（中间件四步循环）、Claude Code SDK（四层+AutoDream，MEMORY.md）、Letta（OS 虚拟内存，Agent 自管记忆，core/working/archival/recall + sleeptime）、DeepSeek（记忆外置插件）。
5. **已放弃方向**：纯扩上下文、纯向量库、微调当记忆、全量历史拼接。
6. **五方案栈**：Text2Mem（操作语言/ISA，12 原子操作 ENC/RET/STO）、Mem0（存取）、Letta（自治）、ReMe（文件即记忆，向量70%+BM25 30%，Git 可审计）、memU（记忆即 Agent，24/7 后台，Resource/Item/Category 三层，自进化遗忘）。
7. **四层架构的致命短板**：①被动记忆（不会主动记）②检索准确率瓶颈 ③冲突消解靠规则（非理解）④**记忆不会"生长"**（碎片不涌现为高阶认知）。
8. **有潜力方向**：知识图谱驱动、记忆即 Agent、文件即记忆、端到端记忆模型。

## 二、与 YHLZ 现状对照

| 素材概念 | YHLZ 现状 | 差距/评价 |
|---|---|---|
| L0~L3 四层 | L0 上下文 + **L1 窗口摘要** + **L2 长期(belief+向量)** + **L3 认知根基** | 结构同构；YHLZ 的 L3 更"人格化" |
| L3 双层（Profile/Episodic） | 认知根基/persona（画像）+ L2 向量（情景） | 已具备雏形 |
| 写入=智能抽取 | review_once/consolidate 抽取、去重、自主写入 | 已具备 |
| 检索=混合+时间衰减 | 向量+BM25+rerank+**importance/salience**+时间衰减 | 已具备，**salience（情感显著度）是 YHLZ 的加分项** |
| 管理闭环/后台整理 | review_reinforce/decay/consolidate/快照 | 已具备 |
| 短板①被动记忆 | **自主节律(3h)+内在因(P2)** 驱动主动 | **YHLZ 正在补强（超出四层架构）** |
| 短板②检索准确率 | 混合+rerank，仍有限 | 共性难题 |
| 短板③冲突靠规则 | belief/contradiction/refute 联动 | 部分（有 LLM 裁决空间） |
| 短板④记忆不会生长 | **consolidate 分级→认知根基→persona；实体图；技能** | **YHLZ 的强项（记忆涌现/内化）** |
| 知识图谱 | 实体/关系轻图 | 早期，可深化 |
| 记忆即 Agent | 自主+内在因 | 部分对齐（YHLZ 方向） |
| 文件即记忆(ReMe) | 认知根基.md/日记/drives.json/台账 | 已对齐（透明可审计） |
| 端到端记忆模型 | **明确不做**（不训参数，0196/0250 结论） | 有意放弃（成本/灾难遗忘） |

## 三、结论

- YHLZ 的架构与该"工业四层共识"**高度同构**，且在两条"有潜力方向"上已先行：**记忆生长/内化** 与 **记忆即 Agent（自主+内在因）**。
- 素材点出的**四大短板**中，YHLZ 已在**①主动记忆**与**④记忆生长**上做了超出通用架构的工作；**②检索准确率**与**③冲突消解**仍是可继续投入处。
- 可借鉴（后续可选，不在本轮）：Profile/Episodic 显式分层、Text2Mem 式原子操作、AutoDream 式闲置后台整理。
- **本轮不动记忆实现**（按用户要求只做了解记录）。
