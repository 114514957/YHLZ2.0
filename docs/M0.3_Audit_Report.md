## 2. 架构变化说明

### 2.1 回退链 (目标架构落地)

```
Primary          qwen3-tts-customvoice   (realtime 主引擎)
   ↓ 失败
Secondary        qwen3-tts               (语音克隆)
   ↓ 失败
GPT-SoVITS       gpt-sovits              (高保真 Gradio 服务, M0.2 adapter 入链)
   ↓ 失败
Fallback         edge-tts                (在线兜底, 最终保障)
```

- 注册顺序 = 回退链顺序, 由 `tts_engine.py` 的 `ENGINE_REGISTRY` 常量定义 (`tts_engine.py:27-32`);
- 构建时输出链路日志: `TTS fallback 链: qwen3-tts-customvoice → qwen3-tts → gpt-sovits → edge-tts`。

### 2.2 Engine Registry (遗漏注册修复)

- 补注册 `gpt-sovits` (新增 `backend/tts/gpt_sovits_engine.py`, 包装 M0.2 adapter, 含 `health_check` / `change_weights`);
- 补注册 `edge-tts` (集成审计 R5 的兑现);
- 修复前 fallback 仅 2 级 (customvoice / qwen3-tts); 修复后 4 级全链。

### 2.3 Failure Handling (多级自动降级)

**激活期** (`activate` / `load`): 目标引擎加载失败 → 沿注册顺序逐个尝试后续引擎, 首个可用者成为激活引擎; 若当前激活引擎仍健康则保持现状, 不做无谓降级。

**运行期** (`synthesize` / `stream_synthesize_text`): 激活引擎合成抛异常 → 沿链自动切换到下一引擎并重试; 每级只试一次 (`tried` 集合防 ping-pong 死循环 — 初版实测发现 qwen3↔edge 无限互跳, 已修复); 全链耗尽 → 抛 `TTSEngineError` (永不静默失败)。

### 2.4 明确 fallback 日志

统一格式 `TTS Engine {x} {原因}, fallback to {y}`:

```
TTS Engine qwen3-tts-customvoice unavailable, fallback to edge-tts   # 激活期
TTS Engine qwen3 synthesize 失败, fallback to gpt-sovits             # 运行期
TTS Engine gpt-sovits unavailable, 继续回退                          # 单级跳过
TTS fallback 链耗尽: 无可用TTS引擎                                    # 全链失败
```

### 2.5 附带可靠性修复

- `edge.py` 预热无超时: 网络不可达时 `Communicate.stream()` 可无限阻塞 → 回退链卡死。已加 `asyncio.wait_for(..., 10.0)` (edge.py:83);
- 运行期回退后 `_active_name` 持久化为新引擎, 后续调用直接命中健康引擎, 无每请求降级开销。

## 4. 潜在风险

| # | 风险 | 等级 | 说明与缓解 |
|---|---|---|---|
| R1 | Edge 依赖在线服务 | 中 | 兜底引擎本身需联网; 完全离线时合成返回兜底音频 (不静默失败, 有日志), 最终保障为 mock 音频而非报错 |
| R2 | 运行期回退仅覆盖"抛异常"路径 | 低 | 各引擎 synthesize 内部已自兜底 (返回 mock 不抛异常), 运行期异常降级主要防御意外错误; 两级兜底叠加, 符合"永不静默失败" |
| R3 | GPT-SoVITS 引擎每次 load 尝试连接 Gradio | 低 | aiohttp 连接本地端口即时失败; 会话泄漏已在 M0.2 修复, 失败路径幂等 |
| R4 | `activate()` 语义变化 | 低 | 目标不可用但当前健康时返回 True 并保持现状 — 比旧行为 (返回 False) 更稳健, 已由 test_switch_api_still_works 覆盖 |
| R5 | 注册表顺序 = 回退链顺序的隐式约定 | 低 | 已通过 `ENGINE_REGISTRY` 常量集中定义并测试链序; 后续新增引擎需注意插入位置 |

## 5. 结论

M0.3 目标达成: Engine Registry 补全 (gpt-sovits + edge-tts 注册), 回退链从 2 级升级为 4 级 (Qwen3 → GPT-SoVITS → Edge), 激活期/运行期均沿链自动降级, 明确 fallback 日志落地, 并修复了链式降级中的死循环与 Edge 预热阻塞两个可靠性缺陷。14 项新测试 + M0.1/M0.2 共 28 项回归全部通过; 本机真实环境自动降级到 edge-tts 即为验收的实证。Voice Identity / WebUI / 角色系统零改动。

*不进行下一阶段修改。*
