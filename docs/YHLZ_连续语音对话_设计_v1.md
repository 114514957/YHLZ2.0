# YHLZ 连续语音对话 设计 v1

> 目标：把工作台语音从"对讲机/语音消息"（点一次→听3秒→回一句）升级为**连续自然对话**——一直听、自然断句、能插话打断、低延迟。
> 日期：2026-09-11。状态：设计稿。

## 0. 现状与问题
- 工作台 `/voice`：**一次点击 = 一轮**（服务端采集固定 ~3s → SenseVoice → LLM 流式 → TTS 播报），每次都要点、固定断句、不能打断 → 像"发语音消息"。
- 但 `tools/voice_dialog.py`（CLI Demo）**已实现连续链路**：VAD 连续采集 → ASR → LLM 流式 → 句级切分 → 并行 TTS → 队列播放；含插话不打断/排队、相邻短段合并。→ **本设计主要是把它"搬进工作台 + 加 UI"**。
- QQ 端受平台限制，语音本质是"语音消息"，**连续对话只在工作台/桌宠**。

## 1. 架构（服务端采集 + 长连接 SSE）
- 麦克风在**服务端**（同机），无需把音频从浏览器传上去。
- 新增 **`/voice-continuous`（长生命周期 SSE）**：服务端跑连续循环，向客户端推送事件；客户端只需展示，**免点击**。
- 事件（统一口径）：
  - `state`：`listening | thinking | speaking | idle`
  - `partial`：实时转写片段（边说边出）
  - `user`：本轮到齐的用户文本
  - `delta`：元亨回复流式片段
  - `turn_done`：本轮完成（含全文）
  - `barge_in`：被打断
  - `level`：VAD 电平（前端画波形）
- 循环：`聆听(VAD) → 断句 → ASR → 思考(LLM流式) → 说话(句级TTS) → 回到聆听`。

## 2. 自然轮次（VAD 断句，不靠固定 3s）
- VAD 检测说话起止；**动态 hangover**（静音 ~0.6–0.9s 判"说完"），静音期不硬断。
- 最短语音时长（防咳声/噪声误触发）；能量门限自适应 + 噪声底。
- 复用 `VoiceFrontend`（RNNoise/AGC）与 `target_vad`。

## 3. 打断（barge-in）
- **speaking 期持续监听**：检测到人声 → **立即停播 + 取消当前 LLM**（复用 `turn_control` 的协作取消）→ 开新轮。
- **回声处理**：无真 AEC → 播放期抬高门限 + 回声指纹（`voice_dialog` 已有）；保守起步（半双工），再放开。

## 4. 低延迟
- ASR：**分段 SenseVoice**（短句，快）为主；可选流式 sherpa 出 `partial`。
- LLM：流式（已有）。
- TTS：**句级切分**，第一句即开口（边说边生成），不再整段生成完才说。
- 记忆：投机预取（已有）。

## 5. 资源策略（8G 显存）
- ASR/TTS/LLM **不可同驻**。连续模式推荐：
  - **LLM**：本地 Gemma 常驻（GPU）。
  - **ASR**：SenseVoice **CPU**（短句可接受）或 sherpa-onnx（CPU）。
  - **TTS**：**edge-tts**（不占显存、低延迟）；离线退 SAPI。
- 即"GPU 只放 LLM，ASR/TTS 走 CPU/云"，换取连续可用（牺牲一点质量/延迟）。

## 6. 交互
- 工作台：**"连续对话"开关**（默认关；开启后免点击）+ 状态灯 + **实时转写** + 波形 + 打断提示。
- 桌面桌宠：可挂同一连续语音（对桌宠说话）。
- 停止/退出：关开关即结束会话。

## 7. 分阶段与验收（做一步测一步）
- **V1 连续会话骨架**：`/voice-continuous` SSE + 状态机（listening/thinking/speaking）+ 前端开关/状态灯。
  - 验收：开启后免点击，能连续两轮。
- **V2 自然断句**：VAD 动态 hangover + 最短时长 + 实时 partial。
  - 验收：正常语速说话能自动断句，不硬切。
- **V3 barge-in**：说话期可打断 + 取消 LLM。
  - 验收：她说话时插话能立即停并转新一轮。
- **V4 句级 TTS 降延迟**：第一句即开口。
  - 验收：首字延迟明显下降。
- **V5 桌宠接入**（可选）。

## 8. 风险
- 无 AEC → 打断/半双工保守起步。
- 8G 资源 → 必须"GPU 只放 LLM、ASR/TTS 走 CPU/云"。
- 服务端麦克风 → 仅同机可用（工作台与麦克风同机；远程访问浏览器时需改为前端采集，后续可选）。
