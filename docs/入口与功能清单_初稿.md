## 3. Golden Path 初选

冻结前只把以下路径列入第一阶段验收：

```text
文本输入 → /chat → LLM 流式 → 文本事件 → TTS → 播放 → COMPLETE
麦克风 → VAD → ASR → Session Kernel → LLM → TTS → 播放
播放中用户输入 → INTERRUPT → 停止旧输出 → 新 turn
```

Agent、视觉、主动行为、声音克隆、行动系统和复杂 Avatar 动作先列为外围/任务路径；它们必须在 Kernel 契约稳定后逐项接入。

## 4. 入口归属规则

1. 一个用户意图只能被一个入口提交为活动 turn；
2. 入口不得自行维护第二份“正在处理/正在播放”真值；
3. 入口可做协议转换，但不能改变 `turn_id`、取消和提交语义；
4. 任何新入口必须先登记、指定路径类别、定义降级方案并通过契约测试；
5. 没有负责人和回滚方案的入口不进入生产清单。
