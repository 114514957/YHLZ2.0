> 回归证据：自测用例全绿；T01 十块 PASS=10；批次01（general）PASS=15；S01 + 测试样本（story）PASS×4 WARN×1 不变。

> 配套程序：`tools/v9_story_gate.py` v1.0（含 11 个正反自测用例；`--selftest` 随时验证程序本身）。
> 定位一句话：**门控是底线闸门，不是质量裁判**——机器管"可判的"，人管"只能看的"。

## 一、门控能保证的（机器可判 → 硬 FAIL）

| 组 | 检查 |
|---|---|
| 形态（story 档） | 长块 **>20 轮**；含 **≥400 字超长句**；fiction 与必备元数据（category/status/emotion/length_tier/contract）齐全 |
| 禁项 | 客服腔/模板腔/报告腔/AI 自述腔；括号、星号、分号、冒号、列表行；填充语撞车（先说好/我这边/别指望/后来我…） |
| 角色纪律 | 发言人白名单（老爹/元亨/利贞/陌生人/朋友/群友）；**大肥鱼禁言**；元亨不得用「理论上来说」 |
| 防带歪 | **来源名黑名单**（苏菲/克莱恩/阿蒙…）——小说/游戏人物设定不得渗进元亨素材 |
| 基线机械项 | 元亨自称 ≥2 种（≥4 条元亨答时计）；收尾方式不全是一种（同型 ≥90% 告警） |
| 重复控制 | 4 字片段复读扫描（术语如 JSON 有豁免表） |
| 辅助指标 | 平均轮长/短轮率/语气词数（报告级，供人审参考） |

## 二、门控不能替代的（必须人审）

- **「像不像元亨」「有没有人味」「梗好不好笑」**——语义与审美，机器判不了；
- **"只改风格不改内容"的核对**（信息点有没有被改坏）——需要老爹抽审；
- IP 的"实质性相似"判断、事实/经历边界、人设漂移的微妙语义；
- 因此流程固定为：**门控先过（机械底线）→ 老爹抽审（语义上限）**；门控 FAIL 不入人审，先修。

## 三、工作流

```bash
# 长对话线（测试样本、故事集、续写/改编）
python tools/v9_story_gate.py --profile story <文件或目录>

# 重处理线（批次01 这类：不管轮数/超长句，只查禁项/纪律/防污染）
python tools/v9_story_gate.py --profile general <文件或目录>

# 输出：屏幕报告 + <文件>.gate.txt；--json 另存 .gate.json；退出码 0=PASS / 1=有FAIL
# 改脚本后先跑自检：python tools/v9_story_gate.py --selftest（当前 11 用例全绿）
```

## 四、可调参数（都在脚本顶部 CONFIG，改参数不动逻辑）

- story 档：`min_rounds=21`、`require_ultra=400`、fiction 必填；
- general 档：只查禁项/纪律/防污染；
- 黑名单/词表/豁免表（repeat_exempt）/告警阈值（破折号>2、收尾≥90%）原地可改。
