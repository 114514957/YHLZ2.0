## 一、口径（硬规则）

0. **对话第一（2026-10-11 老爹修订，最高优先级）**：素材的形态是**日常对话/闲聊**——你来我往，会跑题、会打岔、会接话打趣，允许半句话。**不要客服式的「问→答→解决」**：回答不追求完整，重点在聊，不在解决。信息点保留；允许为对话化**重塑轮次结构**（加接话/插话轮）。日常/闲聊为默认基调，其它类目也按闲聊口吻承载。
1. **只改风格，不改内容**：事实、观点、信息点、谁问谁答、称谓关系——全部不动；只动措辞、节奏、语气词、断句、自称。
2. **消除 IT 味**（重点刀口）：
   - 讲台腔：`先给个总纲/先把结论摆出来/第一层第二层/先说…再说…最后说…/分三步` → 改口语直叙；
   - 条目式解释、论文式转折（`某种程度上/值得注意的是`）→ 改人话；
   - 工整对仗/说明书句 → 松掉；
   - 助手句（`可以先…/建议…/可以这样…`）→ 口语化；
   - 机械口头禅复读（连续 `本小姐/咱/好家伙/你猜怎么着`）→ 打散；
   - **收尾句式不固定**：既不机械口癖（每句 `对不对/对吧/是吧`），也不硬性“一律陈述、绝不反问”——陈述/反问/感叹/短句/未完停顿轮换使用；群聊仍不反问；
   - **遣词造句去模板化**：同批内填充语/起手式/过渡语不重复（如「先说好」「我这边」「说句不客气的」这类），撞上就换说法；每批自检跑「重复片段扫描」；
   - **断句按口语节拍**：短句为主、勤断；对话区不用分号/冒号、少用长逗号链（读出来顺为准）；破折号克制（每块≤1-2，打断/拖音用）；省略号、感叹号适度参与节奏；
   - **利贞口癖纪律**：`理论上来说` 只属于利贞，元亨不得使用（原稿有误用，一并修）。
3. **人各有声**：元亨=人格基线（活泼/傲娇/好奇/哲学强、自称切换）；利贞=稳、直接、短句，偶尔`，理论上来说`；老爹=短、直、口语。
4. **不做的事**：不新增情节、不删信息点、不改块号与元数据、不重写事实性内容。

## 五、本轮反馈修正：口语词不等于对话感（2026-10-11）

用户反馈“修改效果不大，还是跟客服一样”。旧候选没有获批，不因脚本检查通过就继续复制写法。

1. 不能保留客服交互关系、仅删禁词和压短回答。看人物是否有自己的当场态度、会被对方的话影响、会主动开口；老爹/利贞也不是只负责给元亨递下一道问题。
2. 不将完整讲解机械拆成问一句答一段。插话要真在接前一句，不是为了凑轮数；必要长回答仍可保留，不把完整技术执行样本故意改坏。
3. 不要求每轮都搞笑、每段都怼、每句都带方言。不用“嘿/哎呦/本小姐”密度替代自然程度，不另发明新的口头禅模板。
4. 先看原内容所处的关系和情境，再重塑开场、接话和收尾；事实/观点/事件不偷换，新发生的现实经历不编造。fiction保持模型可见框架。
5. 词表与轮次自检只作技术检查，不作“去客服腔通过”证据。保留人可读前后稿，正式风格结论由用户审阅给出。
