# 原文引用与防失真规则 v1（2026-10-18）

> 老爹指示：「**多用原文，注意尤其是从书里弄来的，多用原文来表述观点、性质，以防知识失真**。」
> 适用范围：**所有从书籍/文献/小说/课程里取的素材**（哲学概念、设定术语、技术原理、人物性格）。
> 一句话原则：**观点、性质、论断用原文；语气、口语、衔接可以自己写。**

---

## 1. 为什么要这条规则

改写会把"作者的判断"悄悄换成"我的理解"，三处最容易失真：

| 失真类型 | 例子 | 后果 |
|---|---|---|
| **概念被换词** | 「绝对精神」→「终极意识」 | 概念错位，学到的是另一个东西 |
| **性质被降级** | 「这是**必然**的」→「这大概是」 | 强度丢失，论断变成猜测 |
| **论断被合并** | 两个不同观点被揉成一句 | 张冠李戴，模型记住错误的归属 |

**元亨要学的是"书里那个观点"，不是"我转述的那个观点"。** 转述可以，但**核心论断必须可回溯到原文**。

---

## 2. 三种必须保原文的情形

| 情形 | 保什么 | 示例 |
|---|---|---|
| **① 概念/术语** | 原词，不换 | 「绝对精神」「此在」「能指」「意识流」——**不许改成近义词** |
| **② 性质/强度** | 原情态词 | 「必然/只能/本质上/在某种意义上是」——**不许弱化成"可能/大概"** |
| **③ 有归属的论断** | 原文 + 归属 | 「黑格尔认为……」「据《苏菲的世界》」——**不许改挂到别人头上** |

**反之可以改写的部分**：过渡句、口语化、元亨的回应口吻、寒暄、情绪反应。

---

## 3. 写法（三种落法，按素材用途选）

### 落法 A：直接引用（推荐用于核心观点）
> 元亨：「苏菲的老师说得很直白——『你不可能知道自己死后会怎样，所以你只能相信或者不相信。』这话我认，剩下的交给活着的人去争。」

- 引号内是原文（短句）；
- 引号外是元亨自己的承接；
- **不整段复制**，单次引用控制在 2 句内。

### 落法 B：术语保真 + 自述（推荐用于概念讲解）
> 元亨：「你说的那个东西，书上叫『**绝对精神**』——不是我起的名，是黑格尔的。它指的是精神把自己外化出去、再认回自己这一整个过程。你要我用白话说，也行，但名字不能换，换了就不是它了。」

- 术语原样保留；
- 解释可以白话，但**明确标注"这是术语/原名"**。

### 落法 C：观点归属（推荐用于多人观点对照）
> 元亨：「这块有两个人说法不一样。一个说『知识来自经验』，另一个说『有些知识天生就在』。我不是和事佬，但这两句我都得原样摆出来，不然你根本看不出他们吵的是什么。」

- 双方的**原话并置**，不改写；
- 元亨只做点评，不做合并。

---

## 4. 硬约束（跟着 IP 与来源策略走）

| 约束 | 数值/做法 |
|---|---|
| 单次引用长度 | **≤ 2 句 / ≤ 60 字**，不整段 |
| 单册引用总量 | **不超过该素材块正文的 20%**（避免"复制书"） |
| 来源标注 | 每块元数据里写 `source_book` + `chapter`（或页码范围） |
| 在版权期内的书 | 只做**落法 B/C**（术语与观点归属），**不做落法 A 直接引用** |
| 公版书（福尔摩斯/洗冤集录/笑林广记等） | 三种落法都可用 |
| 改名不免责 | 把「黑格尔」改成「黑格」仍是侵权，**改名不等于可用** |

## 6. 自检清单（每块书源素材贴进去前逐条过）

- [ ] 术语是否原样？有没有被换成近义词？
- [ ] 性质词（必然/只能/本质）有没有被弱化？
- [ ] 论断的归属人对不对？有没有张冠李戴？
- [ ] 引用是否 ≤2 句 / ≤60 字？
- [ ] 引用总量是否 ≤ 本块 20%？
- [ ] `source_book` / `chapter` / `quote_type` 填了没？
- [ ] 在版书是否避开了落法 A？
- [ ] 元亨的承接是"接住观点"还是"改写观点"？（必须是前者）
