# 知识产权与来源策略 v1 · 2026-10-13

> 依据：GB/T 45654—2025「应具备训练数据知识产权管理策略和规则」「不应侵害他人依法享有的知识产权」。
> 性质：**内部合规策略文档**，不是法律意见；不替代对具体来源的逐项核权。
> 配套：[素材来源登记册 v1](素材来源登记册_v1_20261013.md)（逐来源事实）｜[安全标注规则 v1](安全标注规则_v1_20261013.md)（S18 知识产权类的标注口径）。

---

## 1. 三条总原则

1. **许可先行**：任何外部素材**先核许可、后取用**；核不清的记为 `pending`，**不计入"已有可用训练数"**。
2. **分层隔离**：自有／已核／仅非商业／公版／仅参考，**五层物理分开存放与统计**，不混池。
3. **改名不免责**：换角色名、翻译、让模型重写，**都不视为清除来源条件**——原许可仍然适用。

## 2. 许可分层与使用边界

| 层 | 判据 | 可用范围 | 存放与统计 |
|---|---|---|---|
| **L1 自有** | 我们自己创作/合成 | 全用途 | 主素材目录 |
| **L2 已核可用** | 许可明确允许训练用途 | 按许可条款 | 正常入池 |
| **L3 仅非商业（NC）** | CC BY-NC、自定义非商业条款 | **仅非商业路径**；单独标注 | **单独目录 + 单独统计**，不得混入商用产物 |
| **L4 公版** | 原文已进入公有领域 | 可用；**译本另行核权** | 标注 `public_domain` + 译本版本号 |
| **L5 仅参考** | 许可不明/研究限定/门控未获 | **只看不进集** | 不入 `sft_persona_*` |

**当前归类**（详见登记册）：L1＝SRC-001/003；L3＝SRC-004/005；L4＝SRC-014；L5＝SRC-007/015；其余 `pending`。

## 3. 逐类来源的处理规则

### 3.1 在版书籍（小说/语言学/科普）
- **默认路线：只做"不依赖原文"的原创讨论型样张**（阅读讨论、抽象机制）；
- **摘录原文或改编具体桥段**：必须同时满足 ① 拿到文本 ② 逐本核权完成 ③ 明示授权 → 才可进 `adapted` 分池；
- **上限**：即便授权，单本来料在总监督量中**受配额限制**（防某一部作品盖过元亨自身声线）；
- **人名与设定**：按门控黑名单执行——**角色名与专有设定不进元亨素材**（当前实现：`tools/v9_story_gate.py` 的 `source_names`）。

### 3.2 开源数据集
- 逐个来源核，**不按顶层 license 推断整库**（COIG 即为反例：顶层 Apache，子集条件不一）；
- 保留 `source_id`（仓库 + 版本/SHA + 子集名）与许可快照；
- 门控未获 / 研究限定的（如 xLAM）**标为不可用**，不"先下后说"。

### 3.3 公开网页与百科（SRC-015）
- 定位为 **reference_only**：只用于设定研读，**不得作为语料**；
- 若未来要用：必须先记录 **robots 证据 + 站点许可 + 引用范围**，再逐站评估；
- 引文长度控制：**不作为训练数据时也不整篇复制**，只留要点。

### 3.4 QQ 群与聊天记录（SRC-002/003）
- 涉及**他人个人信息** → 见第 4 节。

### 3.5 用户（老爹）提供的素材
- 提供≠授权：登记为来源，**权属与用途仍逐项确认**；
- 老爹本人的创作/发言：`consent_status: own`。

## 4. 个人信息与匿名化（与安全标注规则联动）

| 情形 | 要求 |
|---|---|
| 含**他人**个人信息（昵称、QQ 号、群号、可识别言论） | 使用前取得同意；**当前未取得** → 必须先匿名化，并登记处理方式 |
| 含**敏感**个人信息（身份证、手机号、住址、健康、金融） | 单独同意；未取得 → **剔除** |
| 匿名化后 | `consent_status: anonymized`；保留 `id_map` 于**内部对账**，不随语料分发 |
| 出集口径 | **不输出任何原始标识符**（字段名、账号、昵称、群号） |

**当前状态**：`tools/v9_qq_corpus_curate.py` 已完成工程层去标识（18567 → 18505 条，三项残留检查全 0），但**同意路径仍待老爹 D-1 决策**；在决策前，该语料**只作候选，不进正式集**。

## 5. 留痕要求（每次取用外部来源都要落）

| 留痕项 | 落点 |
|---|---|
| 来源登记（含许可与获取方式） | `素材来源登记册_v1_20261013.json` |
| 许可快照（数据卡/条款/robots） | 登记册 `robots_or_terms` 字段 + 缓存证据文件 |
| 采集前评估 / 采集后核验 | 登记册 `pre_collect_assessment` / `post_collect_verification` |
| 内容指纹 | 素材 `content_hash`；语料 `sha16` |
| 安全标注 | `safety_labels`（含 `S18` 知识产权类） |
| 处理脚本与版本 | 每个来源注明所用脚本名（可复跑） |

## 6. 禁止清单

1. 许可不清就进集（"先用着，回头补"）；
2. 把 NC 池混入任何面向商用的产物；
3. 用改名/翻译/重写规避来源条件；
4. 把 `reference_only` 来源当语料；
5. 拿"仅内部使用"当版权豁免；
6. 绕过访问门控（如需要授权的数据集）；
7. 在训练数据里保留他人可直接识别的个人信息。
