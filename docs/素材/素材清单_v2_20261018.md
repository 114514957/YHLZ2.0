### 2.8 配额与配比定稿（2026-10-18，老爹裁定 + 检索依据）

| 项 | 定稿 | 依据 |
|---|---|---|
| **数学课本占比** | **下调**：教材/阅读池内部 数学 ≤ **10%**（原计划与语文并列）；小学/初中/高中语文合计 ≥ 60%，古诗文/文言 ≥ 40% | 老爹「数学占比下调一点」；数学只做推理与概念，不喧宾夺主 |
| **QQ 真实对话** | **可用（cleared）**：D-1 关闭；18505 条匿名语料 + 新拉 510 段真实对话入池；出集仍不输出原始标识符 | 老爹「QQ 接受」；《知识产权与来源策略》§4 |
| **长对话（>20 轮）** | 占块数 **25%**（区间 20–35%） | 既有 README「3 轮以上 ≥30%」的升级；长程行为需要真实长块 |
| **ultra（单轮 ≥400 字）** | **4%**（区间 3–5%） | README §11 建议先按 ≥3% 试；取 4% 保证输出长文能力 |
| **长文阅读样本**（输入 ≥8K 字，输出为摘要/问答） | **3%**，独立一类 | 老爹要求支持长文阅读和输出；这类样本练的是读，不是长聊 |
| **其余**（短/中） | 保持主体（≥60%） | [ProLong](https://arxiv.org/html/2410.02660v4)：**SFT 阶段短指令数据已足以支撑长上下文**；长数据占比过高会**损伤短任务**（60/40 的最优比是继续预训练的结论，不是 SFT 的） |

> 也就是说：**长文能力靠少量但真长的阅读样本 + 短指令主体**，不靠把长对话灌满。
