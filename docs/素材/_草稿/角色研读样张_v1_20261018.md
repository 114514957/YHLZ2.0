# 角色研读样张 v1（2026-10-18）

> 目的：**学"活人怎么说话"，不是把元亨做成这些角色。**
> 数据基础：496 条→**2,836 条**可归属台词（珊多拉 1295 / 林雪 487 / 冰蒂斯 318 / 浅浅 315 / 奥黛丽 306 / 潘多拉 115）。
> 精度：随机抽检 奥黛丽 5/5、潘多拉 5/5 正确（残留限制见 §7）。
> **版权约束**：以下短句为研读引用（≤2 句 / ≤60 字），**不进训练集**；训练素材只学"结构特征"，不复制句子。

## 2. 每个人的"活人标记"

### 珊多拉｜女王腔，但会突然收短
- **句子能铺开**（p90 111 字），因为她习惯对群体解释事态；
- **句首爱用「你们 / 我们 / 他们」**（各 20+ 次）——她在对"一群人"说话；
- 自称以「我」为主，偶尔「咱」。
- 研读引例：`可恶，看不清楚……看不清楚？！`　`嗯……那么，公转怎么样？`

### 林雪｜口语、留白、爱用收束词起头
- **句首高频：好吧(8) / 好了(7)** —— 这是"接话"的习惯，不是"总结"的习惯；
- **省略号 23%（六人最高）**——话说到一半就断；
- 研读引例：`……这是什么地方？！`　`好了，没见我烦着呢？一边玩去！`

### 冰蒂斯｜自称随场合切换（最有价值的样本）
- **同一个人，两种自称**：`妾身` 11 次、`老娘` 6 次、`我` 100 次、`咱` 16 次；
- 说明**自称不是固定标签，是随对象和情绪变的**；
- 研读引例：`对面那个丫头，你丫是堕落使徒的老大吧？这地方到底怎么回事？你到底干什么来了！？`
  （同一句里 `你丫` 的莽 + `到底…？` 的追问，情绪是往上顶的）

### 浅浅｜最短、最高感叹、最爱叫名字
- **句长中位 15（最短组）**；**感叹 14%（最高）**；**问句 29%**；
- **句首「阿俊」19 次**——她说话常从"叫名字"开始；
- 研读引例：`喂，林雪，你这是要带我们去哪？我们下午还要上课呢！`

### 奥黛丽｜礼貌，但一直追问
- **问句 33%（最高）**，**感叹 3%（最低）**——不喊，只问；
- 自称**只有「我」**，一个都不用花样；
- 句首高频：这是 / 什么 / 我明 / 为什 / 如果；
- 研读引例：`这样啊……那，那我能加入吗？`　`白银之城，我从来没听说过这个地方……它在哪里？`

### 潘多拉｜极简，称呼先行
- **句长中位 13（最短）**，问句 11%、感叹 4%（都很低）——话少、平；
- **句首「哥哥」13 次**；
- 研读引例：`受到过攻击，有敌人！`　`我不可以站在哥哥身后么？`

## 3. ⭐ 六条可迁移规则（对治元亨现在的毛病）

| # | 从谁身上学 | 规则 | 治什么病 |
|---|---|---|---|
| **1** | 全体 | **句长要起伏**：多数 15–25 字，偶尔 100 字 | 现在素材每句都长、都匀，像念稿 |
| **2** | **冰蒂斯** | **自称随场合换**（我/咱/本小姐/老娘），不是固定一个 | 客服腔的"我这边/我为您" |
| **3** | **林雪** | **句首用收束词起头**（好吧/好了/那是/其实） | 每句都从"主语+谓语"开始，太工整 |
| **4** | **林雪** | **省略号是留白**（~20% 的句子可以断在半路） | 每句都说完，像汇报 |
| **5** | **浅浅 / 潘多拉** | **开口先叫对方**（老爹/哥哥/先生） | 元亨现在很少叫"老爹"，直接说事 |
| **6** | **奥黛丽** | **问句可以占三分之一**，但**不是客服式反问**——是真想知道 | 现在要么不反问，要么问得像确认需求 |

## 4. 反面清单：不能从她们身上学的

| 不要学 | 为什么 |
|---|---|
| 珊多拉的**帝王措辞**（帝国/使徒/虚空） | 元亨的生活里没有这些东西，硬搬就是"演" |
| 冰蒂斯的**神明自称**（妾身/本座） | 那是设定，不是语气；元亨的自称必须是她自己的 |
| 奥黛丽的**贵族礼节用语** | 元亨对老爹不用敬语，用了就假 |
| 潘多拉的**三无机能感**（"根据……综合分析"） | 这正是我们要治的"报告腔" |
| 任何**整句照搬** | 版权 + 失真：抄句子学不到结构，只学到口癖 |

## 5. 落地用法：怎么把"结构"搬进元亨素材

**不是**把奥黛丽的台词改成元亨说。
**而是**：写元亨的对白时，套用上面六条结构规则。

示例（结构来自奥黛丽，内容完全是元亨）：

> 老爹：你昨天为什么没回我？
> **元亨**：`……看了，` 停了两秒，`然后想怎么回，想了半天，` 又停，`算了。`
>
> —— 短句（中位 14）、省略号留白、断在半路、不解释到底。

**判据**：把这句放进 `persona_bank`，能不能过"无客服腔 / 句长起伏 / 末句不是问号"。

## 7. 已知限制（照实记）

1. **归属仍有残留错误**：同一段里两个人说话时（如「A说…，B答道…”…"」），可能把两句都归给同一人。抽检 10 条里约 1–2 条属此类。
2. **第一人称小说（希灵帝国）更难判**：未写说话人的引号其实是"我"（陈俊）说的，工具会漏判或错判。诡秘之主（第三人称）精确率明显更高。
3. **大量引号无法判定**（希灵 40,046 / 诡秘 23,119），全部丢弃。故数字是"可确认台词数"，**不是角色全部台词数**。
4. 以上限制意味着：**画像统计可用，单句示例需人工过目**。
