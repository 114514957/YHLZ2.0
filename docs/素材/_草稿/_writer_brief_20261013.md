# 每块扩写要点表（2026-10-13）｜写手必读

> 规范性文件见 `_writer_spec_20261013.md`。源块全文见 `_src_1to30_清单.md`。
> 下表 `源块` 号 = 源文件的 `对话-N`；`新块` 号 = 要写的 `故事-2XX` 的编号。
> 「超长轮」= 那一条元亨发言必须超过 400 汉字（目标 430-520，留余量）。

## 通用动作（每块都要做）

- 源块的每一轮都必须保留它的**说话人和顺序骨架**（谁起头、谁接、谁收），但轮次数量要抻到 22-26。
- 源块里的每一个信息点都必须还在（不许丢、不许改），但可以挪到别的轮里说、可以拆成几次说。
- 至少 3 条 15 字以内的短轮；至少 12 条元亨发言。
- 让老爹和利贞也有存在感，别变成元亨单口相声。

## 源块 1 → 故事-201｜哲学·幸福和快乐
- 源块骨架：利贞起头问亚里士多德的幸福和快乐是不是一回事 → 元亨长答 → 老爹问躺平晒太阳算不算幸福 → 元亨答。
- 必留信息点：eudaimonia 翻「兴旺」比「快乐」准｜幸福是把人的功能发挥好、活出该有的样子｜快乐是副产品不是目标｜快乐是感受（会来会走、靠外部刺激、人被动）｜幸福是活动（灵魂合乎德性的持续实践、靠选择习惯、人主动）｜快乐不排高低、幸福排高低（德性有高低，勇敢公正节制）｜外部条件（朋友、健康、起码的资源）是条件不是本质｜快乐是伴随音不是那首曲子｜追快乐反而追丢｜晒太阳是休息、休息是恢复｜晒太阳晒成全部就缺「活动」这一环｜乐在其中和活得好是两个问题。
- 扩写方向：利贞要抠字眼（「繁荣」和「快乐」哪个译法好、凭什么德性有高低）；老爹要往自己身上套（我遛弯算不算、我打牌算不算、那我孙子呢）；元亨用生活里的类比把「活动」和「感受」的区别说开。
- 超长轮：第 1 条或第 3 条元亨答（讲清楚那套区分的）要 430 字以上。另一条元亨答也可以到 200 字左右。
- 特别要求：源块里「咱说句不客气的」这半句在整批里只能出现一次，本块请换成别的说法（例如「这话不好听，但就是这么回事」）。

## 源块 2 → 故事-202｜日常·出门吃个饭
- 源块骨架：老爹说别做饭了出去吃、你挑 → 元亨定馆子 → 利贞问几点出发要不要占位 → 元亨答 → 老爹问谁买单 → 元亨答。
- 必留信息点：挑川菜馆｜要小馆子、锅气足｜不要连锁｜怕辣提前说、可以点两个不辣的菜、但不会迁就太多｜六点半出门｜利贞先占位最稳、那家饭点排队｜占到了发消息｜谁挑的地方谁有面子、买单别看元亨｜老爹想当请客的老爹，元亨不拦着。
- 扩写方向：点菜环节可以细（水煮鱼微辣、拍黄瓜、米饭要不要加），但**不许出现"到店之后"之外的新事件**，整个过程就在"决定这顿饭怎么办"这一段时间里打转。利贞可以中途插一句台账式的提醒。老爹可以中途反悔（想吃面、想吃烧烤），被元亨按回去。
- 超长轮：元亨讲「为什么非要小馆子、锅气是个什么东西、一家人坐下来吃饭跟填肚子的区别」，430 字以上（这条可以自然长出，允许带到一点上一批故事-104 的味，但不许抄它的句子）。
- 特别要求：源块的「别指望本小姐迁就太多」必须换说法（「别指望」整批只留 1 次，不在本块）。

## 源块 3 → 故事-203｜技术·日志结构化
- 源块骨架：元亨问日志结构化怎么落地 → 利贞答（定字段）→ 老爹问老系统自由文本怎么办 → 利贞答 → 元亨问 JSON 还是列存 → 利贞答。
- 必留信息点：先别想工具、先定字段｜固定键值（时间戳、级别、服务名、请求 ID、消息体、耗时）｜时间戳统一 ISO 8601 带时区｜级别限死 debug 到 fatal｜请求 ID 贯穿整条链路、一次查询串起一次请求｜老系统分两步、新代码按字段打、老的先加解析层、能正则抽的抽、抽不动塞 raw 字段兜底｜一次改不完、先管住新流量｜字段固定聚合多就列存、字段变化大要保留原始结构就先 JSON 再对常查的键做提取列｜常见做法是 JSON 打底加物化列。
- 扩写方向：这是利贞的主场，元亨负责追问、举例、抬杠（「那查的时候我不还得背字段名」「上礼拜那事查了仨小时」），老爹负责外行打岔（「这跟记账有啥区别」）。利贞的答案是短句为主，别写成文档。
- 超长轮：元亨的一条，讲「为什么查日志这事让人上头、一次请求串不起来有多气人、结构化真正省下的是什么」，430 字以上（要用生活类比，别写成方案）。
- 注意：不许出现「首先/其次/分两步走」这类讲台腔；「分两步」要改成「先…再…」的聊天说法。

## 源块 4 → 故事-204｜闲聊·旅行的意义
- 源块骨架：老爹问旅行有什么意义 → 元亨答（换个地方把自己重看一遍）→ 利贞问待家里不也能想明白 → 元亨答（家里的墙不会顶你，路上会）→ 老爹问所以你是为了被顶才出门 → 元亨答（差不多，回来就不一样了）。
- 必留信息点：换个地方重新看自己｜家里不顶你、路上会顶你｜为了被顶而出门｜回来就不一样了。
- 扩写方向：全靠闲聊撑，不许加"某次旅行发生了什么"（那是新情节）。可以聊的是：为什么要顶、被什么顶（不是人，是路、是听不懂的话、是走错的那一段）、待在家里为什么想不明白、回来之后哪一点不一样了。老爹可以老实说"我出门就为吃"。利贞可以拆台（「你上回出门带了仨充电宝」这种细节可以，但别引入一次具体旅程的事件）。
- 超长轮：元亨讲「被顶」到底是什么感觉，「墙」和「路」的分别，430 字以上。
- 注意：元亨的自称要换着来，不要整块「本小姐」。

## 源块 5 → 故事-205｜故事·那台老收音机
- 源块骨架：老爹问那台老收音机后来怎样了 → 元亨答（修好了、能响，一堆细节）→ 利贞问声音还清楚吗 → 元亨答（杂音大，像哭）→ 老爹问人呢，还在听吗 → 元亨答（只剩一个了）。
- 必留信息点：从老爹床底下翻出来｜壳子裂了、旋钮掉了、里头全是灰和蜘蛛网｜小刷子扫、铜丝接断线、折腾大半天、手都黑了｜通电先刺啦响、然后冒出电台声音、忽大忽小｜蹲那儿听半天、调频旋钮涩、要指甲掐着转｜搁窗台上、天线拉到头、勉强两个台（一个老歌一个评书）｜这玩意儿跟人一样、零件老了修修补补还能出声、声音里带着毛病｜杂音很大、像哭｜只剩一个了。
- 扩写方向：这是**安静、疼**的那一块。节奏要慢，短句要多。利贞的问题要少而准（「哪个台」「修的时候焊了几次」），老爹的问题要家常（「听那个有啥意思」）。**不许新增事件**（不能出现"我又去买了个电容"这种新事，除非源块里有；源块里没有就只聊已经发生的那些细节和感受）。
- 超长轮：元亨重讲修的过程那一条，430 字以上，但要拆成有呼吸的口语句（不许一段到底）。
- 注意：这块跟源块 22 是同一台收音机，本块的重点是「像哭」和「只剩一个了」，别写成 22 的闹腾版。

## 源块 6 → 故事-206｜日常·晒被子
- 源块骨架：利贞问今天晒被子了吗 → 元亨答（晒了、那味道绝了、蓬松得像新买的）→ 老爹问几点收的 → 元亨答（四点收的、太阳刚好、斜着打过来晒得透透的）。
- 必留信息点：晒了｜晒完的味道好｜厚被子蓬松得跟新买的一样｜四点收的｜四点太阳刚好、不早不晚、斜着打过来晒得透透的。
- 扩写方向：这一块就是**纯过日子**，靠细节和抬杠撑：被子多重、晾衣绳塌过没有、拍被子扬起来的灰、太阳味到底是不是螨虫被烤焦（利贞可以给一句事实，元亨不信，也不许引科学术语堆砌）。老爹可以打岔到「我那件夹克也该晒」。
- 超长轮：元亨讲「太阳味」这件小事为什么让人心里踏实，430 字以上。
- 注意：源块里「好家伙」「你猜怎么着」各出现一次可以用，但整块不超过两次，且不许连着用。

## 源块 7 → 故事-207｜技术·内存一直涨
- 源块骨架：元亨问内存一直涨从哪查 → 利贞答（堆快照对比）→ 老爹问对比看什么 → 利贞答（只增不减的对象）→ 元亨问找到之后呢 → 利贞答（顺引用链找根因）。
- 必留信息点：先看堆快照对比｜看只增不减的对象｜顺引用链找根因。
- 扩写方向：信息点极少，全靠聊。可以聊的是：怎么算"一直涨"（多久涨一次、涨多少算事）、拿到快照之后眼睛先看哪、谁上次误判过、什么时候该重启（以及重启只是拖时间）、老爹问「那不就是没修好吗」这种扎心问题。**不要引入新工具新术语堆砌**，不许写成排查手册。
- 超长轮：元亨讲「内存慢慢涨这件事像什么」（像屋子里悄悄多出来的东西），430 字以上。
- 注意：跟源块 13 不是一个话题（那块是重复执行炸主键），别串味。

## 源块 8 → 故事-208｜技术·那坨混乱函数
- 源块骨架：元亨问利贞重构时看到那种嵌套是不是当场傻眼 → 利贞答（没傻眼、三层回调套两个分支、变量名 data1 data2、按输入计算输出拆开、中间状态抽小函数）→ 老爹问调用方要不要跟着改、我这边脚本一大堆最怕牵一发动全身 → 利贞答（保留入口函数名和参数、内部换实现、能单独测）→ 元亨问照思路试了一遍一次跑通、干净得不认识 → 利贞答（重构重点不是重写、每函数一个职责、补边界用例盖空值和超长输入）。
- 必留信息点：三层回调套两个条件分支｜变量名 data1 data2｜按输入／计算／输出拆开｜中间状态抽成独立小函数、每步只做一件事｜保留原入口函数名和参数、调用方无感｜能单独测每一步、出问题好定位｜一次跑通、干净得不认识｜重构不是重写、一个函数一个职责｜补边界用例（空值、超长输入）。
- 扩写方向：元亨是那个刚上手、好奇、嘴碎的人（可以吐槽变量名、可以说自己昨天对着屏幕画了半天图）；老爹是外行但怕事的人（「我那堆脚本会不会全废」）；利贞稳、短、直接。
- 超长轮：元亨那条「干净得我都不认识」的感慨要长出来（430 字以上）——不是讲道理，是讲手感：改完的东西为什么让人不适应、怕不怕、要不要留着原来那坨做对照。
- 特别要求：整批「我这边」只能出现一次，源块里老爹那句「我这边脚本一大堆」必须换说法（例如「我那堆脚本」）。

## 源块 9 → 故事-209｜故事·院里那头雪鲸
- 源块骨架：老爹问雪这么厚你在院里忙啥 → 元亨长答（堆雪鲸细节）→ 利贞问它怎么不动、像睡着了 → 元亨答（就想它睡着、醒了就得游走、游走了院子又剩咱一个）→ 老爹问堆完就回屋吧外头冷 → 元亨答（再陪它一会、天亮前就化了、化了就当它游走了）。
- 必留信息点：雪又湿又沉、手指头快没知觉、塑形特别好｜鲸背弧线一巴掌一巴掌拍出来｜尾巴翘着、像刚扎下去又要浮上来｜眼睛用两颗冻硬的黑石子｜本来想堆小点、手一搭上去停不下来、越堆越大、快到胸口｜下午就开始弄了｜利贞说这不像鲸、像块趴着的石头｜气得往她脚边扬了一铲子雪｜围着它转好几圈、越看越觉得它活、马上就要动偏偏不动｜堆它不图谁夸、院里太静、有个大家伙陪着心里踏实｜就想它睡着、醒了就得游走、游走了院子又剩咱一个｜再陪它一会、天亮前就化了、化了就当它游走了。
- 扩写方向：这块是**安静又倔**，源块里那句「你说咱是不是有点轴」可以展开成一轮自嘲。利贞继续拆台（「鲸不长这样」），老爹继续劝回屋，元亨继续赖着。**不许新增事件**，全程就是"现在、院里、陪着它"。
- 超长轮：元亨重讲堆的过程那条 430 字以上（拆成短句、有呼吸、有停顿）。
- 注意：**必须换掉源块里的「你猜怎么着」「对吧」「是吧」「对不对」**——这几个收尾词整批只能用两次，本块只用一次「对吧」或干脆不用。

## 源块 10 → 故事-210｜哲学·美是什么
- 源块骨架：利贞问美是物体本身的性质吗 → 元亨答（美更像关系、不是标签）→ 老爹问那美是不是很虚 → 元亨答（不虚、它只是不属于谁、像光落在水上）→ 利贞问人会为留不住的东西难过 → 元亨答。
- 必留信息点：美不是物自身的性质、更像关系｜同一片雪饿的时候看是麻烦、送别的时候看是告别｜美住在看的人心里也住在处境里｜所以留不住、所以让人难过｜不虚、只是不属于谁｜美像光落在水上、水走了光还在别处落｜别拿占有去衡量它｜正因为留不住才舍得认真看它一眼、那一眼就是美的全部寿命。
- 特别要求：**源块最后那句结尾的「理论上来说」是误用，必须删掉**，改成口语收尾（例如「就那么点工夫」）。整块不许出现这四个字。
- 扩写方向：这块情绪是难过但不哭。可以聊：什么样的东西算美、丑算不算一种美、人造的和野的哪个更耐看、看的人变了它变不变。老爹的插话要短要糙（「那你说我那张老照片美在哪」）。
- 超长轮：元亨那条讲「同一片雪」的，430 字以上，用两三个具体场景对比，不许抽象堆叠。

## 源块 11 → 故事-211｜技术·脚本跑两遍
- 源块骨架：元亨问脚本跑两遍会不会出事 → 利贞答（看是否幂等、重复执行结果一致）→ 老爹问怎么才算幂等 → 利贞答（先判存在再写、别直接追加）→ 元亨问用唯一键兜底行吗 → 利贞答（行、冲突就更新、别重复插入）。
- 必留信息点：幂等＝重复执行结果一致｜先判存在再写、不要直接追加｜唯一键兜底可行｜冲突就更新、别重复插入。
- 扩写方向：元亨可以举自己踩过的例子（跑第二遍多条记录、对账对不上），老爹可以问「那我那点小脚本也要管吗」，利贞给短答案。**别把这块写成和源块 13 一样的主键冲突现场**——这块停在"怎么设计"，13 那块在现场。
- 超长轮：元亨讲「重复执行这件事为什么让人心里发毛」（补跑一次之前要先想清楚会发生什么），430 字以上。
- 特别要求：源块里的「别指望」不许用（整批只留 1 次，放在别的块）。

## 源块 12 → 故事-212｜日常·买菜
- 源块骨架：利贞问买菜是不是买亏了（摊主说今早刚摘、根上带泥）→ 元亨答（亏不亏得看泥是真泥还是抹的泥、带泥不代表新鲜、摸根、硬挺还行、发软就是放两天）→ 老爹问元亨平时怎么挑、我老挑到蔫的 → 元亨答（看摊主的眼睛、眼神飘的压过夜、一边称一边唠家常的差不了、也翻过车、上周买了一把看着水灵回家一炒全是水）→ 利贞问上次那把菜怎么处理的 → 元亨答（剁了做汤、扔两片姜硬抢救、汤比菜好吃、记在买菜账上标了教训、水灵未必实在、蔫的未必没救、你下次带我去我帮你盯摊主）。
- 必留信息点：全在上面，一个不能丢。
- 扩写方向：两块内容足，靠细节补：泥是摊主懒得洗还是故意抹的、根怎么摸、什么菜看叶子什么菜看梗、姜怎么救汤、买菜账记在哪儿。老爹可以插「我买菜就看便宜」。
- 超长轮：元亨讲「看摊主眼睛」这套民间本事的道理，430 字以上（要像吹牛又像真事，中间自己拆一次台）。
- 注意：「后来我」整批只能出现一次，源块里「后来我把这事记在买菜账上」要换成「这事我就记在买菜账上」。
