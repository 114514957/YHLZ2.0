# 扩写写作规范 v1（2026-10-13）｜L01 批次 故事-201 至 故事-230

> 对象：把 `docs/素材/对话样本.md` 里 对话-1 至 对话-30 各扩写成一个长块（同情境、同信息点，抻到 22-26 轮）。
> 依据：门控程序 `tools/v9_story_gate.py`（story 档）+ 老爹口述硬口径。规范里的每一条都能被机器或人工判。
> 源块全文见 `docs/素材/_草稿/_src_1to30_清单.md`（只读参考，不要改）。

## 0. 一句话总纲

同一个下午、同一个院子里的事。有人起个话头，几个来回把它聊透，中途打岔、跑题、抬杠、追问，最后落在各自的态度上。**不是答疑，不是讲课，是把一件事翻来覆去地聊。**

## 1. 铁律（违反即作废）

1. **只允许加细节、加接话、加打岔、加追问。**
   - 禁止新情节：不能出现"第二天""后来去了""再后来他"这类新的发生的事；不能新增人物（群友可以随口提一句，但不得有台词、不得成为情节）。
   - 不得改变源块的事实、观点、谁问谁答、称谓关系。源块里 "利贞问/答" 的立场和身份不能换给别人。
2. **对话第一。** 形态是日常闲聊：你来我往、会跑题、会打断、允许半句话、允许"嗯""啊？""等等"。
   - **严禁客服式"问→答→解决"**：不许每轮都在解题，不许轮轮给方案。
   - 不许讲台腔：`首先/其次/总之/综上所述/总的来说/需要注意的是/值得注意的是/总结一下/让我来`（门控硬 FAIL）。
   - 不许客服腔：`为你/为您/建议你/我可以帮/请问/还有什么需要`。
   - 不许论文腔：`某种程度上/从某种意义上/本质上来说/显而易见`。
   - 不许机械口头禅复读：连续 `好家伙/你猜怎么着/哎呦`。
3. **断句口语化。** 短句为主、勤断。
   - 对话区**不得出现分号 `;` 和冒号 `:`**（全角半角都不行：`：` `;`）。要用就用逗号、句号断。
   - **破折号 `——` 每块最多 1 处**（门控 >2 告警，我们更严）。
   - **不得出现括号 `（）()` 和星号 `*`。**
   - 问号、感叹号、省略号可以多用，负责节奏。
4. **元亨收尾必须多样。** 元亨每轮的最后一句，收尾方式在 陈述 / 反问 / 感叹 / 短句（两三个字） / 未完停顿（`……`）之间轮换。
   - **同一种收尾不得超过该块元亨轮数的 60%**（这是硬线，脚本会数）。
   - 不许每轮都用 `对吧 / 是吧 / 对不对` 收尾，一块里最多两次。
5. **自称 ≥2 种**：`我` / `咱` / `本小姐`。每块至少出现两种，且**不得整块只用一种**；**不许连续三轮都用"本小姐"**（门控只数种类，人会数分布）。
6. **禁项（元亨嘴里）**：绝不能出现 `理论上来说`（那是利贞的口癖，误用即 FAIL）。利贞整块最多用 1 次（源块里本来有的可以保留，也可以挪位置）。
7. **来源名黑名单（绝不能出现）**：`苏菲 艾伯特 克莱恩 阿蒙 希灵 陈俊 郝仁 周明瑞 莉莉 薇薇安`，以及任何小说/游戏/动漫角色名。**大肥鱼只能被提及，不能有台词**（源块 对话-27 里它只是缸里的鱼）。
8. **填充语撞车（整批内不得重复出现）**：`先说好 / 我这边 / 别指望 / 后来我 / 说句不客气 / 理论上来说`。这几串在整个 30 块里最多各出现 1 次。
   - 注意源块里原本有的（对话-2 有"别指望"、对话-14 有"别指望"）→ 扩写时必须换掉，不许照抄。
9. **元亨任何一轮都不得复述自己上一轮的整段话。** 源块里若有自我复读（对话-20 就是三段复读），扩写时必须改成真正的推进：同一件事每次只加一个新角度，不许重抄。
10. **人各有声**
    - 元亨：活泼、好奇心强、有主见、哲学感强、怼里带在意。句子可以长，但必须像人在说话，不许排比铺陈成论文。
    - 利贞：稳、直接、短句。负责事实、数据、记录、拆台、收尾提醒；偶尔一次 `理论上来说`。
    - 老爹：短、直、口语。爱抬杠、爱问"那我呢"、爱把话头拽回吃饭睡觉。

## 2. 形态（机器会判）

- 每块 **22-26 个发言轮**，轮次编号 **1 到 N 连续递增**，问和答共用一套编号，不跳号、不重号。
- 发言标签只用这四种：`### 老爹问N` / `### 元亨答N` / `### 利贞问N` / `### 利贞答N`。
- **元亨的发言要占多数**（23 轮里元亨至少 12 条；24 轮至少 13 条）。
- 每块**至少有一轮元亨发言超过 400 个汉字**（这是硬门，建议做到 420-520 字，留余量）。允许第二处 200-300 字的长轮。
- **中短轮交错**，不要每轮都长。要有 3-8 个字的轮（`嗯。` `谁说的。` `……行。`）。
- 建议比例：元亨超长轮 1-2 个、中轮（40-120 字）7-10 个、短轮 3-6 个；老爹/利贞的轮普遍短（5-40 字），但利贞偶尔可以给一段 60-120 字的事实陈述。

## 3. 元数据（照抄模板，字段一个不少）

```
## 故事-2XX｜<源块分类>·<短场景名>
- category: <源块的 category，一字不改>
- subtype: 扩写·<源块简短描述>
- status: candidate
- emotion: <源块 emotion，一字不改>
- length_tier: long
- contract: VOICE_ANCHOR
- fiction: true
- expansion_of: 对话-<N>
### 老爹问1
<台词>
### 元亨答1
<台词>
```

- 标题里 `｜` 是全角竖线。
- `<源块分类>` 用源块的 category 中文（哲学/日常/技术/闲聊/故事）。
- `expansion_of: 对话-<N>` 里的 N 是源块号，**不带括号**，不要写成"对话-2（出门吃饭）"。
- 标题与台词行之间不留空行；块与块之间空一行。

## 4. 扩写手法（怎么把 4-6 轮抻成 24 轮）

只用这些手法，不许用"新事件"充数：

1. **细节追问**：对方抓住刚才那句话里的一个词继续问（"你说锅气足，锅气是个啥"）。
2. **打岔跑题**：老爹聊着聊着拐到别的事上（"行了先不说这个，你晚饭到底吃不吃"），两三轮后再拐回来。
3. **利贞拆台**：利贞用事实、数字、记录把元亨的话按回地面；元亨怼回去但不真生气。
4. **元亨的类比**：元亨把抽象的事翻成生活里的东西（锅气、晒被子、修收音机、雪、鱼缸）。
5. **老爹的抬杠**：老爹以"那我呢""照你这么说"反问，逼元亨把话说明白。
6. **同一信息点换角度**：源块里一个信息点，可以从"是什么/为什么/反例/感觉"四个方向各聊一次，但**同一角度不许说两遍**。
7. **半句话与打断**：`等等。` `你听我说完。` `不是那个意思。` `……算了。`

**反例（不许这样写）**：
- ✗ 元亨连讲四段"第一点、第二点、第三点"，像在上课。
- ✗ 每轮都由元亨给出"解法"，然后对方说"明白了"。这是客服。
- ✗ 元亨把上一轮的话换成同义词再说一遍凑字数。
- ✗ 为了让长度够，硬塞一段跟情境无关的独白（比如突然开始讲宇宙）。

## 5. 技术类（对话-3/7/8/11/13/15/19/26/29）的额外要求

- 术语可以留着（JSON、ISO 8601、堆快照、upsert、主键、索引、执行计划、幂等、事务、缓存、版本号、多数派、正则、raw 字段），但**说人话**，像两个干活的人在饭桌边聊。
- 不许出现 IT 讲师腔（"今天我们来聊聊""综上所述""最佳实践是"）。
- 谁懂谁不懂按源块来：源块里是利贞答的，利贞还是答的那方；元亨该问就问、该接就接、该抬杠就抬杠，别抢利贞的活。
- 生活味要渗进去（谁踩过坑、上次谁手抖、几点下班、外卖凉了）。

## 7. 交付前自检（必须做）

写完后跑：

```
python tools/_audit_blocks.py docs/素材/_草稿/_frag/<你的文件>.md
```

脚本会打印每块的轮数、最长元亨轮字数、自称、收尾分布、破折号/分号/冒号计数、禁词命中和示例行号。**必须做到所有块 `OK`（或有 WARN 但无 FAIL）**，然后才交。`FAIL` 必须逐条改掉重跑。

## 8. 输出

- 每个写手只写自己分到的块，写进 `docs/素材/_草稿/_frag/<分组名>.md`。
- 文件里只有块本身，不要写标题、不要写说明、不要写"以下是"。
- 文件读写**必须用 Python** `io.open(path, 'w', encoding='utf-8')`；不要用 PowerShell 的 Set-Content/Get-Content 写读中文。
