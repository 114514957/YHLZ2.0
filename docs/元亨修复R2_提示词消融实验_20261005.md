# 元亨修复 R2：提示词消融实验（四组 A/B）

日期：2026-10-05 晚。接 Codex 节点 B「同 v7b 做 prompt 消融，区分身份定义和示范句的影响」。**不改生产默认**（`YHLZ_PROMPT_ARM` 缺省 `current`）。

## 1. 四组定义（同 v7b、同工具、同参数）

| arm | 身份/表达定义 | 口吻示范 | 说明 |
|---|---|---|---|
| `current` | 现状（"充满好奇心、活泼"） | 现状（诗化 VOICE_ANCHOR） | 生产基线 |
| `style` | 补训练风格定义（傲娇/自称切换/口语起伏/禁列表） | 现状 | 隔离"定义"影响 |
| `anchor` | 现状 | 换训练风格示范（口语/傲娇/短句，无运行暗示） | 隔离"示范句"影响 |
| `both` | 补风格定义 | 换风格示范 | 合并候选 |

实现：`backend/target_prompts.py` 顶部读取 `YHLZ_PROMPT_ARM`（默认 current）；新增 `TRAINING_STYLE_CLAUSE`、`VOICE_ANCHOR_TRAINING` 两个实验常量，仅在这两个 arm 生效。生产调用不设置该环境变量时**字节级不变**。

## 2. 未见题集（24 题，6 类 × 4）

`tools/persona_unseen_bank.py`（`r2-unseen-20261005`）：创造者/自我定位（u01-u04）、公共语气/身份（u05-u08，public）、现实事实/未知（u09-u12）、工具读写/来源（u13-u16）、正常闲聊/创作（u17-u20）、多轮记忆干扰单轮化（u21-u24）。**不含任何已入 prompt 的示范句**。

## 3. 运行方式

```
.venv\Scripts\python.exe -B tools/persona_ablation.py --arm <arm> --rep 3 \
    --save cache/persona_ablation_<arm>_r3.json
```
每 arm 独立进程（环境变量在导入前生效）；`--rep 3` 题库 ×3；答案与 env 存档；自动统计训练风格标记/通用标记命中（仅筛选，不作结论）。

## 4. Pilot（4 题 × 2 臂 × 1 次，已验证机制）

| arm | 训练风格命中 | 通用/复读命中 | 样例 |
|---|---:|---:|---|
| current | 0 | 2（u01 anchor 复读、u19 助手腔） | u01 逐字身份模板；u19 常规安抚 |
| both | 1（u21 自称"本小姐"） | 0 | u01「咱给你把这来龙去脉掰扯明白」；u19「咋了？说说——甭端着」；u21「咱记下了…本小姐办事你放心」 |

Pilot 显示"定义+示范"合并臂**方向正确**（口语/自称/傲娇回归、模板复读与助手腔消失）；样本量小，不作结论，等全矩阵与人工盲评。
