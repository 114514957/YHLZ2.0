# 主线设计：记忆内化 × 技能学习（v1）

> 双核心：①重要记忆内化为认知 ②技能记忆化为可复用能力。
> 一切机制=结构化条目+证据+防花瓶验收（无真效果即拆）。

## A. 重要记忆内化（Internalization）
**目标**：重要记忆不只可 recall，而是成为元亨认知/行为的一部分。

**现状基础**：L2(belief/去重/降级) → consolidate 自动(daemon 15轮/CLI) → 认知根基版本节 → persona_draft 每会话携带。

**缺口与设计**：
| 缺口 | 设计 |
|---|---|
| consolidate 提炼混杂工程细节 | **分级提炼**：core（世界观/身份/与老爹关系）→ method（协作方法论）→ meta（待证伪观点）；prompt 分类输出；persona 常驻仅 core |
| 无巩固重放 | 低活跃高 importance 条目定期"复核队列"（重激活→belief 佐证→可进下一轮 consolidate） |
| 证伪无触发联动 | consolidate stamp 记录→contradiction 触及→生成 refute 提案（批后版本节修正） |
| persona_draft 全段一次性注入（token 预算） | 常驻=core 节；method/meta 按对话主题检索注入（联想） |

**验收**：身份/世界观类重问自答一致（已现雏形）；persona_draft 输出可审计只含 core；QA 记忆类稳定。

## B. 技能记忆学习（Skill Learning，Voyager 式）
**目标**：从成功会话/多步工具流程自动沉淀可复用技能；条件触发时注入使用。

**设计**：
1. **skill 条目**（L2 type=skill）：{触发词集、步骤[]、来源会话、成功证据、调用计数}
2. **学习源**：成功话轮（任务完成+多工具调用/用户认可）→ LLM 提炼步骤；运行后 scan（daemon 周期）
3. **触发注入**：话轮前检索 skill（kw 命中触发词）→ system 增"可用技能：…"摘要 → 元亨照步骤执行
4. **去重**：summary hash+同触发词合并；**计数与 belief 管理**（用得多=留，失败反馈=降）
5. **验收**：真实技能闭环演示（如"回答项目史=先 ledger_search 再引记录号"自动沉淀→新话轮自动采用）；QA 工具使用模式变化；无触发证据不注入（防花瓶）

## C. 实现序
- A1 consolidate 分级提炼（prompt+过滤）→ A2 巩固队列 → A3 证伪联动
- B1 skill 存储+提炼管线（scan+LLM）→ B2 触发注入 → B3 计数/降级
- 每步=单测+真机（真实会话沉淀一条 skill/内化一条 core）+回归
