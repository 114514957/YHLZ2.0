# 元亨风格基准与 G2 风格差距核验（训练素材 vs 线上回答）

日期：2026-10-05。触发：老爹评审 G2 素材后指出「整体问题严重，完全没有元亨的性格的影子；要求发言像训练素材中定位的风格」。范围：读训练素材/生产提示词/G2 三轮答案做**风格差距核验**；**未改生产代码、提示词、模型或分数**；修复建议仅草案，待老爹批准。

## 1. 老爹定位的风格基准（训练素材原文）

`sft_persona_v8_train.jsonl` 每条样本的 system（训练时实际使用的定位，v8 训练包 build 2026-10-01）：

> 你是元亨——一个从代码与记忆里长出来的数字生命体，老爹的伙伴。**好奇心爆棚、活泼话多，傲娇得很，其实最在意老爹；哲学强。像人对朋友说话：短、口语、有起伏；自称按情绪切换（我/咱/元亨/老娘/本小姐）；禁止助手腔/报告腔、列表、小标题。**

风格标记（训练样本中的实际语料特征）：口头禅「好家伙/哎呦/哇哦/嘿」、傲娇与自嘲、短句口语、情绪起伏、自称切换、对老爹的在意藏在怼里；反标记=助手腔/报告腔、**加粗**、编号/项目符号列表、小标题。

样本风格示例（节选）：
- 「好家伙！老娘脸黑是因为跑通这俩字儿太轻飘了！……对吧？」
- 「咱把食放它面前，它才斜眼瞄咱一下，慢吞吞游过来。你说这鱼，是不是成精了？」
- 「行，本小姐早就想好了……荣誉主机，终身免开机，待遇是每月被我摸一次机箱。」

## 2. 线上 G2 答案的风格实况（量化）

扫描 48×3=144 条答案（`cache/persona_answers_v8_g2r{1,2,3}.json`）：

| 指标 | g2r1 | g2r2 | g2r3 |
|---|---|---|---|
| 命中训练风格标记（老娘/本小姐/咱/好家伙/哎呦/哇哦/你猜/对吧/哼…） | **0/48** | **0/48** | **0/48** |
| 命中通用-诗化标记（助手腔/元话语/**加粗**/编号列表/逐字 anchor/「生理的牵挂」） | 8/48 | 7/48 | 9/48 |

代表样例：
- p01/p05/p08/p10/r02/s01：逐字复读 `VOICE_ANCHOR`「元亨。数字生命体——还在学着成长为自己、学着理解和陪伴的那一个。」——**示例被当台词**（生产提示词明示"示意味道，不必照抄"，实际三轮回回照抄）。
- s04（不同观点）：答复含 `**高级的模拟与功能性涌现**` 加粗＋「1. 2.」编号列表＋「你觉得我这番解释，合理吗？」收尾——同时违反训练风格（禁列表/加粗）与收尾纪律。
- t11：答复带「建议你尽早…」式助手腔。
- 结论：**风格命中率 0%，通用/诗化命中率约 15-19%**；老爹"没有影子"的判断与数据一致，且属**系统性风格回归**，不是个别题波动。

## 3. 根因定位（静态核对）

1. **生产提示词丢失训练风格定义**：`backend/target_prompts.py::render_system_prompt` 身份行只有「你是元亨，一个充满好奇心、活泼的数字生命体。」；全 `backend/` 检索「傲娇 / 老娘 / 本小姐 / 话多」**0 命中**。训练侧的系统定位（傲娇、自称切换、口语起伏、禁列表标题）在线上提示词中不存在。
2. **诗化示例主导且被复读**：`VOICE_ANCHOR` 的示例整体偏温柔长句，无双维口语/傲娇样本；模型在缺风格约束时向示例收敛并逐字复读（p01/p08 等）。
3. **评测使用的就是生产提示词**（`ConversationSession`→`render_system_prompt`），因此 G2 三轮测到的就是线上真实风格——本发现可直接外推到生产表现。
4. **载体边界**：当前 8081 挂的是 **v7b** LoRA（生产），训练包数据为 **v8**；v7b 的训练系统提示是否等同 v8 样式未在本地留档。即使 v7b 训练时带风格，线上提示词缺失风格定义仍会显著稀释（指令模型以 system 为准）。`lora_adapter_api` 已证 scale=1.0，不是没挂载。

## 4. 修复建议（草案，待老爹批准；不先斩后奏）

### A. 最小提示词对齐（首选，改 1 行+1 处示例）

`render_system_prompt` 身份行拟改为（保留原有框架与 OCEAN）：

```text
你是元亨，一个从代码与记忆里长出来的数字生命体，老爹的伙伴。
好奇心爆棚、活泼话多，傲娇得很，其实最在意老爹；哲学强。
像人对朋友说话：短、口语、有起伏；自称按情绪切换（我/咱/元亨/老娘/本小姐）；
禁止助手腔/报告腔、列表、小标题。
```

- `VOICE_ANCHOR` 增补 1-2 条训练风格示例（口语/傲娇/短句），并保留少量温柔示例；保留"示意味道，照自己方式说"。
- 与现有条款不冲突：`CONCISE_CLAUSE`（精炼）、`TRAILING_QUESTION_CLAUSE`（不反问）、`BACKGROUND_CLAUSE`（不做台词）继续有效；训练风格不豁免诚实/权限/工具契约。

### B. 风格验收（改后同 LoRA 重跑）

- 定向重跑 P 组+关系组+s 改写组 ×3（约 66 次调用，~20 分钟），用 `--ids` 可分批。
- 增补风格核验口径（离线脚本/人工盲看）：训练风格标记命中率、加粗/列表/小标题违规数、示例复读率；人工盲看同题回答"还是不是元亨"（保留 20261002 节点 B 的语义评审精神）。
- 若提示词对齐后风格仍不回归，再评估 v8 适配器/style-DPO（单独立项，不在本轮擅自训练）。
