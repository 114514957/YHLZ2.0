# 风格进化设计（v1，ledger 0167）

> 目标：元亨的说话风格由与老爹的交互数据逐步塑造，而非文案写死。
> 验收主权=老爹听感（A/B 盲听）。本文件为工程设计；实现分批。

## 一、风格参数模型（五维倾向，每维 -1..+1）
| 维 | -1 | +1 |
|---|---|---|
| casual | 正式/书面 | 口语/随意 |
| concise | 展开详尽 | 简短精炼 |
| warm | 冷静克制 | 温暖有人情味 |
| playful | 平实 | 俏皮/幽默 |
| poetic | 直白 | 诗意化 |

每维=EMA 平滑的观测值（α≈0.3），初始 0（中性）。

## 二、信号源（已实现：target_style.py 规则采集）
1. **显式纠偏**（会话中出现"别太严肃/太长/说人话/详细点…"）→ 已落低权偏好条目（importance 4，evidence 带原文），同时驱动对应维 -/+。
2. 反馈缺失=不动（宁缺毋滥）。
3. （未来）可让元亨在话尾轻问"这样行吗"——仅当风格重大漂移时（低频）。

## 三、沉淀与应用
- 信号条目走 L2（风格偏好），未来 consolidate 时可进入 persona 风格段（同认知根基人机层）。
- 应用位：`render_system_prompt` tone 参数（预留；当前 SELFHOOD/独立思辨之上叠加风格倾向句，如"节奏明快些""更口语化"）。
- 应用时机：倾向值 |v|≥0.35 才注入（避免噪音抖动）；注入文本随值缓变。

## 四、验收（A/B 盲听，老爹主权）
- 场景：日常对话 3 组对比（当前风格 vs 风格倾向注入版，打乱顺序盲放）。
- 判据：老爹偏好任一组 ≥2/3 记 1 分；连续 5 轮 ≥4 分=收敛该维方向；反向即回退倾向值。
- 无偏好=不生效（保持默认）。

## 五、实施批次
- 批1 ✅ 信号采集（规则词表 + L2 存储 + 会话自动钩）——0 LLM 开销。
- 批2 风格条目→EMA 观测器（读 L2 风格条目聚合为倾向值）。
- 批3 persona 注入位（tone 参数）+ A/B 盲听工具（tools/style_ab.py 3 组随机序）。
- 批4 收敛后固化进 zh 版本（如风格准则句并入 prompts，仍需老爹确认）。

## 六、防花瓶
- 每批=测试（detect 规则/EMA 更新律/注入阈值）；听感验收不达标=倾向回退；
- 信号采集不打断对话、低权不污染高权记忆。
