# 启动入口重建 · 2026-10-22

> 结论：**入口没丢，是守护进程没了。** 旧的桌面快捷方式还在、指向的脚本也在，但那条链不写日志、不等就绪，服务死了没人拉起来，双击看起来就像没反应。

---

## 1. 现场恢复了什么

时间线（`cache\logs\launcher.log` / `boot.log`）：

| 时间 | 事件 |
|---|---|
| 18:32 / 18:45 | 启动成功：`spawn llama` + `spawn daemon`，5 秒后 `gemma=True daemon=True`，一直健康到 19:09 |
| 19:09 | 日志中断（守护进程消失） |
| 21:02–21:08 | 又有一段健康记录，然后再次中断 |
| 之后 | **8081 / 8321 全部不在** |

`launcher.log` 里每 72 秒一条 `ensure_stack` 是**看门狗**在打；它一停，说明守护没了，而 `YH_boot.bat` 起的是一次性 launcher——服务死后没有第二个东西来兜。

## 2. 旧入口的三个毛病

1. **不写日志**：`pythonw` 没有控制台，启动失败时什么都看不见。
2. **不等就绪**：`YH_workbench_normal.bat` 只等 120 秒就开浏览器，模型没加载完就打开一个打不开的页面。
3. **失败即关窗**：脚本出错直接退出，窗口一闪而过。

## 3. 新入口（已落地）

**`YH\start_yuanheng.bat`**（ASCII 正文 + CRLF，避免 GBK 解析问题）：

1. 先做 6 项前置检查（目录 / pythonw / python / launcher / watchdog / 日志目录）；
2. 拒绝管理员权限（管理员 token 会传染给 llama/daemon）；
3. 如果 8321 已经活着，只开浏览器，不重复拉起；
4. 否则依次起 launcher、watchdog、QQ Lite；
5. **最多等 180 秒**，每秒探测 8321，连上才开浏览器；
6. 超时则打印要看的四个日志路径并 `pause`，不再一闪而过；
7. 全过程写 `cache\logs\startup.log`。

**诊断模式**（不起任何东西）：

```
YH_workbench_normal.bat check
```

实测输出：

```
[check] root        : C:\Users\ACE_WA~1\YHLZ\YH
[check] pythonw     : ...\.venv\Scripts\pythonw.exe
[check] python      : ...\.venv\Scripts\python.exe
[check] launcher    : ...\tools\yhlz_launcher.py
[check] watchdog    : ...\tools\yhlz_watchdog.py
[check] workbench   : DOWN on 8321
```

**兼容**：`YH_workbench_normal.bat` 已改成一行转发到 `start_yuanheng.bat`。桌面快捷方式「YH 元亨利贞」本来就指向这个 bat，所以**快捷方式不用改**，双击走的就是新逻辑。中文名的 `启动元亨.bat` 也留了一份（同样转发）。

另外给了 `repair_shortcuts.vbs`：万一哪天快捷方式本身丢了，双击它就能重建桌面和开机自启两个 .lnk（开机自启指向 `YH_boot.bat`，不弹浏览器）。

## 4. 我没能替你启动

- 从沙箱里 `start` 出去的进程会在命令结束时被一起收掉（launcher 起来 3 秒就没了）；
- `schtasks` 被拒（"系统找不到指定的路径"）；
- 写桌面被拒（`拒绝访问`），所以快捷方式 .lnk 本体我没动——但它指向的 bat 已经换成新逻辑。

**需要你双击一次桌面「YH 元亨利贞」。** 起来之后 `/state` 和 `cache\logs\startup.log` 都能看到。起不来就把 `startup.log` 给我。

## 5. 教训（写进规程）

- 起服务只走一个入口：`start_yuanheng.bat`；`YH_boot.bat` 留给开机自启（静默）。
- **不要**在守护运行时用 `daemon_restart.py` 反复重启：它按端口属主杀进程树，守护和会话可能被牵连。
- 判断服务是否活着看**端口**，不看进程名——launcher 的 `_proc_alive` 曾被同名无关进程骗过（源码注释里记着）。
