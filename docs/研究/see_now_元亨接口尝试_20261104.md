## 2. 检查：它为什么能脱离 DSH 跑

`dsh-see-now@0.1.1` 的 package.json：

```
dependencies: None
peerDependencies: { "@deepseek-ai/dsh-tools": ">=0.1.0-rc.7" }   ← 可选
exports: . / ./pack / ./png / ./pipeline / ./tokens / ./capture /
         ./chat / ./speech / ./voice / ./interject / ./window /
         ./runner / ./loop / ./timer / ./tool-spec
```

也就是说：**只有 `src/index.js`（DSH 插件那半）需要 Cordis 上下文**；抓帧、判帧、拼图、编码、token 估算全是纯函数。这正是能接给元亨的前提。

关键 API（读源码确认，不是猜）：

| 模块 | 入口 | 用途 |
|---|---|---|
| `capture.js` | `spawnFrames({source,width,height,fps,ffmpegPath,onFrame,...})` | 起一根 ffmpeg rawvideo 管道，逐帧回调 |
| `pipeline.js` | `createPipeline({width,height,fps,...})` → `.push({t,buf})` / `.finish()` | 打分、切点、积分、留帧、出图 |
| `tokens.js` | `imageTokens(w,h)` | 按 42px patch 网格算 token |
| `pack.js` / `sheet.js` / `png.js` | `solve` / `composePacked` / `encodePng` | DP 装箱、拼图、零依赖 PNG |

`finish()` 返回 `{stats, sheets}`，每个 sheet 是 `{png: Buffer, w, h, frames:[{t,tier,via}], cells, from, to, why}` —— 这就是给元亨的"一眼"。

## 3. 桥接实现

### 3.1 `YH/tools/see_now_bridge.mjs`（Node）

两个模式，刻意分开：

- `--probe`：**不碰 ffmpeg**。合成 36 帧（3 段换面 + 移动竖条）喂进 pipeline，验证打包/编码/token 口径。
- `--capture --seconds N --quality low [--region x,y,w,h]`：真抓屏，走 `spawnFrames`；ffmpeg 缺失时返回 `ok:false` + hint，**不假装成功**。

输出约定：**最后一行是一行 JSON**（Python 侧 `json.loads` 最后一行），日志走 stderr。

### 3.2 `backend/see_now.py`（Python / 元亨侧）

- `TOOL_SPEC`：`see_now(seconds, quality, region)`，描述里写清了"静止画面几乎不出图""别连续频繁调用"。
- `probe()` / `capture()`：调 Node 桥，回 dict。
- `as_image_part(png)`：PNG → `{"type":"image_url","image_url":{"url":"data:image/png;base64,…"}}`，与 `target_orchestrator._to_data_url` 同口径。
- `render_summary(payload)`：给模型的一句文本（几帧、哪几秒、多少 token）。

## 4. 实测证据

### 4.1 `--probe` 输出

```json
{"ok":true,"mode":"probe","png":"…\\cache\\tmp\\see_now_probe.png","bytes":11062,
 "size":[798,462],"tokens":222,
 "frames":[{"t":0,"tier":1,"via":"start"},{"t":1,"tier":1,"via":"cut"},{"t":2,"tier":2,"via":"cut"}],
 "spans":[0,2],
 "stats":{"frames":36,"kept":3,"cuts":2,"sheets":1,"overflow":0},
 "ms":142}
```

36 帧进 → 3 帧留（2 次切点命中）→ 1 张图。**798×462 = 222 token**，与调研里记的口径完全一致。

### 4.2 出图（人眼验过）

2×2 宫格：左上暗色（帧号 1，带一条白竖条）、左下绿、右下黄（帧号 2/3），右上为暗色补位格。帧号烧在格子左上角。

### 4.3 元亨能不能看图 —— 三臂实验（llama.cpp :8081，gemma-4-e4b）

同一张图、同一个问题，只改投递方式：

| 臂 | 投递方式 | prompt_tokens | 回答 |
|---|---|---:|---|
| A 控制 | 纯文本，不带图 | 38 | 「红、橙、黄、绿、蓝、紫。左上角各一格。」← **幻觉** |
| B 看图 | 图放在 **user 轮**的 content parts | 210 | 「1、2、3。」← **读到了烧进去的帧号** |
| C 看图 | 图放在 **tool 结果**的 content parts | 266 | 「屏幕上是三个色块：左边是黑色，中间是绿色，右边是黄色。」← **对** |

三件事同时被证明：
1. 元亨的模型**确实具备视觉**（`/props` 里 `modalities.vision=true`，且实测读到了烧号的数字）；
2. 控制组会**编**（没图也能说出六种颜色）——所以"看图"必须用 token 数/正确性来验，不能靠它嘴上说；
3. **tool 结果里塞图也能被看见**，意味着最自然的接法可行：`see_now` 工具直接返回「文本摘要 + 图片 part」，不用额外一轮 user 消息。

> 注：222 token 是**图片本身**的账；C 臂 266 是含系统提示、工具定义与一轮对话的总 prompt。两者不矛盾。

## 5. 阻塞点：ffmpeg

`--capture` 失败时的返回：

```
{"ok": false, "mode": "capture", "error": "...", 
 "hint": "需要一个可用的 ffmpeg：设 YHLZ_FFMPEG 或把 ffmpeg.exe 放进 PATH"}
```

本机现状：PATH 没有 `ffmpeg.exe`，`~/.dsh/tools/ffmpeg/bin` 不存在，`PROJECT` 四层内也没有。**备一次 ffmpeg 同时解锁** see_now（给元亨）与 dsh-video-storyboard（给离线看视频）。

## 6. 下一步（接口收口，未做）

要真正变成元亨的一个能力，还差三处：

1. **注册 capability**：`backend/target_scheduler_tools.py`（或 capability registry）里加 `see_now`，handler 调 `backend.see_now.capture()`；
2. **让工具结果能带图**：`target_orchestrator.py` 现在把工具结果写成 `{"role":"tool","content": <str>}`。实测（C 臂）llama.cpp 接受 `content` 为 parts 数组并渲染 `<|image|>`，所以只需在拼装处允许 `content` 为 list；
3. **节流**：默认 `seconds=6`、单轮最多一次；避免模型连续自拍把 token 烧掉。

风险与边界（装之前要想清楚）：

- **隐私**：整屏会看到 QQ/密码框/私聊。默认建议走 `--region` 收窄，或只在老爹明确要求时调用；
- **它不是"看懂"，是"看见"**：只按画面变化筛帧，语义相近的两页可能算没变；
- **常驻抓屏 0.28~0.45 核**：一直挂着要算 CPU 账；
- **别当被动工具**：作者默认 `maxAutonomousWakes=8`、`idleStopMin=3min`，接进元亨时要显式关掉自主唤醒，只走"爹说看一眼"。
