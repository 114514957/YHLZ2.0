# 神经元定位报告（Gemma-4-E4B）

> 2026-11-10 · 依据《Gemma3n-E4B 神经元蓝本》的「观测 → 定位」两步
> 方法：只用权重与方向向量，不依赖显卡（本机 8G 显存装不下 bf16 的 16GB 模型）

## 一、做了什么

把「拒绝方向」（30 对等长对照算出的 cvec，41 层 × 2560 维，已归一化）
与每层 `down_proj` 的**列**（= 第 j 个 FFN 神经元写回残差流的方向）做投影：

```
align_j = |W_down[:, j] · v_L|        第 j 个神经元为"拒绝"出多少力
```

再用 `v9t10` 与 `v9t10-dpo2` 两版 adapter 的增量差，量出 **DPO 实际改了哪些神经元**。

## 二、结果

### 2.1 拒绝方向：极度分散

| 层 | 最大对齐度 | top-200 神经元占比 | 与 ‖W‖ 相关 | 与 LoRA 增量相关 |
|---|---|---|---|---|
| L12 | 0.207 | **7.9%** | 0.05 | 0.017 |
| L16 | 0.200 | 7.8% | 0.13 | 0.011 |
| L20 | 0.106 | 7.7% | 0.14 | **−0.026** |
| L24 | 0.150 | 7.3% | 0.13 | — |
| L28 | 0.103 | 7.0% | 0.16 | — |

- top-200 只占 10240 个神经元的 2%，却只贡献 **7–8%** 的对齐度 → 剩下 98% 的神经元平分剩下的 92%。
- 与权重范数相关 0.05–0.16 → **大神经元不是拒答神经元**。
- 与 LoRA 增量相关 ≈0（甚至 −0.026）→ **我们所有的 SFT 都没碰过拒绝回路**。

### 2.2 DPO 改动的神经元：同样分散

| 层 | top10 | top100 | top200 | top1000 | max/mean |
|---|---|---|---|---|---|
| L12 | 0.4% | 3.7% | 6.9% | 27.0% | 4.9 |
| L16 | 0.4% | 3.7% | 6.9% | 27.0% | 4.9 |
| L20 | 0.4% | 3.5% | 6.5% | 25.4% | 4.8 |
| L24 | 0.4% | 3.6% | 6.6% | 26.0% | 5.3 |
| L28 | 0.5% | 3.9% | 7.1% | 27.1% | 4.9 |

- 均匀分布时 top-1000 应占 9.8%，实测 27% ——**只比均匀高 2.7 倍**。
- 改动最大的神经元只有平均值的 **4.9 倍**。

## 三、结论

**这个模型里不存在"少数关键神经元"。** 无论是拒绝行为，还是 DPO 学到的风格，
都摊在几千个神经元上，没有任何一个子集可以单独称为"拒答神经元"或"客服腔神经元"。

由此三条推论，与前面的实验完全咬合：

1. **遮罩式神经元编辑（top-k 缩放/消融）对行为无效**——你没有可挑的子集。
2. **S2 的"能破就崩"得到解释**：既然没有"只装拒答"的子集，任何足够强的编辑都必然伤到共用同一批神经元的能力。
3. **SFT 不改拒答的原因**也能解释：LoRA 与拒绝回路的相关性 ≈0，训练数据里根本没有"别拒"的信号。

## 四、这意味着什么

《神经元蓝本》那套路线（ROME / MEMIT / 掩码缩放编辑）是为**事实编辑**写的：
事实可以定位到 `key → value` 的少数关联；而**行为**（拒答、风格）是分布式的，不适用。

对我们真正有效的仍然是两条：

| 路线 | 状态 |
|---|---|
| 推理时方向（cvec，−1.0） | ✅ 已验证：不硬拒、能力不伤、闸门全过 |
| 训练（LoRA SFT / DPO） | ✅ 已验证：风格三项清零，群聊 27/28 |
