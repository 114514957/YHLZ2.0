# 模型实验站 · 设计 v1（2026-11-06）

> 目的：**做受控实验**，不是做聊天界面。
> 已有的 `llm_workbench` 是「看/聊/跑分」，实验站是「**一次只变一个因素，把结果存成可比的数据**」。

---

## 0. 一句话

给一个配置（模型/适配器/向量/提示词/采样/语法），**自动起冷态实例 → 跑固定题库 → 存一份带配置哈希的记录**；
再给一个对比命令，把任意两次实验并排。

---

## 1. 边界：做什么，不做什么

| 做 | 不做 |
|---|---|
| 把 7 类因子（见 §2）组合成一个可复现的配置 | 不做新的聊天 UI（workbench 已经有） |
| 每次实验强制冷态、固定判据版本、记录后端 | 不追分数排行——**先看闸门，再看分** |
| 结果落盘成 JSON + 一行摘要，可 diff | 不自动调参、不自动搜（人定方向） |
| 一次只变一个因子（`plan` 生成变体） | 不碰生产链路（8081/QQ 那条） |

---

## 2. 实验因子（7 类，全部来自本机已支持的能力）

| # | 因子 | 取值 | 治什么 | 成本 |
|---|---|---|---|---|
| F1 | 适配器 | 单 LoRA / **多 LoRA 叠加**（`--lora-scaled A:0.7,B:0.3`） | 身份 vs 工具纪律的取舍 | 0（推理） |
| F2 | control vector | 文件 × scale × **层区间** | 风格/拒绝方向 | 0 |
| F3 | 提示词 | private / public / 自定义文本 / PROMPT_ARM 分支 | 群聊口径、身份 | 0 |
| F4 | 采样 | temp / top_p / **dry** / repeat_penalty / min_p / xtc | 复读、模板腔 | 0 |
| F5 | **语法约束 GBNF** | 禁问号收尾 / 限长 / 禁开头词 | 反问收尾（根治） | 0 |
| F6 | **logit-bias** | token→bias | 单个模板腔词 | 0 |
| F7 | 训练侧 | 数据版本 + 权重（Σw） | 能力本身 | 分钟~小时 |

**F1–F6 都不重训**——这是实验站第一批要榨干的。

## 4. 三条不变量（踩过的坑，写死）

1. **冷态**：每个配置**必须起新实例**再跑。台账 1068：被聊过一轮的实例，45 分掉 44，`cache_prompt=false` 也救不回来。
2. **后端固定**：记录 `ngl`，数字里标明 CPU/GPU。台账 1067：同一权重 CPU 与 GPU 差 1 分。
3. **判据版本固定**：记录 `persona_bank.JUDGE_VERSION`。台账 1077→1086 每次改判据都会改分数，跨版本比分数前先看版本号。

## 7. CLI

```bash
# 生成变体（一次只变一个因子）
python experiments/station.py plan --base configs/base_private.json \
    --factor F1 --values "v9t7:1.0,v9t7:0.7+v9t8:0.3,v9t8:1.0"

# 干跑（只打印将要下发的 llama-server 命令 + 题库计划，不起进程）
python experiments/station.py run --config configs/exp-0042.json --dry-run

# 真跑
python experiments/station.py run --config configs/exp-0042.json

# 列出 / 对比
python experiments/station.py list
python experiments/station.py compare exp-0041 exp-0042
```

## 8. 第一批实验（P0，全都不重训）

| 实验 | 因子 | 假设 | 判定 |
|---|---|---|---|
| E1 | F1 多 LoRA | v9t7 0.7 + v9t8 0.3 → 身份与工具兼得 | 56 题 ≥45 且 g18 过 |
| E2 | F5 语法 | 禁问号收尾 → st01/st03 这类不再挂 | 反问类失败归零 |
| E3 | F6 logit-bias | 压「哇哈哈」→ 模板腔率降 | 开头占比 <1% |
| E4 | F4 DRY | `--dry-multiplier 0.8` → 复读消失 | 复读检查 0 命中 |
| E5 | F2 向量 | 换「身份方向」向量 + 层区间 | g18/g09 同时过 |
| E6 | F3 提示词 | public 提示词里加一句「被问是不是 AI，答是 AI，但我是元亨」 | g18 过且不掉人格 |

每题跑 `repeats=2`，冷态，CPU（不占 8081）。

---

## 9. 与 workbench 的边界

- **workbench**：给人用——看版本、聊天、点一次评测、看记录。
- **实验站**：给实验用——批量、受控、可复现、能 diff。
- 两者共用 `persona_bank` / `group_bank` / `registry`，但**实验站自己起实例、自己收尸**，不依赖 workbench 的 8091。
