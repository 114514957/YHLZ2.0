## 3. 游戏台词：不能入训练集（版权），改为合规路径

**结论**：崩坏三 / 星穹铁道 / 原神 / 重返未来1999 的台词是**在版版权作品**（miHoYo / Bluepoch）。按《知识产权与来源策略》第 3.1 与禁止清单第 3 条（**改名/翻译/重写不免责**），**不得入训练集、不得整段引用**——否则整个 base/SFT 数据集的合规性会被这一点击穿。

**已落地的合规替代**：
1. 登记册新增 **SRC-030 游戏台词参考**（`reference_only`，注明四作与禁令）；
2. `docs/素材/_规范/美德主题骨架_v1_20261020.json`：把"美德/勇气"拆成 **6 主题**（勇气/守护/牺牲/诚实/同行/希望）+ **12 条元亨口吻原创样张**（明确标注非游戏原文、非名著原文）；
3. 这些原创样张可按你审改后进 SFT/风格池——**主题来自游戏，文字是我们自己的**。

> 若你要的是"游戏原句进训练"，那需要**版权授权**（或换成明确 MIT/CC0 的独立游戏文本）。否则我只能做到"学主题、写原创"。
