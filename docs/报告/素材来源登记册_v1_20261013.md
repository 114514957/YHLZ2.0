## 2. 当前缺口（如实记）

1. **15 个来源的"采集前评估"全部 not_done** —— 国标要求的动作，一次都没做；
2. **"采集后核验"只有 SRC-001/002/003 算 partial**（门控＋本次 4000 条机器抽检），**没有人工签字留痕**；
3. **SRC-002/003 的个人信息同意路径未定**（待老爹 D-1：自有群＋匿名化留依据／只取本人发言／停用群友发言）；
4. **SRC-015 缺 robots 证据记录** —— 本轮抓百科时没留证据，下次抓取必须先记。

## 3. 使用规则（硬）

1. **册上无记载的来源不得进集**；新来源先登记再取用；
2. `reference_only` **只许看、不许进训练数据**；
3. `nc_only` 池单独存放、单独统计，**不得混入商用路径**；
4. `pending` 的来源在核清前**不计入"已有可用训练数"**；
5. SRC-002/003 出集前必须完成匿名化（群号/QQ/昵称哈希化）并登记处理方式。
