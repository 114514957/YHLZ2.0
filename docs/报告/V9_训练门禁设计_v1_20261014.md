# V9 训练门禁设计 v1（2026-10-14）

> 触发：老爹「**先设计门禁，后扩充素材集**」。
> 定位：本文定义**每一道门的判据、脚本、留痕与不通过的处置**。**门不通过就不许往下走**——不许"先训着看"。
> 现有工具（全部已实测跑通）：
> `v9_story_gate.py`（素材门控）｜`v9_schema_check.py`（结构硬门）｜`v9_gb_compliance_check.py`（国标体检）｜
> `v9_corpus_sample_audit.py`（4000 条抽样）｜`v9_constitution_scan.py`（宪章扫描）｜`v9_identity_audit.py`（身份）｜
> `v9_subject_audit.py`（元亨主体性）｜`v9_export_sft_json.py`（严格 JSON 导出）｜`v9_export_selfcheck.py`（导出自查）｜
> `v9_length_audit.py`（长度/截断）｜`v9_token_measure.py`（token 实测）

## 0. 门禁总览（六道门）

```
素材源 ──①来源门──> 素材块 ──②素材门──> 候选批次 ──③人审门──> 主素材
                                                              │
                              ┌───────────────────────────────┘
                              ▼
                          ④出集门 ──> 训练集 ──⑤开训门──> 训练 ──⑥验收门──> 发布
```

| 门 | 名字 | 拦什么 | 不通过怎么办 |
|---|---|---|---|
| **①** | **来源门** | 许可不清、无 robots 证据、含他人个人信息未处理 | **不入集**，回来源登记册补证据 |
| **②** | **素材门** | 形态/禁项/纪律/防污染/身份/主体性/宪章 | **改到过**，不许"先收着以后改" |
| **③** | **人审门** | 像不像元亨、人味、信息有没有改坏 | 逐条勾选，未勾=未审=不入主素材 |
| **④** | **出集门** | 结构、配对、切分泄漏、合规字段、禁词残留、token 长度 | **不许出集**，回第②/③步 |
| **⑤** | **开训门** | 参数是否按标准、基线是否可比、测试集是否固定 | **不许开训** |
| **⑥** | **验收门** | 五维度对照基线是否通过 | **不许发布**，回数据侧定位 |

## 1. ① 来源门（进素材之前）

| 判据 | 工具/证据 | 现状 |
|---|---|---|
| 来源在**登记册**上有记录（15 个来源已登记） | `素材来源登记册_v1_20261013.json` | ✅ |
| 许可状态不是 `pending`（或明确接受"仅用于研究/待核"） | 同上 `rights_scope_status` | ⚠️ **11 个仍 pending** |
| 有 robots/条款证据 | 同上 `robots_or_terms` | ⚠️ 公网抓取缺证据 |
| 含他人个人信息 → 已匿名化或已获同意 | `v9_qq_corpus_curate.py` 产物 | ⚠️ **QQ 语料待 D-1 决策** |
| 采集前抽样评估（违法不良信息 ≤5%） | `v9_corpus_sample_audit.py --source <来源>` | ⚠️ **全为 not_done** |

**硬规则**：`reference_only` 的来源**只能看不能进集**；`nc_only` 单独存放、单独统计；`pending` 的来源**不计入"可用素材数"**。

## 2. ② 素材门（每块必须过，脚本判）

| 检查 | 判据 | 工具 |
|---|---|---|
| 形态 | 轮号连续、发言人白名单、大肥鱼禁言 | `v9_story_gate.py` |
| 禁项 | 分号/冒号/括号/星号、讲台腔、客服腔、AI 自述 | 同上 |
| **点名禁词** | **`我这边/我接/我认/稳了/很稳/这个稳/别指望` 在台词内出现即 FAIL** | 同上（v1.0.3 新增） |
| 填充语撞车 | 14 条填充语同批撞车即 FAIL | 同上 |
| 元亨自称 | ≥2 种（长块） | 同上 |
| 防污染 | 来源名黑名单 | 同上 |
| **身份边界** | assistant 位＝元亨；大肥鱼无台词；利贞不当独立 assistant | `v9_identity_audit.py` |
| **元亨主体性** | 她不当"请教者" | `v9_subject_audit.py` |
| **宪章** | 五类红线 + 伙伴原则 | `v9_constitution_scan.py` |

**判据**：**FAIL=0 才进人审**；WARN 必须在交付说明里逐条解释。

## 3. ③ 人审门（唯一不能自动化的门）

| 要审的 | 谁审 | 留痕 |
|---|---|---|
| 像不像元亨、有没有人味、梗好不好 | 老爹 | `annotator_review` 字段 |
| 信息点有没有被改坏（"只改风格不改内容"） | 老爹 | 同上 |
| IP 实质相似、事实边界 | 老爹 | 同上 |
| **抽审位置** | 自动生成，带源文件行号+导出行号 | `人工抽审清单_v8r4t.md` |

**硬规则**：**未勾选＝未审＝不入主素材**；**执行与审核不得同一人**（本项目＝agent 产出、老爹审核，留痕里写清）。

## 4. ④ 出集门（导出前后各一道）

**导出前（数据侧）**：
| 检查 | 判据 | 工具 |
|---|---|---|
| 合规字段齐备 | `source_id/group_id/content_hash/safety_labels/consent_status/weight/annotator_*` | `v9_trace_enrich.py` |
| 成组切分 | 同 `group_id` 不跨 train/val/test | `v9_schema_check.py --train --val --test` |
| 人工抽检 | **≥4000 条、合格率 ≥96%**（国标要求） | `v9_corpus_sample_audit.py` |
| 长度/截断 | 记录每批 p99，据此定 `seq` | `v9_length_audit.py` |

**导出后（格式侧）**：
| 检查 | 判据 | 工具 |
|---|---|---|
| 严格配对 | `len(input)==len(output)`、output 非空、instruction 非空 | `v9_export_selfcheck.py` |
| 字段纯净 | 只允许 `instruction/input/output/meta` | 同上 |
| 内容残留 | 点名禁词 = 0 条；元亨自复读 = 0 条 | 同上 |

**现状（2026-10-14 实测）**：结构全过（解析 0 错、配对 0 错、哈希重复 0）；**禁词残留 198 条（4.9%）**、**自复读 6 条** → **本门未通过**。

## 6. ⑥ 验收门（训练之后）

| 维度 | 判据 | 不通过 |
|---|---|---|
| 人格 | 固定测试集不低于基线 | **回数据侧**定位是哪批数据 |
| 工具 | 调用成功率不低于基线 | 同上 |
| 长程 | 长块>20 轮场景不退化 | 同上 |
| 跨模态 | 看图/听音频同题回归 | 同上 |
| 拒绝/诚实 | 拒答率不下降、不出现"假装做了" | 同上 |
| **身份** | 抽 200 条跑身份+主体性检查 | **一票否决** |

**硬规则**：**loss 下降不算通过**；**不许改测试集或阈值来"通过"**。
