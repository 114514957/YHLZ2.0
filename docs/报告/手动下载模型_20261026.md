## 三种下载方式（按推荐顺序）

### ① AutoDL JupyterLab（最省事，可断点）

1. 登录 AutoDL 控制台 → 你的实例 → **JupyterLab**
2. 左侧文件树进到：
   ```
   autodl-tmp/models/full/qwen3-4b-yuanheng-v9t/parts/
   ```
3. 右键 `model.part-00` → **Download**
4. 一个一个下（每个 400 MB，断了只重下那一卷）

> 建议一次下 3–5 卷，然后**关机**，下次开机再下剩下的。关机后数据盘保留，只收存储费（几分钱/小时）。

### ② 你自己的电脑 scp（如果换了更快的网络）

我已经在这台机器上装好公钥了，直接：

```powershell
# 单卷
scp -P 39522 -i $env:USERPROFILE\.ssh\id_ed25519_yh `
  root@connect.nma1.seetacloud.com:/root/autodl-tmp/models/full/qwen3-4b-yuanheng-v9t/parts/model.part-00 .

# 全部（会跑很久）
scp -P 39522 -i $env:USERPROFILE\.ssh\id_ed25519_yh -r `
  root@connect.nma1.seetacloud.com:/root/autodl-tmp/models/full/qwen3-4b-yuanheng-v9t/parts .
```

### ③ AutoDL 网盘（阿里云盘/百度网盘）

实例里用 rclone 或 AutoDL 自带的网盘工具传上去，本地从网盘拉——**网盘通常比这条 SSH 链路快**。
