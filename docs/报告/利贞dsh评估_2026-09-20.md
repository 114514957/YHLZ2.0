## 结论摘要
1. **项目适配成立**：dsh 以工作区目录为根，**自动读取并遵守仓库 AGENTS.md**（自发提到台账纪律）；读写文件、跑命令、中文汇报全部正常。
2. **多轮会话（利贞 #dev→#a 流的关键）成立**：SDK `session_id` 二跑可续上下文（R2 正确回忆上一轮文件与内容）；**headless 模式无 resume**（一次性，推理→stderr、最终答复→stdout）。
3. **完全自主可配**：`DSH_PERMISSION_MODE` 三档（read-only / workspace-write(ask) / **danger-full-access(never)**），本轮用 full-access（你选的完全自主）。
4. **生态可用**：插件系统=pnpm（"一切皆插件"）；实测三方插件 `dsh-plugin-memtrace`（GitHub，双时态代码图记忆）**11.6s 装好**，自动注册 bundle 并编入 MCP row（`mcp-memtrace`）。
5. **审计/成本可查**：会话 JSONL 含 `tokenUsage`（totals+每轮 buckets）与 `contextBreakdown`（system/tools/messages 分账）。
6. **建议**：进入阶段 2 做 `dev_runner` 双轨原型（SDK 后端），保留 opencode 回退；**是否替换**待阶段 2 数据再定（你定的"先详完再定"）。

## 实测结果
| 项 | opencode（现利贞） | dsh headless | dsh SDK |
|---|---|---|---|
| S1 单任务（读文件+写文件+跑命令+汇报） | ✅（JSON 事件流） | ✅（stdout 纯最终答复，stderr=推理） | ✅（`final_response`） |
| 多轮续跑 | ✅ `--session` | ❌ 无 resume（一次性） | ✅ `session_id` 复用（实测） |
| 结构化结果 | JSON 事件（需解析） | 纯文本 | `final_response/finish_reason/notifications/events/session_id` |
| 用量/成本 | 逐步 tokens+cost | 会话日志 tokenUsage | 会话日志 tokenUsage+context 分账 |
| 权限模型 | 靠 agent 提示词约束 | 三档 preset（本轮 full-access） | 同左（可 patch） |
| 插件生态 | 无（agent/模型配置） | 同左 | pnpm 插件+MCP 自动编入 |
| 运行时体积 | 全局 npm 包 | 复用 npm dsh 包 | **venv 255MB**（含内置多 provider runtime） |

样例数据：headless S1 用量 `uncachedInput 8304 / output 945 / cacheRead 24960`；tools schema 占上下文 ~6481 tokens（占大头，后续可裁剪工具集）。opencode 同任务逐步 `total ~9.6k tokens / cost ~$0.0001/step`。

- profile 目录 = `package.json(dsh.profile.bundles) + cordis.patch.yml`；`dsh plugin` 即 pnpm 转发
- 三方插件实测：`github:syncable-dev/dsh-plugin-memtrace` → 依赖安装 → **bundle 自动登记** → `dump-config` 出现 `mcp-memtrace`（serverName=memtrace，可用 `MEMTRACE_BIN` 覆写）

- 结论：生态链路（发现→安装→组合→运行）完整、可用

## 项目适配发现
- ✅ 工作区=cwd；会话按项目分目录（`session_projcache`）；AGENTS.md 生效
- ✅ key 继承（走项目 .env）；模型默认可配（本例 `deepseek-v4-flash` 实测可用；headless 默认 `deepseek-flash`）
- ⚠️ 未知待阶段 2：workspace-write(ask) 模式在非交互下如何走审批（需要 QQ #a 桥）；SDK **跨进程**同 session_id 能否续上（本轮同进程）；超时/中断语义
- ⚠️ dev preview（0.1.5-rc 系列）会有破坏性变更 → 若采用需**锁版本**、opencode 保底

## 风险
1. 完全自主=danger-full-access（FS 边界关闭）；评估中安全，生产建议 workspace-write + 审批桥或限定沙盒路径
2. 体积/依赖：SDK 255MB + pnpm store
3. 生态件质量参差（三方插件 0.1.x），引入前需代码审阅
4. 版本漂移（RC）→ 依赖锁定与升级流程
