## 结论（数据支持的部分）

1. **模型/范式是重要因素**：训练式 DDSP 的音色相似度 **0.60**，零样本 SoulX 只有 **0.47–0.48**（相对差 ~25%）。"换个引擎能更贴元亨嗓"——成立。
2. **"加长参考音"被证伪**：A1（9s 长参考）0.4732 ≤ A0（2s）0.4834，基本持平略降；这条低成本假设不成立。
3. **但不仅是模型**：两个引擎 8kHz 以上能量都只有 ~1%（原唱 5.7%）。音频都"闷"——因为①元亨嗓数据本身是 Edge 合成（带宽受限）、②声码器平滑。**"清晰/亮"需要补高频**，这不是换 SVC 引擎就自动解决的。
4. **DDSP 有"爆"的隐患**：削波 0.098%（SoulX 的约 1000 倍）、跳变 max 0.53 → 直接上会听到毛刺/爆点；必须加输出级限幅与削波监测（高音闸）。
5. **性能**：DDSP 推理秒级且可与聊天共享 GPU（不需要唱窗）；SoulX 需唱窗 ~66–100s。DDSP 在"性能"维度占优。

## 局限与待补

- CAM++ 训练于说话人识别，跨"歌唱域"只有**相对比较**意义，不能当绝对音质分；
- 未做响度对齐（试听包已附 RMS，建议对齐音量再比）；A1/B0 比 A0 响 2–2.5dB；
- 未做 ASR 吐字检查（下一步可补 `cover_asr_check`）；
- DDSP 历史上听感曾输给 SoulX（0480 前后）——本次相似度更高≠听感一定更好，**请老爹用试听包裁决**。
