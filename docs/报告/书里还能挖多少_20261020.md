# 书里到底能挖多少：小说对白 + 教材/工具书 · 2026-10-20

> 老爹：「那么多书里就这点能用的？还有教材书，工具书」。
> 结论：**之前确实只用了 2,322 个 8k 块（PT 用）**，小说里还有两类没挖：**对白**和**章节内知识**；
> 教材/工具书本机没有，改走**开放许可**（维基教科书/词典/百科，CC BY-SA 4.0）拉。

## 1. 小说：从 2,322 块 → 还能挖出 4,434 组对白

`tools/v9_novel_dialogue.py`：从 4 本书里抓引号对白，连续 6 句成组，带说话人线索：

| 书 | 对白组 | 抓到引号 |
|---|---:|---:|
| 希灵帝国 | 1,321 | — |
| 异常生物见闻录 | 1,335 | — |
| 诡秘之主 | 1,333 | 8,003 |
| 苏菲的世界 | 445 | 2,676 |
| **合计** | **4,434** | — |

过滤：中文占比 <60% / 单句 <6 字 / >80 字（太长像独白）都丢；内容哈希去重 + 5-gram 近重去重。
产出 `data/pd/v9_novel_dialogue.jsonl`（license `owner_waiver`，老爹 D-3 裁定）。

> 这批是**多角色对白**，适合教"说话节奏/口吻切换"，不进 SFT 人格集（避免串口吻），只进 PT 的 speaking 池。

## 2. 教材/工具书：本机没有，改拉开放许可的

本机 `下载物象/图书素材` 只有 4 本小说，**没有教材/工具书**；全项目也没有 epub/pdf 类教材。
所以用 MediaWiki API 拉三类**明确可用的开放许可文本**：

| 源 | 相当于 | 许可 | 已拉 |
|---|---|---|---|
| `zh.wikibooks.org` | **教材**（数学/物理/编程/语言） | CC BY-SA 4.0 | 21 块 |
| `zh.wiktionary.org` | **工具书/词典**（释义、用法） | CC BY-SA 4.0 | 9 块 |
| `zh.wikipedia.org` | 百科（概念/定义/综述） | CC BY-SA 4.0 | 15 块 |
| **合计** | | | **45 块**（首批） |

做法：`generator=random` 取标题 → 逐页 `prop=extracts&explaintext` 取纯文本 → CJK 过滤 → 6000 字分块；
每块带 `license`、`source_url`、`title`。慢速（0.8s/页）+ 失败重试。

> 已经后台跑 **120 页/源** 的第二批，回来会并进 context 池。
