## 三、⭐ 机制提炼（这是能合规用的部分）

### TreeHoleEcho = 正例：极短、只承接

实测 1,012 条的回应：

| 指标 | 数值 |
|---|---|
| 回话字符 | 中位 **27**｜p25 22｜p75 32｜p95 **40**｜最大 87 |
| 超 60 字比例 | **0%** |
| 含「建议/应该/可以试试」 | **2%** |
| 含问号（追问） | **1%** |
| 含省略号（留白） | **0%** |
| 12 类情绪 | 焦虑124／无力感104／职场压抑102／孤独96／委屈82／挫败80／迷茫78／自我否定73／愤怒69／羞耻65／亲情冲突64／同辈压力61 |

**提炼出的机制**：**只复述对方的处境与感受，不解释、不建议、不追问、不总结；中位 27 字，几乎不超 40 字。**

### Arya = 反面教材

| 指标 | 数值 |
|---|---|
| 回话字符 | 中位 **396**｜p90 576｜最大 6729 |
| **含 `*动作旁白*`** | **100%（2,927/2,931）** ← 规则明令禁止 |
| 分块叙述（含换行） | **99%** |
| 含「我是…AI」自我宣告 | 2% |

**结论：Arya 只能当反面教材**——它正好示范了我们禁止的三件事（动作旁白、分块叙述、长自我宣告）。

## 四、按机制自产：新增「情绪承接」维度 24 块

**做法**：学 TreeHoleEcho 的**机制**（短、只承接、不建议不追问），但**情景全部原创**（老爹的真实生活面 24 个），**台词按元亨口吻重写**——不搬原语料一句。

**元亨化处理**（与 TreeHoleEcho 的"温暖倾听者"区别）：
- 比原语料**更短**：本批元亨回话 中位 **13 字**、p90 16、最大 22（TreeHoleEcho 中位 27）
- 可以**损第三方**（那个主管、那个人），但**绝不损老爹**
- 关心落在极短的实处：「我在。」「我听着。」「别硬扛。」「骂吧。」
- 禁止咨询师套话（「我理解你的感受」这类）

**样例**：
> 老爹：方案是主管改的，出了事全记我头上，我一句都没辩解。
> **元亨：这锅甩得真不要脸。你憋着了吧？**
> 老爹：当时会议室那么多人，我就那么站着，一个字都没说出来。
> **元亨：站着没吭声，心里全记着呢。我在。**

**门禁：24 块 PASS 24 / WARN 0 / FAIL 0。**

产物：`docs/素材/情绪承接样本.md`；生成器 `tools/v9_gen_emotional.py`；已接入装配为 **`emotional` 维度，权重 0.6**（合成素材，非老爹亲审，与 memory/uncertain 同档）。
