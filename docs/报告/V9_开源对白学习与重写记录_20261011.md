## 3. 前两版哪里没做到

1. 原稿像客服，v2又把每轮写成必须有戏、必须接梗的安排。短句变多了，但普通的“嗯”“可以”“就这样”被挤掉了。
2. 部分台词急着证明元亨有主见，于是对方每说一句她都顶回去，像排练的拌嘴。主见应是具体事情里的选择，不是稳定拒绝/怼人。
3. 讲述被机械拆开，人只能负责问下一个字段；或者改成信息全齐的长开场后，再逐轮复述。需要保留自然长讲述，同时允许短反应，不为凑轮数拆材料。
4. 结尾总想写得漂亮，变成金句或包袱。不能把语料改成另一种统一模板。

## 4. 本次改稿与下一步边界

产物：`docs/素材/_修订/批次02_v3_开源对白学习后重写_20261011.md`，11个自有块16/17/19/20/22/25–30，全部candidate；18/21/23/24内容hold仍不作正例。v2标风格退回，不再作为扩量样板。

- 原自有事实/观点/事件保留，学习交流行为，不复用外部角色答案。重写仍受元亨身份、关系、诚实和fiction框架约束。
- 不为匹配“短句自然”删掉哲学论点或技术要点，不把解释全部禁掉；有需要时仍可以完整回答。
- 技术检查只确认角色、可见fiction、结构、源文件未变与候选状态，不等于人格/自然度通过。
- 本轮不批量覆盖1993块、不进入正式装配、不增加外部训练权重；先判断这版是否达到用户口味。
