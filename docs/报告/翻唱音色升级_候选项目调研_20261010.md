## 一、先把"音色差"的可能原因摆出来（决定往哪测）

| # | 假设 | 依据 | 验证动作（待拍板） |
| --- | --- | --- | --- |
| 1 | **参考音（prompt）质量/时长是零样本上限** | 当前 Xiaoyi 嗓参考 = Edge 合成克隆 `ref01.wav`（约 2s，音色本身就"电子"）；念山AI 实测：扩散步数只影响伪影，**相似度上限由参考音频与训练数据决定** | 换 5-30s 干净干声参考再唱同一首对比 |
| 2 | **输出带宽**：SoulX-SVC 输出 **24kHz 单声道**（高频上限 12k） | 现行链路 `wsl_soulx_svc.sh` 产物 24k；RVC/Seed-VC/HQ-SVC 均 40-48k | 同一干声出 24k vs 44.1k 版本 A/B（或试超分后处理） |
| 3 | **范式差距**：零样本 SVC（SoulX）vs 训练式（RVC/so-vits） | 中文社区普遍结论：翻唱成品质量/相似度 RVC 系通常更好；训练式用 10min+ 目标人声把音色"焊死" | 用元亨嗓素材训一个 RVC 模型对比（上限路线） |
| 4 | 输入链残留（混响/和声漏音）拉低清晰度 | 项目已有 MSST/aufr33 降噪、MDX 分轨资产 | 干声预处理链 A/B |

> 结论先行：**可能不用换全套模型，先把参考音和输出带宽这两件事测掉**，再决定是否换引擎。

## 四、路线建议（供拍板，未动手）

**第 0 步（零成本先测，半天内可出结论）**
1. 备一段 **5-30s 干净干声**做新参考音（可从现有素材剪辑），SoulX 同歌 A/B；
2. 输出升采样/带宽对比（24k→44.1k 后的听感）；
3. 用 `verify_cover.py`（内容/音高）已有指标 + 新增 **说话人相似度（CAM++/ECAPA cos）** 做客观对照。

**第 1 步（引擎对比，各约半天）**
- **Seed-VC**：ComfyUI 节点/念山AI 双路径现成，44.1k 输出，Windows/4GB 已实测；
- **HQ-SVC**：AAAI 2026 论文直击"高质量零样本+超分"，权重已放出，WSL 可跑。

**第 2 步（音色上限路线）**
- **RVC 训练元亨嗓**：需 10min+ 干净人声语料（可用已录/合成语料，先用现有 DDSP 训练素材试）；推理极轻（100-300MB 模型），可挂进现有工作台/ComfyUI（TTS-Audio-Suite）。

**第 3 步（后处理）**
- 音频超分/降噪/去混响补齐（项目已有 MSST/aufr33 资产，可与新引擎叠加）。

**ComfyUI 定位**：作为"实验台/可视化编排"可选手臂（TTS-Audio-Suite 或独立 ComfyUI + Seed-VC/RVC 节点）；注意其常驻显存与现有 8GB GPU 互锁排班冲突——建议只在唱窗/专用时段跑。

## 七、目标与验收标准（老爹 2026-10-10 追加）

1. **吐字清晰**：歌词逐句可读（ASR 可读率不低于现档/原唱人声同级）；内容 cos 保持良好档。
2. **高音不爆**：无削波（目标 TP ≤ -1 dBTP）、无爆音跳变/力度失控；高音段音高跟随，不以强行降调破坏听感。
3. **整曲完整**：一首歌端到端一次生成（分轨→换声→混回→母带→入库），无掉字、无断裂。
4. **完善的工作流**：全自动、有分层留档、自动验收（不合格能定位到段）。
5. **高性能**：整单时长有预算并持续优化（当前 SoulX 整单基准 ~171s/4min 歌）；与聊天 GPU 互锁排班兼容。

## 八、工作流 v8 设计草案（训练式主线，待开工令）

主线思路：**保留现成三轨/验收/排班框架，把"干声换声"引擎换成"元亨嗓 RVC（2h 语料训练）"，并加"高音质量闸"**。

```text
选歌 → 分轨(现成 demucs+MDX) → 干声净化(降噪/去混响) → 换声引擎【RVC 元亨嗓】
    → 高音质量闸 → 三轨混回(现成 wsl_mix3) → 自动验收(内容/音高/相似度/爆音) → 母带 → 入库
```

- **引擎**：RVC v2（检索式，推理快、吐字稳、音色贴）训练自 `yuanheng_2h`；SoulX-SVC 保留为对照/备援嗓。
- **高音质量闸**：F0 超界段检测（如 >500Hz 占比）+ 削波/爆音跳变检测；超限按段处理（分段重跑 / -1~-2 半音微降调，和声伴奏同步，沿用 0488 例外条款）。
- **性能**：RVC 推理预期显著快于 SoulX 逐段推理（待实测）；分轨/F0/混回复用现成；目标整单不低于现基准。
- **兼容**：训练一次性（唱窗之外后台跑）；推理挂进现有 `sing_start`/`cover_job` 编排；ComfyUI 不作主线（可选实验台）。
- **对比基线**：同一首歌（如《虚构义》）SoulX vs RVC 双版盲测 A/B。
- **风险与旁支**：① 语料为**说话干声**，歌唱高音/长音表现需 A/B 验证，不足时补唱腔数据（合成或实录）；② 低成本旁支：SoulX 路线换 `ref06_2h` 长参考 + 干声净化，先看能改善多少。
