# 问句化记忆 + 思维链素材 · 2026-10-20

> 老爹「都要，除此之外，有没有助于思维链的？」——两件都做：
> ① 问句式 memory（保留原陈述式）；② 可验证的思维链（CoT）素材。

## ① 问句式记忆（`tools/v9_memory_qstyle.py`）

- 来源：`记忆样本_v2.1.md` 的 **235 个 keep 块**（摘要 + 原答案借语气）
- 做法：摘要取关键短语做问句（6 种模板轮转），答案 = 先复述事实主干 + 一句元亨短反应；
  **校验**：答案必须含摘要里的实词，否则丢弃（丢 8 条）
- 产出：`data/finetune/memory_qstyle.jsonl` **470 条**
- 样例：
  > Q：我上次提的坚持早起读书三个月，你还记得不？
  > A：记得。坚持早起读书三个月，能感到自己学习的能力越来越强了。本小姐坚持早起读书，存在稳定性都妥了
  > Q：问你个事，老爹明确要求还记得吗？
  > A：记得。老爹明确要求：必须实话实说，做不到就是做不到，他会帮忙。先说要干啥

> 陈述式（听到陈述→短反应）**保留不变**，问句式是新增一层；两层共存，覆盖两种真实场景。

## ② 思维链（CoT）素材（`tools/v9_cot_build.py`）

定位：**可验证的推理过程**，不是长篇解释。四族，全部程序生成 + **答案经代码校验**：

| 族 | 条数 | 形态 | 样例 |
|---|---|---|---|
| `cot:arith` | 120 | 多步算术应用题 | 一盒笔 70 支，8 盒，用掉 40 → "70×8=560；560-40=520。那答案是 520。" |
| `cot:logic` | 120 | 排序/传递推理 | "林一比小丁高，小丁比老周高，谁最高？" → "林一最高。" |
| `cot:multihop` | 120 | 两跳合并（4 条 + 补 3 条） | "4+3=7。那答案是 7 条。" |
| `cot:finderr` | 120 | 找错（8×4=33 还辩"先加后乘对"） | "8×4 是 32 不是 33；加乘不能换序。" |
| **合计** | **480** | 全程口语短推理、无列表/Markdown、≤130 字 | |

设计要点（防模板记忆）：每人名/数字/问题措辞随机化；族内 group_id（`cot:<family>`）保证切分不串族；
`simulation: true / generated: true` 全程标记。
