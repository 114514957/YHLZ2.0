# 记忆召回评测 · 首次出数（2026-11-18）

> 目的：补上台账 1236 §6.4 步2/步4 与 1174 D8 一直缺的量化证据。
> 跑器：`tools/recall_eval.py`（可复跑）；数据集：`data/eval/memory_recall.jsonl`（45 条）。

## 一、口径先说清（第一版测错了）

| 路径 | 说明 | 结果 |
|---|---|---|
| `recall_strict`（3-gram≥2） | **不是**生产路径 | 命中 12.0%／精确 42.9% |
| `semantic_recall` | **生产实际使用**（`YHLZ_MEMORY_RECALL=v2`） | 命中 80–96%／精确 76.9% |

第一版拿字面路径测，得出"命中 12%"的结论是**错的**——生产走的是语义路径。
教训与台账 1271 同源：**验收标准必须与实际路径一致**。

## 二、生产路径真实成绩（45 条：该命中 25 / 不该命中 20）

| 阈值 | top-k | 精确率 | 命中率 | 误召回 |
|---|---|---|---|---|
| 0.45（现值） | 1 | 76.9% | 80.0% | 10.0% |
| 0.45 | 3 | 32.0% | **96.0%** | 10.0% |
| 0.55 | 1 | **78.3%** | 72.0% | 5.0% |
| 0.55 | 3 | 46.8% | 88.0% | 5.0% |

- **命中率达标**（目标 ≥60%）：top-3 = 96%，top-1 = 80%
- **精确率未达标**（目标 ≥80%）：最高只到 78.3%

> 注：精确率在 top-k 下天然被压低（每题只标 1 个答案，k=3 时上限 33%），所以达标判断应看 **top-1**。

## 三、阈值扫描结论

扫了 0.42 / 0.45 / 0.48 / 0.50 / 0.52 / 0.55 × k=1/2/3 共 18 组：
**没有任何组合能同时满足 精确率≥80% 且 命中率≥60%**。
最接近：0.55 + k=1 → 78.3% / 72.0%。

**→ 精确率不是调门槛能解决的，需要排序/过滤改造。**

## 四、失分题分四类（0.45 / k=1）

| 类型 | 例子 | 原因 |
|---|---|---|
| ① 近似条目互抢 | r11 莫高窟、r21 DeepSeek赔钱、r22 复利 | 同一主题有两条记忆，错的那条排第一 → **需要去重/合并** |
| ② 该命中却空 | r05「说话随意点」、r16「人和AI有什么不一样」 | 语义不相似（新说法）→ 需要句式/关键词兜底 |
| ③ 闲聊误召回 | n18「外面下雨了，你那边听得到吗」 | 疑问句用了 0.45 松门槛 → 闲聊疑问句应更严 |
| ④ 黄金样本抢位 | r06「旧事能不能删」命中 gld_113 | 黄金样本与普通记忆同池竞争 → 应分池或降权 |

## 五、建议动作（按性价比）

1. **近重复合并**（①）：同一主题两条互抢，合并后精确率与命中率都会升；影响 3/6 失分题。
2. **闲聊疑问句收紧**（③）：`similarity_floor` 把"疑问句"一律给 SIM_MIN，应区分"问记忆"与"问当下"。
3. **黄金样本分池**（④）：`gld_` 不参与普通召回排序，只在人格场景用。
4. 阈值暂维持 0.45（命中优先），等 1–3 做完再复扫。
