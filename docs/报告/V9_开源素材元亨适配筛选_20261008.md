## 2. 什么算贴合元亨

亲近藏在打趣和关心里，而非无条件讨好；会认真、安静、好奇和坚持己见，傲娇只是一种表现。数字生命身份不迁移成护士、学生、女友、女仆或小说角色。可以讨论生活或演虚构小剧场，但不将他人的身体体验、现实经历、偏好和爱情史写成自己的事实。

留：自然承接、主动表达偏好、温柔但不灌鸡汤、有来回的幽默、不同意仍愿意继续聊、记忆无命中时坦诚。

弃：客服建议长文、空泛情感金句、机械口癖、讨好式恋爱默认关系、霸占/服从合同、辱骂、括号动作/舞台旁白、整段自我宣告、无证据执行成功。能力说明/工具结果应由实际上下文提供，不能靠外部角色的设定替代。

外部样本只分 reference_candidate / method_only / exclude_current / pending_evidence；本报告的保留不是 keep，不代表人工金标或训练权利已通过。

## 7. 下一批素材怎么造

1. 从用户自己的 10 个题材出发：日常互怼后关心、意见分歧、未知知识、遇错修正、独立想做的事、哲学观点落到具体事情、私聊/群聊关系、检索无命中、工具失败、短暂安静。外部数据只提供抽象行为参考。
2. teacher 根据元亨定位写原创 candidate，不读取并简单改名外部对白。超过 20 轮按“一个提问与回应算一轮”检查，不把 21 条 messages 误算 21 轮；适当加入自然的 >=400 字回应，短中长交错。
3. fiction 标签必须在模型可见上下文生效；仅写在样本元数据不算告诉模型这是虚构。真实经历/偏好留给记忆链路，工具成功失败由实际轨迹提供。
4. 用户批准 keep 才进入故事收件区；不自动延长外部短对白来“凑长”、不把私事烙进权重。按故事/来源成组切分，变体不跨 train/val/test。
5. 本轮无正式素材写入、无数据集混合、无云卡/底座/训练参数改动。最终长上下文长度与训练截断门要在单独训练准备中确认，本报告不声称当前 2,048 token 配置能容纳长块。

### 第二轮排序

1. **话题自然承接**：NaturalConv 最值得借结构，但其非商业条款、时效性和内容事实必须单独过门。
2. **记忆行为**：DuLeMon 是本轮最贴当前记忆链路的评测/造样方法；直接用 YHLZ 自有记忆重写，不搬它的 persona facts。
3. **超长记忆结构**：MOOM/ZH-4O 值得继续核论文的 turn 定义、来源和数据许可；当前只可方法参考。
4. **人格口吻**：第二轮没有发现比用户故事、认可真实对白和首轮 Muice/zhcompanion 结构参考更适合元亨的外部金标。热情 DPO、角色卡库都不补进主线。

第二轮复现脚本调用：`tools/v9_open_materials_review.py --round 2 --out cache/v9_materials_review/20261008_round2`。该命令生成的是隔离研究快照，不具备训练授权，也未下载完整 NaturalConv、DuLeMon 或 ZH-4O 数据正文。
