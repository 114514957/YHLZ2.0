# V9 小说与游戏情境素材纳入方案

2026-10-11。用户扩大素材来源：不必全是现实故事，游戏/小说也能摘取调整为素材，点名《希灵帝国》《异常生物见闻录》《诡秘之主》。这是来源方向授权，不代表作品全文、改编段已取得训练使用权或已完成采集。Gemma E4B PT与8万段合格训练目标不变。

## 1. 虚构可以用，故事规则要成立

前次蛋糕反例只针对该片段的刻意反转，不推广为“奇幻无厘头都不能用”或“必须真实亲历”。非现实设定、有趣的反差、想象性和奇幻日常都可成为素材；人物反应、因果与场景规则要连贯。避免把过度严格的真实记忆检查应用到已经明确标注的故事演绎。

元亨核心是谁/与家人怎么相处仍由自有素材承担；外部故事补情境、关系互动、讨论和上下文，不强迫每个训练样本讲现实生活，也不要求每个角色是元亨。

## 2. 三种制作方式

| 类型 | 输入与目标 | 数据标注 |
|---|---|---|
| 阅读/剧情讨论 | 用户给出短片段或自述情节，元亨表达理解、疑问、喜欢或分歧，不当旁观者讲完整百科 | 阅读上下文可见、引用边界明确；不能只凭书名编造原文/原剧情 |
| 情境改编 | 在来源范围允许时选择完整互动，重新设计元亨、老爹/利贞在场的对话；事件/角色映射核对，不只全局替换人名 | fiction可见，original/adapted分清，source_id到场景/章而不只到书名 |
| 抽象机制产生原创情境 | 学“严肃任务里的轻松回话”“不确定时修正”“规则有适用范围”“误会如何澄清”等交流机制，另写不复刻原台词或完整独特剧情的自有场景 | original_candidate、行为目标与生成来源说明；仍逐段检查原创性/人格/因果，不把改写宣称自动解除来源条件 |

用户未提供三本书的实际片段；本轮在当前工作区文件名检索没定位到相应文本，不推断其他目录没有。未从网络抓小说正文、未编造摘录、未把此三书改名写进训练集。

## 3. 三本书的试制用途（设计提案，非逐章阅读结论）

- 《希灵帝国》：先寻找适合做同伴互动、任务与日常交错、人物口吻区别的片段；是否够俏皮由实际段落决定，不因书名就指定风格优劣。
- 《异常生物见闻录》：先寻找不同背景角色相处、误会/规则差异、从日常进入事件的完整情境，转成能接得上的多轮材料。
- 《诡秘之主》：先寻找信息不全时的推断/修正、知识有条件边界、人物知道与读者知道不同的情境，补主见和上下文；不将角色的能力/信仰/世界观自动变成元亨核心设定。

上述是采样任务，不声称已经核验作品中指定情节，不仿作者特定语言细节或照抄标志台词。每本先挑3–5个可讨论的短情境，确认有用再扩；不是要求用户再从头审全部候选源。

## 4. 重点用于概念边界

允许在故事内讨论魔法、神明、异常现象与游戏机制，而不要求人物每句否定它们。适用范围变化时才明确区别：剧情里的“召唤”不是现实工具调用，“记住咒文”不是完成memory_save，游戏装备/技能不是当前机器上可执行的新工具。

若需要工具场景，要么用真实注册表任务轨迹，要么在该例中完整声明模拟工具schema及模拟结果。不能从小说名词臆造生产工具，不能把剧情成功反馈当作实际执行收据。

对话结束后的往事/用户偏好仍走runtime记忆；训练目标学的是阅读讨论、故事演绎与行为选择。虚构框架必须进入模型可见输入，不仅存在于素材meta。视觉/音频人物理解的训练另需对应输入，纯文本故事不冒充完成跨模态训练。

## 5. 数据量与来源工作

小说/游戏情境进入现有说话与上下文辅助池；自有原创且用户认可的情境也可进黄金核心。保持8万总目标，不另设没有内容证据的万条小说配额。完整章/游戏任务场景及其改编共同group，不能把同一场景的不同角色版本随机拆到train/val/test。

字段至少包含：source_title、source_version或路径哈希、chapter_or_scene、original_or_adapted、fiction、speakers、relationship_context、target_behavior、rights_scope_status、review_status、group_id。元数据/评分不进入assistant对白。去重后再计独立段数、token与任务覆盖，小说长度不等于SFT可用数量。

摘录与改编的文本来源/许可范围要逐本核对，持有电子书或换角色名不按自动训练授权处理。授权明确的原文/改编与抽象交流机制自产分池，不把版权问题一句“开源/仅内部”略过。当前外部训练批准数不变，本报告不是法律判定。

## 7. 追加候选簇：哲学启蒙 / 智慧小说（「苏菲的世界这样的」，2026-10-11 老爹追加）

> 与 §2 三种制作方式、§5 字段与权利规范共用；**逐本核权、不设配额**；黄金仅收自有认可原创；本簇的哲学议题与《故事原素材种子库》B 段（苏格拉底/第欧根尼/庄子…）天然合流——「阅读讨论」型可先做**不依赖原文**的哲题样张；引用原文/具体桥段必须待文本 + 授权。

- **《苏菲的世界》（乔斯坦·贾德）**——哲学史启蒙小说：神秘来信引路、从苏格拉底到康德；可用点：哲学史议题讨论、"提问比答案重要"的引导结构。状态：待文本/待核权（挪作+译本）。
- **《纸牌的秘密》（贾德）**——同作者：纸牌小矮人与"你是谁"之问；可用点：身份与存在议题、旅途谜题。状态：待文本。
- **《禅与摩托车维修艺术》（波西格）**——"良质"哲思＋父子公路行；可用点：专注与维修的安宁、质量之辩。状态：待文本。
- **《小王子》（圣埃克苏佩里）**——驯养、仪式与告别；可用点："建立联系"的价格、玫瑰与狐狸的边界。状态：原文公版、译本逐版核。
- **《牧羊少年奇幻之旅》（柯艾略）**——天命与"宝藏就在出发地"；可用点：追梦与回头、预兆与选择。状态：待文本/待核。
- **《瓦尔登湖》（梭罗）**——湖畔独居的安宁手册；可用点：简朴、与自然作伴、独处的丰盛。状态：原文公版、译本核。
- **《哲学的慰藉》（阿兰·德波顿）**——六哲人应对六种烦恼；可用点：把哲学当"安慰工具"的讨论框架。状态：待核。
- **《夜晚的潜水艇》（陈春成）**——中文当代幻想；可用点：想象力与安宁（藏起来的潜艇）。状态：待文本/待核（在版）。
- **《春宵苦短，少女前进吧》（森见登美彦）**——京都奇幻夜游、俏皮；可用点：奇幻日常、热闹里的善意。状态：待文本。
- **《哲学家们都干了些什么》（林欣浩）**——中文幽默哲学史；可用点：哲学史闲谈（适配"阅读讨论"型）。状态：待文本/待核。

- 说明：以上为**候选队列**（rights_scope_status=pending），不是已批准来源；试制时按 §2 选「阅读讨论 / 情境改编 / 抽象机制」对应路径，metadata 用 §5 字段（含 group_id 防泄漏）。
