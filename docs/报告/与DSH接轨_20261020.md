## 6. 为什么这样"接轨"

1. **工具名撞车风险归零**：训练数据里的 `todo_write`/`job_output`/`subagent` 就是 DSH 里真实存在的；
2. **行为形态对得上**：DSH 强调"先计划、可后台、能派子 agent、有交付"，这些形态现在都有样本；
3. **留出族可测**：schedule/skill 没进训练，将来接进 DSH 时可直接测"会不会用没见过的工具族"；
4. **注册表可快照/可漂移检查**：DSH 升级加工具，跑一次 `v9_dsh_tools.py` 就有新 sha，`--drift` 点名数据要不要跟上。

## 7. 下一步

1. **DSH 零样本评测**：用留出的 schedule/skill 出题（如"每天九点提醒我"），看它选不选得对；
2. **多轮长轨迹**：现在最长 7 步，DSH 真实任务常 20+ 步，要补长程样本；
3. **工具结果真实性**：目前 tool 回包是合成文本，未来可接 DSH 真实 `tool_uses` 留痕替换；
4. 4,386 条新数据待签。
