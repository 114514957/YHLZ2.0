# 逻辑书 / 科普书 / 有趣比方 · 2026-10-20

> 老爹：「继续挖，还有，逻辑图书，有趣的科普书，还有有趣的比方」。
> 三样都拉了，且都加了**质量过滤**（第一版噪音太多，返工了一次）。

## 1. 逻辑图书 + 科普书（按主题搜，不再随机抽）

`tools/v9_knowledge_pull.py`：MediaWiki `list=search` 按主题找页，再逐页取纯文本，6k 分块。
主题词：**逻辑 / 谬误 / 推理 / 数学 / 物理 / 宇宙 / 生物 / 科普 / 比喻**；源：维基教科书 + 维基百科。

**过滤**（第一版 200 块里混进"清朝/川普/文化大革命"这类搜索噪音）：
- 标题含主题词，**或**正文里主题词出现 ≥3 次；
- 中文占比 ≥40%、正文 ≥400 字。

结果：**127 块 / 约 58 万字**，命中如
`数理逻辑`、`超普通心理学/語言與思考/思考`、`智力理論`、`物理学`、`宇宙`、`英语常用同义词辨析`。

## 2. 有趣的比方（比喻句）

`tools/v9_simile_extract.py`：从小说、教材、公版文本抓**真比喻结构**——
`像…一样/似的/那样`、`如同`、`好比`、`犹如`、`宛如`、`活像`，句长 30–140 字，中文占比 ≥70%。

**第一版误收**（"仿佛还在眼前"这种）→ 加结构过滤后：**546 句**（希灵 144 / 异常 125 / 诡秘 125 / 苏菲 99，其余来自公版）。

样例：
> 它们是如此巨大，以至于几乎占据了整个天空三分之一的面积，表面隐隐可以看到无数尖锐的突起和**网格一般的纹理**。

## 3. 教材/工具书（上一轮修复后）

`v9_refbooks_pull.py` 改多批循环后：**192 块**（维基教科书 164 / 词典 13 / 百科 15）。
