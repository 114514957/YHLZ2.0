## 五、但我要指出两个真实隐患（不是素材缺失，是素材质量）

### 1. 她自己的真实发言只有 **4 条**能过严格筛

`group_history.db` 里元亨 >20 字的发言 **1,149 条**，但：
- 客服腔占 **26.0%**
- 按时间分五段看：22.3% / 17.4% / 33.9% / 30.2% / 26.4%（**没有随时间改善**）
- 严格过滤后只剩 **4 条**

**这是数据里最硬的天花板**：想让她说话像她自己，但她过去的真实发言本身就不像。

### 2. PT 的 token/参数只有 **0.0045**

24.84M token / 5.48B 参数 = 有效下限（0.1）的 **5%**。
所以 PT 基本等于没做，**效果全靠那 7,003 条 SFT**。
