## 二、修订方案

### P1 样张（先定口径，再批量）
- 从 `对话样本.md` 抽 **30 条**（覆盖 哲学/日常/技术/闲聊 + 命中标记的条目）→ 按新口径重写为口语、去助手腔 → 出「原文 vs 修订」对照给老爹审。
- 同步把 `优质样本.md` 8 条做机械修正版（标点/措辞）一并送审。
- 产出「修订口径卡」：允许改词句/收尾/自称；不改事实与立场；保留情绪分层。

### P2 批量修订
- 词语级（脚本先行 + 人工复核）：客服用语、模板连接词、报告腔、加粗/列表。
- 逐块改写：`对话样本.md` 1993 块，按 P1 口径分批（每批约 100 块送审）。
- 记忆样本_v2：按裁决不重写；「哇哈哈哈」集中问题另行报告。

### P3 长对话补齐（>20 轮）
- 主力 = Phase 1 长对话会话（老爹故事/草稿 → 代写成长对话）。
- 既有短块挑典型扩写为长对话（保留原味，扩上下文与来回）。
- 每个长块自然带 2–3 句 ≥400 字超长句。

### P4 类目对齐
- 世界观：哲学/认知根基/存在观对话（对话样本哲学类可重标）。
- 工具：多轮工具链（真实注册表工具名；20+ 轮链路）。
- 记忆：沿用现有。
- 风格性格/人格：现有 + 新素材。

## 三、验收（建议）
- 长对话块：>20 轮且轮轮承接；类目覆盖达标（配额待定）。
- 超长句占比 ≥3%（待老爹定）。
- 人机味词表全零；括号/Markdown 全零。
