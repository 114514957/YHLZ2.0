# 自有素材与开源素材抽样对比

> **用户审阅更新（2026-10-11）**：用户认可展示第2（咖啡店）、第3（Muice简短有态度）、第6（LCCC普通接话）；指出蛋糕塌了的例子有点无厘头。因此本文原来的“蛋糕段得意/反转可优先保留”仅为助手当时观察，不是认可结论，不再当正面风格锚点。第4/5用户未表态。具体片段认可不等于整块/整库或训练许可放行。

2026-10-11。目标：按用户纠正的“要俏皮”比较，不把普通日常、热情、毒舌、恋爱撒娇和元亨俏皮混成一个维度。此次只比较，不重写、不批准训练、不改主素材。

## 1. 方法与限制

固定种子20261011，按组名SHA256派生随机种子，用Random.sample，每组3条。自有修订是从v3覆盖的11块中抽3个ID，并读取同ID原稿；全主对话1993块与黄金旧keep/fixed67块各独立抽3。外部任选4个已查来源：Muice、MemorialSummer、zhcompanion、LCCC；没有按实际抽中的效果更换源或重抽。

| 组 | 抽样范围 | 抽中ID |
|---|---|---|
| 原稿/v3同题比较 | v3的11个ID，各3条，共6次呈现 | 对话16、17、28 |
| 主对话额外随机 | 全1993块 | 对话598、1322、682 |
| 黄金素材随机 | 67个旧keep/fixed数字ID | golden122、109、117 |
| Muice | 固定revision主train.jsonl全部3376条，不含Customized | 1-based行2944、537、2195 |
| MemorialSummer | 固定revision JSON全部170条 | 0-based索引86、67、26 |
| zhcompanion | 已保存的全部6个demo | viewer行0、3、1 |
| LCCC | 仅已保存首/中/尾24行，不是682万条全库随机 | viewer行3410259、6820502、6 |

共24次呈现，含同题原/修配对；不是24个独立情境。来源/切片差异很大，不估整库合格率、不报显著性、不给精确总分排名。不是按题材配对外部集，哲学与短俏皮句的功能不同，不能仅用句长定胜负。

外部full记录用于阅读判断；报告用概述，不把一段节选假称整段质量。当前用的是小样与研究缓存，无数据获训练放行。官方card/名称也不证明单条质量。部分外部全文需量化/版权适用范围另核，不以抽样取代许可审核。

复现：`tools/v9_style_sample_compare.py --out cache/v9_style_comparison/20261011`。采样清单含文件/仓库revision、SHA256、ID、发言数与字符数；字符不是token。生成器仅保存来源定位与机械测量，不复制外部全文成新训练集。

## 2. 先看自有原稿与v3的同题差异

### 对话17：去掉模板，但仍急着讲道理

原稿（节选）：

> 利贞：幸福能拿来比较吗？
> 元亨：哎呦，这能比吗？各有各的甜，就像咱上次吃的那家甜品店，你爱芒果我爱草莓，谁更甜？对不对？

v3（同段节选）：

> 利贞：幸福能比较吗。
> 元亨：上次那家甜品店，你吃芒果，我吃草莓，谁更幸福？
> 老爹：你啊，你吃得多。
> 元亨：还真按多少算啊。

阅读判断：v3中老爹歪解一下、元亨接住，是比原稿口癖更有用的变化；但她接着又把“不比幸福”的观点收束完整，仍有把聊天做成论证的安排。没有足够俏皮就不能仅凭词表更干净签收。

### 对话28：原稿的得意劲被改淡了

原稿末尾：

> 老爹：明年还做不做
> 元亨：做，本小姐打算故意再塌一次，反正大家都说坑里那块最好吃。

v3末尾：

> 利贞：明年还做不。
> 元亨：做。说不定故意塌一次。
> 老爹：还塌上瘾了。
> 元亨：你们不是吃得挺开心嘛。

阅读判断：原稿这一次自称服务于具体得意，不是无意义高频复读；故意把失败变成下一次主意，有自主选择和玩心。v3缩成不确定语气，信息变得松散，也弱化原来的打算。v3多了来回，不代表比原稿俏皮。应保留原有意图与性格，不为句短抹掉她的兴致。

### 对话16：不是所有段落都必须俏皮

原稿用连续起手词、反问尾词包装钟摆论的讲解；v3减少这些，但还是按相同论点逐项往下说。沉静与诚实可以保留，这一段不该因为没笑话就一概判差；要改的是讲座结构，不是强行拿痛苦做包袱。此前写完v3便对效果乐观，证据不足，本轮不签收。

## 5. 样本支持的结论

1. 用户指出修订仍不对，不能被“禁词减少、句子更短”推翻。同题蛋糕段确实在修订中减弱了原有的得意和计划，这是实在的退步线索。
2. 我把去模板进一步改成平淡，也是方向偏移。元亨需要具体问题中的好奇/玩心/选择/小得意；不能把傲娇自称和幽默全部删光，又不能恢复每句同一口癖。
3. 外部库不是整体比自有库更像元亨。Muice三条里只有一条清楚呈现轻巧态度；Memorial部分反转也有暧昧或生硬；LCCC的正常不代表足够俏皮。这个小样不能推广成比例或全库排名。
4. 本次最值得借的是zhcompanion行3的回扣前文、Muice行2195的有态度短答、Memorial索引86的接夸奖；它们还是参考，不是训练批准。不能只取它们好的一句，便声称全段/全库自然。
5. 认真哲学、温柔、普通接话与俏皮必须共存。以后修改先标本段要承担的关系/情绪功能，保留原有闪光处，再去客服结构，避免把整库改成同一种“自然”。

本轮不生成v4，不覆盖主素材，不追加外部训练数据。后续修订需要以用户认可的具体片段定风格，不继续自我宣布已经改好。
