## 三、五个必须说清的问题

### 3.1 诚实边界样本：真客服腔重灾区（72 处）

原文摘录（全部是「我这边」）：
> 「做不到哦老爹。**我这边**没有直接解析表格文件的能力」
> 「**我这边**真没辙」
> 「**我这边**没有图像识别的能力，图对我来说就是一片空白」

**180 块里 72 处，命中率 40%。** 这份材料是"诚实边界"的核心来源（权重 1.0），**但它的表达方式正是老爹点名要治的客服腔**。

### 3.2 优质样本：**风格标杆本身是坏的**

它是"风格标杆 · 由利贞手写"，8 块里 **6 块结构错**：

| 块 | 实际结构 | 问题 |
|---|---|---|
| 优质-3 | 老爹问 → 元亨答 → **老爹答** → 元亨答 | 老爹作答 |
| **优质-4** | **元亨问** → 利贞答 → 元亨答 → 老爹答 | **元亨首问（夺主体）** |
| **优质-5** | **元亨问** → 利贞答 → 元亨答 | **元亨首问** |
| 优质-6 | 老爹问 → **利贞答** → 元亨答 | 利贞抢答 |
| 优质-7 | 老爹问 → 元亨答 → **利贞答** → 老爹答 | 利贞/老爹作答 |
| 优质-8 | 老爹问 → 元亨答 → **利贞答** | 利贞抢答 |

**用这 8 块当 few-shot 标杆，教的就是"元亨提问、利贞/老爹作答"。**

### 3.3 真实对话样本：真实与规范的冲突

40 处 FAIL 全是**括号 11 / 星号 10 / 列表行 10**。但这份文件头写着「**QQ 实录·原样保留·不得润色**」。
→ **这不是素材的错，是规范没给"真实数据"开口子。** 需老爹定：要么豁免（标 `raw:true` 跳过格式门），要么逐条清洗（但就不"真实"了）。

### 3.4 黄金样本：**门禁与装配器口径不一致**

- 黄金样本用 `### 老爹` / `### 元亨`（无编号）；
- **门禁只认 `### X问N` / `### X答N`** → 73 块全部"无可解析对话轮"；
- **但装配器能读**（stats 里 golden=69 条正常入集）。

→ **是工具口径问题，不是素材问题。** 但意味着**黄金样本从未经过门禁检查**。

### 3.5 风格六条：**全库不达标**

| 风格项 | 命中块数 |
|---|---:|
| 句长太匀（p90/中位<1.8） | **1,671** |
| 未称呼对方 | **1,536** |

## 五、结论与建议

**结论：现有素材"框架齐全、量还不足、内容有两处硬伤"，不能直接开训。**

按优先级：

| 优先级 | 事项 | 理由 |
|---|---|---|
| **P0** | **重写诚实边界样本**（72 处客服腔，180 块） | 权重 1.0 的核心材料，表达方式恰恰是错的 |
| **P0** | **修优质样本 8 块结构** | 它是 few-shot 标杆，错了会带偏后续生成 |
| **P1** | 对话样本 45 处 + 记忆 8 处 + 承认不确定 7 处 | 量不大，可批量改 |
| **P1** | 定义"真实数据"豁免规则（`raw:true`） | 否则真实对话永远过不了格式门 |
| **P2** | 黄金样本纳入门禁（扩展 `parse_turns` 支持无编号格式） | 否则 73 块永远没被检查过 |
| **P2** | 风格判据改语料级比例 | 现逐块口径全库都不合格，无法收敛 |
