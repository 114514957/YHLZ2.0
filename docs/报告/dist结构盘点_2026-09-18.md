## 三、性质判定：打包产物 / 发行版

- **打包产物**：是。`dist/finetune_bundle` 与 `dist/local_serve` 是项目「训练链 + 部署链」的成品归档。
- **发行版**：是，但属于**源码+数据型发行包**（deliverable bundle），不是二进制发行版：
  - 无 `.exe`、无安装器、无版本清单/校验和；
  - 无模型权重、无 `llama-server` 运行时——运行依赖项目根外部资产。
- **三份 zip 是版本快照**（v3/v4/v6），内容随版本递增：
  - v3（16 项）：无 `audio_infer.py`、无 `run_qat.sh`/`run_dpo_only.sh`，数据止于 v3；
  - v4（21 项）：加入 `audio_infer.py`、`run_qat.sh`，数据到 v4；
  - v6（30 项）：含 v5/v6 数据、`tool_use_v6.jsonl`、`run_dpo_only.sh`、`__pycache__`；
  - **v6 zip 内容与当前 `dist/finetune_bundle/` 一致**，即当前工作副本 = 最新快照。
