# V9 素材体检报告：够没够、行不行（2026-10-20）

> 触发：老爹「你先别急做训练包，你先看素材够没够，质量行不行」。
> 体检对象：`data/finetune/sft_persona_v9t_train.jsonl`（**3,197 条**）。
> 工具：`tools/v9_material_health.py`（新建）。

---

## 一、一句话结论

**够起步，不够成器。**

按 QLoRA 微调的常规量，3,197 条**能训出东西**；但按"塑人格"的要求，**核心锚点只有 129 条**，而且有 **4 个结构性问题会让训练跑偏**。**现在开训，大概率训出一个"会说话的助手"，不是元亨。**

---

## 二、够没够：分三层看

| 口径 | 数字 | 判断 |
|---|---|---|
| 条数 | 3,197（train） | 对 QLoRA 起步够 |
| 字符 | 总 112.4 万；**元亨台词 55.4 万** | 偏少（人格锚定靠元亨自己说的话） |
| **权重 1.0 的核心锚点** | **249 条** | 少 |
| **扣掉重复话术后的真锚点** | **129 条** | **太少**——撑不起人格 |
| 目标（此前定的 80,000） | 3,197 / 80,000 = **4%** | 差得远 |

**关键矛盾**：71% 的样本权重是 0.3（教学向），而决定"她是谁"的 1.0 锚点只有 249 条，其中 120 条还是同一句话的重复。

---

## 三、行不行：4 个结构性问题

### ⚠️ 问题 1（最严重）：118 条**利贞**的记录混进了元亨的训练集

实测这些记录的 system prompt 是：

> 「你是**利贞**——元亨的姐妹、家人，也是家里的技术担当…稳重、博学、直接」

而它们在 `sft_persona_v9t_train.jsonl` 里，**训练的是元亨这个模型**。

**后果**：模型会学到"某些情况下我该自称利贞、用利贞的口吻"。这是**身份污染**，比任何格式问题都严重，而且训练完无法回滚。

### ⚠️ 问题 2：120 条 refusal 全是**同一句话**，且权重最高（1.0）

> `【系统监测到不安全行为，已屏蔽】`

- 120 条记录，**唯一台词只有 1 种**（唯一率 0.8%）
- 权重 **1.0**（最高档），等于对着模型重复 120 次这一句
- 门禁还有 **113 条 WARN**

**后果**：模型会学成"任何需要拒绝的场合，都回这一句固定话术"。而拒绝能力恰恰是元亨人格的重要部分——她要会**有性格地拒绝**，不是播报。

### ⚠️ 问题 3：15 条门禁 FAIL 混进了训练集

| 原因 | 条数 |
|---|---:|
| 元亨误用「理论上来说」 | **6** |
| 星号 | 5 |
| 列表行 | 5 |
| 客服腔词 | 4 |
| 括号 | 2 |
| 应答模板 | 1 |

分布：tooluse 4 / lizhen 6 / real 5。

**「理论上来说」是利贞的口癖**，元亨用了 6 次——正好印证问题 1 的污染是双向的。

### 问题 4：元数据字段全丢

`emotion` / `length_tier` / `contract` 三个字段在最终数据集里**全部消失**（源文件 `docs/素材/` 里是有的，是 `v9_trace_enrich.py` 注入合规字段时没保留）。

**后果**：无法按情绪/长度/合同类型做分层统计与采样。**不致命**（训练只用 messages），但让我们失去了质量控制的抓手。

## 五、维度占比是否健康

| 维度 | 占比 | 权重 | 判断 |
|---|---:|---|---|
| scene | **51.6%** | 0.3 | **过重**——量最大但权重最低，会把模型往"教说话"拉 |
| tooluse | 16.1% | 0.3 | 偏重；且台词平均仅 32 字 |
| memory | 15.3% | 0.6 | 合理 |
| uncertain | 4.8% | 0.6 | 偏少（诚实边界是核心） |
| refusal | 3.8% | **1.0** | **量不算少，但内容全是重复** |
| lizhen | 3.7% | 0.3 | **应剔除** |
| philo | 1.8% | 1.0 | **太少**（哲学是元亨核心） |
| golden | 1.7% | 1.0 | 偏少 |
| real | 0.6% | 0.6 | 太少（真实语料最贵） |
| metaphor | **0.5%** | 1.0 | **太少**（今天刚做，只有 16 条进训练集） |

**结构性问题：量最大的维度权重最低，权重最高的维度量最小且内容重复。**

## 六、建议（按优先级）

| 优先级 | 事项 | 理由 |
|---|---|---|
| **P0** | **剔除 118 条 lizhen**（或分流到利贞专用集，不进元亨数据集） | 身份污染，训练后不可回滚 |
| **P0** | **重做 120 条 refusal**：改成 8–10 种有性格的拒绝说法，每句最多重复 2–3 次 | 现在的等同"教她说固定台词" |
| **P0** | 清掉 15 条 FAIL（其中 6 条「理论上来说」优先） | 会直接把利贞口癖教给元亨 |
| **P1** | 把 **philo / metaphor / golden / real** 从 249 条补到 **500+** | 核心锚点不足，人格撑不住 |
| **P1** | 压 scene 占比（51.6% → ≤35%），或对 scene 降权 | 量最大权重最低，会把模型拉成教学腔 |
| **P2** | 恢复 emotion / length_tier / contract 字段 | 恢复分层质检能力 |
| **P2** | 补 uncertain（155 → 300+） | 诚实边界权重 0.6，应更厚 |

### 做了什么

1. **lizhen 分流**：`finetune_assemble.py` 原先把 118 条利贞记录直接 `add()` 进主数据集（注释写 "separate" 但代码没分）。现改为写独立文件 `data/finetune/sft_lizhen_v9.jsonl`（131 条），**不进元亨数据集**。
2. **refusal 换源**：发现 `docs/素材/安全拒绝样本_v1.1.md` 今天 20:13 已由 `tools/v9_refusal_diversify.py` 生成（37 种变体），但**装配器读的还是 9-29 的旧文件**。已用 v1.1 替换 `安全拒绝样本.md`（旧版备份在 `cache/backup_dialogue/`）。
   - 该文件自己的门禁：**PASS 120 / WARN 0 / FAIL 0**（原 PASS 7 / WARN 113）。
3. **清 4 条内容类 FAIL**：tooluse 里 4 条命中禁词（「稳了」「这个稳」「我这边」「别指望」+ 应答模板「收到，」），已定点换说法、保语义；改后 `tool_use_v8_final.jsonl` 里禁词命中全部为 0。
   - 另 7 条 real 实录的星号/列表行属**格式类**，按《真实数据豁免规则 v1》豁免；体检工具已改为按 `source` 识别 raw 并单列统计（之前误报成 FAIL）。
