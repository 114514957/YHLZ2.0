## 5. 为什么没做 prefix 稳定

学习报告建议把动态记忆块作为**第二条 system** 放在 history 之后；但 `backend/prompt_structure.py:51-58` 的硬不变量是：

> 首条必须是 system；`messages[1:]` 出现任何 system/developer 直接抛异常。

这条不变量是为了防止“检索到的记忆文本变成指令消息”。如果照搬 P0-1，会把记忆抬成 system 权限，和安全边界冲突。需要先定一个**既能保留静态前缀、又不破坏该不变量**的方案（例如只把真正静态的人格/工具纪律放 system[0]，动态块仍以“数据”身份留在同一 system 内，并测 llama 实际 cache 命中率），再动代码。本轮不硬改。
