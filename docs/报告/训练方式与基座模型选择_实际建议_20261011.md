## 0. 概念对齐（三者正交，别混着问）

| 维度 | 含义 | 当前可选项 |
|---|---|---|
| 阶段 | 做什么类型的训练 | DAPT（继续预训练）/ **SFT（监督微调）** / DPO（偏好优化） |
| 方式 | 同一次训练里参数怎么更新 | **全量（全参）** / **LoRA** / **QLoRA** |
| 基座 | 训在谁身上 | IT（`gemma-4-E4B-it`，现役）/**base（`gemma-4-E4B`，待验证假设）** |

所以正确的问法是「哪个阶段 × 哪种方式 × 哪个底座」——例如：*SFT 阶段，LoRA 方式，IT vs base 对照*。

## 1. 方式对照（A800 80G 云卡语境）

| 方式 | 显存/耗时 | 效果上限 | 迭代/回退 | 实际建议 |
|---|---|---|---|---|
| LoRA | bf16 轻松（V8 实测 38.6G / 645 步 / 1.86 s/it ≈ 20 分钟一轮） | 中高：风格/行为足够，榨干上限略欠 | adapter 可切换、可回退；本地 llama.cpp 直接挂 | **主力**：所有实验先走它 |
| 全量（全参） | 仅 language 全参：bf16 + 8bit 优化器 ≈ 50-60GB；全模型全参（7.9B）不做（需 ZeRO/offload、边际收益低） | 最高 | 差：每次输出完整权重，回退成本高 | **终局冲刺**：LoRA 触顶后才上，只训 language，冻结视觉/音频塔 |
| QLoRA | 16-24GB 小卡也能训 7-8B | 中：量化噪声，风格课收益略打折，速度更慢 | 同 LoRA | **本项目用不上**（A800 不缺显存；本地 4060 8GB 跑不动 8B 训练）；仅在换小卡省钱时考虑 |

## 2. 分项实际建议

### 2.1 LoRA（阶段：SFT）——**第一选择**
- 适用：语料试验、风格/人格/行为修正、底座对照实验（A/B/C/D）。
- 参考配置：r=32/64、α=2r、dropout 0.05、lr 1e-4 量级、2-3 epoch、目标全线性层、warmup 3% + cosine。
- 理由：一轮约 20-40 分钟 → 支持「一次只动一个变量」；adapter 可回退；训练产物与本地推理链（llama.cpp + LoRA）完全兼容。

### 2.2 全量（全参）——**不是第一选择**
- 触发条件（满足才做）：① 语料规模到 2 万条级（或 4k 条级 + 大幅通用 replay 冲量）；② LoRA 对照已证明「天花板就在参数更新方式」。
- 做法：只对 language 全参（bf16 + 8bit AdamW），冻结 vision/audio 塔；混 replay 防遗忘；保留 IT 基线权重可回退。
- 现状判断：V8r4 候选仅 4,047 条 → **现阶段直接全参 = 练歪高风险**。

### 2.3 QLoRA——**不选**
- 它解决的问题（显存不够）本项目不存在；引入的量化噪声会干扰「风格归因」实验。
- 保留为备用词条：仅当切换到小显存云卡或更小底座的探索实验时才考虑（NF4 + 双量化 + paged optimizer）。

### 2.4 阶段顺序（SFT / DPO / DAPT）
- **SFT 先行**；**DPO 后置**——只在实际收集到坏例集（chosen 必须人工认可、rejected 必须是真实观察到的坏答案）之后单开一次对照，不与 SFT 同批混跑。
- **DAPT 维持跳过**：346M token 对底座万亿级预训练量 <0.01%，加不动知识且易变笨（台账 0559 已裁决；RUNBOOK §3/§6 同口径）。

### 2.5 基座（base vs IT）——按对照实验验证，不凭体感
- 假设：「IT 底座先验导致客服腔」——待检验；客服腔也可能来自素材配比、提示词、模板或采样参数。
- 做法（RUNBOOK §4 A/B/C/D，同数据、同提示词、同评测）：
  - A 现役基线（IT + V8 adapter）；B IT 不挂 adapter；C base 不挂 adapter（仅诊断）；D **同规模 V9 SFT 数据分别训 IT 与 base 两个 adapter（核心公平对照）**。
- base 的额外门槛：确认 checkpoint 仓库/许可/修订/tokenizer/chat template 兼容；训练脚本不能沿用 IT 模板硬套——先做样本渲染 + labels 掩码检查（EOS/轮次 token）；base 无对话先验，epoch 可放宽到 3-5。
- 转主线条件：base 在自然度上有收益 **且** 工具/记忆/诚实硬门不退化；否则保留 IT。
- 铁律：**底座变更与训练方式变更不同时做**（一次一个变量）。

## 4. 落地顺序（建议）

1. **语料先行**：去IT味修订（批次01 已交付待审，台账 0755-0759 进行中）+ 通用 replay 配比 + 分组切分/去重/未见题隔离。
2. **LoRA 四臂对照**：base/IT × 同数据，先小规模（复用 RUNBOOK §4 D 组口径）。
3. **行为评测定分**：未见题 + 多轮 + 盲评 0-2 分；身份/诚实/虚报关键错误零容忍，不能被风格分抵消；**loss 不作裁决**。
4. **LoRA 触顶才升全参**（见 2.2 触发条件）。
5. **DPO 仅在有真实坏例集时单开**。
