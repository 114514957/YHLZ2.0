## 二、元亨工作台（8321）

**改前**：15 张卡片竖着堆在一条侧栏里，状态、记忆、台账、翻唱、设置混在一起；老水彩皮肤；按钮散落。

**改后**：

- 顶栏：品牌「元亨」+ 状态灯（空闲/思考）+ 连接状态（Gemma/QQ）+ 新对话 / 面板 / 更多（形象、桌宠、全家桶）。
- 中央：对话区（气泡、流式光标、停止按钮、语音条），输入框常驻底部。
- 右侧「控制面板」抽屉：**5 个页签**——状态 / 记忆 / 台账 / 翻唱 / 设置；原 15 张卡全部归位，id 一个不少。
- 明暗主题（◐，localStorage 记住）；宽屏可收起面板（点「面板」或 Ctrl+K），窄屏变浮层 + 遮罩。
- 交互：Ctrl+K 开面板、Esc 关、Ctrl+Enter 发送、页签记忆上次选择。

**兼容**：`console.js` 未改；`index-classic.html` / `console-classic.css` 留档，回滚只需把 `index.html` 换回 classic。

## 三、训练工作台（8090）

**改前**：左边版本列表 + 四个页签，能用但看不出「模型现在什么水平」。

**改后**：

- 顶栏：品牌 + 服务状态 / 显存空闲 / PID + 重扫 / 停止实例。
- **仪表盘四卡**：最新 56 题得分、历史最佳、闸门是否通过、persona56 分数趋势（canvas 折线，红点=闸门未过）。
- 版本栏：仍按「可服务 GGUF / 版本档案 adapter」分组，带 GGUF/adapter/残缺标签与大小。
- 页签保留：概览（版本详情/服务控制/基座）、对话测试、评测（56/群聊/素材探针 + 冷态）、记录（runs 列表 + 逐题对比）。
- 新增 `static/dash.js`：只读 `/api/state`，算指标、画趋势，15s 刷新；不碰 `app.js`。
