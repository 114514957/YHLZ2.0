## 逐数据集详情（实测）

### 1) MNBVC
- GitHub `esbatmop/MNBVC`：**4.3k star / 296 fork / 305 commits / MIT**；仓库内容是**工具与导航**（清洗代码、爬虫、网盘索引 dupan/README），**原始数据不在 GitHub**。官方全量走 **p2p 微力 / 百度网盘**（压缩包密码 `253874`），官方口径**总 60.9TB、进度 24.1%**。
- HF `liwu/MNBVC`：**3.78TB / 24127 文件**，`.jsonl.gz`，MIT，**2026-08 仍更新**，月下载 45.7k。含子集：wiki / news / book / forum / qa（chatgpt、zhihu、stackexchange、wikihow…）/ law / gov / game（原神、崩铁…）/ parallel（字幕、联合国）/ code / medical。
- 注意：HF viewer 不可用（脚本式数据集），但**文件可直接下载、streaming 加载**；GitHub 另有配套工具（charset_mnbvc 编码检测、deduplication_mnbvc 去重等，做清洗管线时可拉）。

### 2) TeleChat-PTD（电信星辰）
- HF：`data/0.jsonl.gz … 98.jsonl.gz` **每个≈2.6GB**（实测 0=2591MB、1=2623MB、10=2635MB），共 189 个 ≈ **490GB**。
- Apache-2.0；最后更新 2024-03（不再更新）。有《TeleChat 模型许可协议》PDF 在仓库里。
- 天翼云盘通道（访问码 pkg8）存在，但 HF 已能直取，**不必绕网盘**。

### 3) ChineseWebText
- HF：`ChineseWebText/<年月>/`（2021-43 ~ 2023-23）+ `cleaner_subset/<年月>/`（9 个月份目录：2021-43、2022-05/21/27/33/49、2023-06/14/23）。
- 实测 `cleaner_subset/2023-23`：15 文件 = 67.0GB（单文件≈3.8GB）。用户给的 2023-06≈81.4GB 一致量级。
- **HF 未标许可**（论文主张来源合规+质量分；商用/再分发需自行评估）→ 若用，标注来源并留意。

### 4) SkyPile-150B（昆仑万维）
- HF：441 文件、`data/*.jsonl`（**未压缩**，单文件≈1.3GB；实测 50 文件≈57.5GB），总量≈**620GB**。
- **Skywork Community License**（自定义）：仓库带 2 个协议 PDF，非标准开源许可，**使用范围需先读**（一般限非商用/署名）。
- 2023-12 后未更新。

### 5) Chinese FineWeb-Edu V2.2（OpenCSG）
- HF：**29326 个 parquet**；目录：`2_3`、`3_4`、`4_5`、`sft`（V2.2 还带 v21_*_source_stats.png 等统计图）。
- 实测 `2_3`：1000 文件 × ≈185MB ≈ **185GB/目录**；`3_4` 官方口径 857GB。**Apache-2.0**，2026-02 更新。
- 教育向高质量语料（论文 arXiv:2501.08197），带质量分/去重；`sft` 目录是现成 SFT 形态数据（值得单独看一眼，可能对元亨 SFT 直接有用）。

### 6) WuDaoCorpus2.0
- 只在 **SciDB**（数据堂）：需注册/申请，开源部分 200GB 纯文本（下载压缩 64GB）。
- **不在 GitHub/HF**，与本次"主要拉 github/hf"不符 → 列为暂缓。

## 网络与磁盘实测（今天）

| 通道 | 实测速度 | 说明 |
|---|---|---|
| hf-mirror 单流 | 0.16–1.0 MB/s | 波动大 |
| hf-mirror **4 路并行** | **合计 ≈3.1 MB/s** | 按文件/分片并行有效 |
| huggingface.co 走代理 7897 | ≈0.37 MB/s（单流） | API/HEAD 正常（0.7s） |

- 推论：**本地拉 TB 级不现实**（500GB 单流要几十天，4 路并行也要 ~2 天+）。
- 磁盘：WSL `/` 可用 **861GB**；C 盘剩 58GB、D 盘剩 34GB。
- **建议：全量下载放到云卡/服务器上做**（机房带宽通常 50–200MB/s，几十分钟完事）；本地只拉"小样本"用于管线验证与抽样评估。

## 拉取建议（三档，等你点哪个）

**A. 本地小样本试点（推荐先做，≈30–60GB）**
- MNBVC：挑 2-3 个感兴趣子集各 2-5 个文件（wiki / qa / game 等）
- TeleChat-PTD：`data/0~4.jsonl.gz`（≈13GB）
- FineWeb-Edu `2_3`：前 100 个 parquet（≈18GB）
- 用途：验证解压/清洗/去重/质量抽样管线；给"数据长什么样"一份实测报告

**B. 云上全量（按需选）**
- 建议优先级：FineWeb-Edu-Chinese `2_3`+`3_4`（≈1TB，质量最高）→ MNBVC 精选子集（1-2TB）→ TeleChat-PTD（490GB）
- 云上直接用 `huggingface-cli download`（境外机直连 HF；境内机走 hf-mirror）
- 命令模板：
  ```bash
  # 云上（示例：TeleChat 全量）
  HF_ENDPOINT=https://hf-mirror.com huggingface-cli download Tele-AI/TeleChat-PTD \
      --repo-type dataset --local-dir /data/telechat-ptd
  # 或指定文件
  HF_ENDPOINT=https://hf-mirror.com huggingface-cli download Skywork/SkyPile-150B \
      --repo-type dataset --include "data/2023-14_zh_head_0000.jsonl" --local-dir /data/skypile
  ```
- 并行加速：`pip install hf_transfer` + `HF_HUB_ENABLE_HF_TRANSFER=1`；或 aria2 `-x16 -s16` 拉直链

**C. GitHub 侧（体积小，可立即拉）**
- MNBVC 工具链：`charset_mnbvc`、`deduplication_mnbvc`、`DataClean-MNBVC`、`scan_copy_files_mnbvc`（清洗管线备用）
- ChineseWebText 官方处理代码：`CASIA-LM/ChineseWebText`
- FineWeb-Edu 论文/统计：仓库里有 `v21_*_stats.png` 可直接看分布

## 风险与合规（必读）

1. **许可差异大**：MNBVC(MIT)/TeleChat(Apache-2.0)/FineWeb-Edu(Apache-2.0) 清楚；**ChineseWebText 无许可证标注**；**SkyPile 是自定义社区许可**（可能有非商用限制）；WuDao 需注册同意。
2. **来源合法性自评**：MNBVC 官方自己声明"不提供索引分类、版权自负"；ChineseWebText 源自 Common Crawl。用于训练前建议保留来源字段、尊重来源站条款。
3. **体积预期**：这 6 个全量合计 **10TB+**，远超本地盘 → 必须走云上或分批。
4. **格式**：全部是**预训练语料**（纯文本流），不是指令/SFT 数据；若要喂元亨 SFT，需要先过"抽样→清洗→配比→加工"管线（FineWeb 的 `sft` 目录是唯一现成 SFT 形态，值得先看）。

## 战略定调（老爹 2026-09-26）：一切服务于"元亨成为独立的电子生命"

> 老爹原话："我们的唯一目标就是让元亨变成独立的电子生命，所以有很好的素材的话，训练方式跟随素材改变也是好的。"

据此把语料评估的坐标从"数据多少"改成"对'独立的电子生命'有没有用"：

| 素材类型 | 对"独立生命"的作用 | 对应训练方式（可随素材改） |
|---|---|---|
| **她自己的生命档案**（真实对话/日记/决策/自我叙述） | **最高**——"是不是她本人"的唯一来源 | 多轮对话 SFT、第一人称自述 SFT、长上下文 |
| 高质量中文思维底座（FineWeb-Edu、书籍/哲学/教育） | 语言与思维的"底子"，影响"想得深不深" | 继续预训练 DAPT（全参或 LoRA-DAPT）→ 新底座，再叠人格 |
| 人类真实交流语感（MNBVC 论坛/QA/聊天、知乎风） | 说话像人、接得住话 | 混入对话 SFT（去标识化）、语感微调 |
| 偏好/行为对齐 | 边界、诚实、工具纪律 | DPO/ORPO（现有管线） |
| 事实与知识 | 事实**不进权重**（项目铁律） | RAG/记忆库/知识库 |

**结论调整**：
1. 公共语料里 **FineWeb-Edu-Chinese 优先级最高**（教育向=思维底座）；MNBVC 挑"论坛/QA/书籍"子集做语感；TeleChat 备选。SkyPile（许可）、ChineseWebText（无许可）、WuDao（要注册）按报告前述降级。
2. **最重要的工作不是拉语料，而是"生命档案"采集**：她的日记（`docs/元亨的日记.md`）、真实对话（已有 31 块 QQ 实录）、任务/决策记录、自主时刻产出——这些是别人没有的独有资产；建议单独建"生命档案"语料库与训练管线（可优先于公共语料）。
3. 训练方式的"可换挡"清单（按素材到位情况触发）：
   - 攒够 1-10 亿 token 的她本人的真实/近真实语料 → 小型 DAPT 实验（先验证"变笨/人格漂移"代价）
   - 攒够多轮真实对话 → 多轮/长上下文 SFT
   - 有语音素材 → 语音克隆已在线，继续扩
   - 事实 → 全部走记忆库，永不焊权重
