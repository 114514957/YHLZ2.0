## 一、为什么停

1. **天花板卡在 48–49**：所有 SFT 版本挤在 38–48 的窄带里，而 56 题下 1σ ≈ ±4.8 分——
   **大部分版本差异是噪声，不是进步**。
2. **最好的一版是 DPO 不是 SFT**：`v9t10`（SFT）48，`v9t10-dpo2`（DPO）**49**，这是历史最高。
3. **再训只会破坏平衡**：任何上层 SFT 补丁（stylepatch4）都掉 3 分。
4. **大模型的边际收益更高**：同样的提示词工程，大模型能直接吃到长上下文、规范化工具调用、
   前缀缓存；而这些**小模型都吃不到**（35/42 层是 512 滑窗）。

## 三、三条硬结论（训过才知道，别再试回老路）

1. **1 epoch**。3 epoch 直接腰斩：v9t5(3ep)=25 → v9t6(1ep)=42，**+17**，而有效 batch、数据、lr 都没变。
2. **数据不是越多越好**。5931 条 → 48 分；13189 条（多灌 LCCC）→ 44 分。**是稀释，不是量**。
3. **权重配比决定工具能力**。工具样本权重 8.9%(v9t10) → 6.9%(v13) 就导致**工具题 13/16 全挂**；
   拉回 16.9%(v14) 又救回 11/16。**只看条数（900→836）完全看不出来**。

配套证据：`docs/研究/训练全时间线比对_20261114.md`、`docs/技术/训练曲线/`（图）、
`docs/方案/训练注意事项_必读.md`（35 条）、`docs/方案/训练公式对照_v12_20261114.md`。
